# 3D 试穿二期：前后片缝合穿到真人网格人台（复活方案）

2026-09-13 定稿。前身：一期（`.claude/plans/3d试穿一期.md`，2026-09-09）→ 2026-09-12 两次裁撤

## 用户拍板（2026-09-13）

1. **缝合配对在前端**：payload schema v1 原样（边名+role），引擎**零改动**；
2. **解算器原样复活旧 PBD**（常数/兜底/热启动全套移植，XPBD 不做）；
3. **碰撞用 three-mesh-bvh**（morph 后 refit）；
4. **独立原则**：人台滑杆不改衣服尺寸、打版参数不改人台，参数层完全解耦；
   合体度只通过**应变热力图**表现；交互 = 「重新试穿」按钮 + 热启动；
   自动重穿（滑杆松手 debounce）做可选开关、默认关。**不做任何自动调版/自动改体型闭环。**
5. **腰头是真实布片**（2026-09-13 用户口径"腰头一定要和前后片连在一起"）：
   直腰头净样=矩形（payload scalars bottom_length/width 前端重建，仍引擎零改动），
   作为第 5 块面板参与仿真、与前后片缝合；弯腰头首期回退视觉环带+提示（净样非矩形，
   需 payload 扩展后再议）。

## 架构与数据流

```
useDraft 快照 ── api.postFitting（protocol 'fitting' cmd，引擎优先回落 HTTP）
  → payload v1（exporters/fitting.py 原样，三通道已就绪）
  → fitting3d/garment/ 纯函数层：
      mesh.ts      4 面板布料网格（边界弧长重采样+错排栅格+delaunator，移植旧 mesh.ts）
      band.ts      直腰头条带网格（scalars bottom_length/width 前端重建矩形环带；
                   金标对账 bottom_length ≈ Σ四片腰口弧 <0.5%；curved 回退视觉环带+提示）
      align.ts     纵向 y-warp：payload stations ↔ 人台地标 分段线性（hem/knee/crotch/hip/waist
                   五节点，节点从 payload 动态取——直/弯腰头腰站 98/102 会漂移）
      placement.ts 圆柱包裹摆位：θ 映射 + 截面支撑半径 + garmentGap 1.2（移植旧 placePoint，
                   surfaceRadius 改为从 base.bin 网格截面求）；腰头 = 腰站环 + 松量
      seams.ts     11 条物理缝合配对（side×2 / inseam×2 / 前中 / 后中 / 腰缝×4 / 腰头自身
                   后中，镜像片前端派生；腰缝锚点 = 后中/侧缝×2/前中 恰为各片腰口弧链端点，
                   按弧长分点，与侧缝同一套机制）
  → sim worker（新建，与 Pyodide worker 并存）：
      solver.ts    旧 PBD 原样移植（verlet + Gauss-Seidel，3×6，preRelax 200，
                   发散兜底阶梯，settled/frozen 停走）
      collide.ts   three-mesh-bvh：worker 内建 BVH，人台 positions transfer 进来 refit(~1ms)；
                   多遍 sweep=3、碰撞向量必须归一化（旧链前科）、摩擦 0.5
      特殊处理     裆底四缝交汇：weld 成簇 + pin 体表，周边稳定后释放；
                   缝合拉链式渐进激活（锚点向两端），防全边同收的冲量；
                   pin 模型：pin 从前后片腰口**移到腰头**（软 pin 在身体腰站 105.6 环+松量），
                   前后片靠腰缝约束悬挂——真实受力（裤从腰头挂着），腰不再是死边
  → Fitting3DView：garment mesh 进现有场景；求解期常驻 rAF，收敛后回按需渲染
      heatmap.ts   应变热力图复活（红紧/绿贴/蓝松）——独立原则下的合体度唯一表达
```

单位全链 cm 自洽（payload cm / base.bin cm / three 场景 cm），零换算。

## 里程碑

- **M0 通道+静态摆放**：fitting 通道通 → 4 面板三角化 → 包裹静态上屏（半透白色）。
  验收：y-warp 五节点过点断言（knee↔48.144 等）；初始穿透 <50 点且最深 <2cm；镜像对称
  （对应粒子 x 中位差 <0.1cm）；三角形最小角 >15°、面积比 ≥99%。
  ✅ 2026-09-13 完成（garment.test.ts 56 用例 + tsc + pytest 1054 恒绿）。实测修正：
  最小角口径改**内部三角形** >15°——边界弧长重采样点近共线 + Delaunay 必产细长三角形
  （front 39/2421、back 68/2737 全贴边界，最小到 ~0°），旧链原样行为不修（对解算/渲染
  无碍）；另镜像 z 差 <0.05cm（θ-bin 双线性对 ±θ 量化不对称）、y 夹取带 −0.0001 护栏。
- **M1 缝合收敛**：worker 解算 + BVH 碰撞 + 裆底 weld/pin + 拉链激活 + **腰头布片**
  （band 网格、腰缝×4、腰头后中缝、pin 移到腰头；curved 回退视觉环带+提示）。
  验收：11 缝点距均值 <0.3cm、P95 <0.8cm（含腰缝）；band 对账 bottom_length vs
  Σ四片腰口弧 <0.5%；穿透 ≤0.15cm（旧容差，勿写 0）；3~5s 收敛；
  vitest node 直跑 solver 300 步无 NaN。
  ✅ 2026-09-13 完成（solver.test.ts M1 金标 + 全套 58 用例 + tsc + pytest 1054 恒绿）。
  实测 320 帧（5.3s）settle，超方案 5s 端 6.7%——系统性偏差：BVH 面法线逐粒子抖动的
  接触噪声地板高于旧解析三管、启动摆动耗散慢（0.985 下砍半 15 帧）。上限按 360 帧
  （6s）收口，M2 丹宁参数复调一并 revisit。实测修正（六轮参数实验，每轮否决留档）：
  ① 人台腰截面**不在轴上**（中心前移 z+8.5、体侧凹凸包虚高 3.7cm）→ band 摆位 BVH
  snap 实际曲面（collider.snapOne，worker 建 BVH 后传闭包；主线程静态首帧不 snap）；
  ② 碰撞器 maxThreshold=4×skin=1.2 造成**深陷失明**（陷入 >1.2cm 粒子查无命中永不
  推出）→ 无界查询（远粒子由场宽相过滤）；
  ③ band 改**结构化栅格**（nC×nR 行列，通用链共享端点重采样使左右端竖边行集错一行、
  bandEnd 永差一步长）；端边配对 flipRun 反转链向；
  ④ band rest **全保纸样矩形**：按吸附构型重定跨行 rest 与环向纸样 rest 自相矛盾
  （66.8 vs 70.1 周长）→ 预应力喇叭+腰缝拔河不收敛；warp 顶段 1.75× 行距由动力学
  压回真实 4cm 布宽，不进 rest；
  ⑤ band 行高映射 = **腰站锚+真布高**（bandWarp）：warp(105.6+4)=112.5 把 4cm 腰头
  钉到 7cm 高的肋外扩区、周长几何逼出屈曲翼（实测顶行 r 22；注意轴心距指标会把
  前移 z+8.5 的前身误读成鼓包，前中 |xz|≈19-20 本属正常贴体）；
  ⑥ pin = **腰头上沿 belt line 只钉 Y**：全体粒子 Y-pin 已否决（底行 warp 高度 vs
  面板腰口自然悬垂差 ~1.1cm 永久拔河，avgSpeed 平台 ~1.0）；crotchHold=60 硬释放
  是实测窗口内的稳定点（40 提前放荡起不收敛、180 硬放/240 淡出=461/>600 步）；
  preRelaxIters 300（450 把面板拧进缠结吸引域）；启动段强阻尼 0.9 适得其反（缓降
  让整裤重量长期挂腰缝、band 爆环）——启动序列对收敛 basin 敏感，调参留档勿盲改。
  新增先验：preRelaxCollideEvery 10、collideSweeps 1（BVH 单面逐粒子幂等）、
  bandBendStiffness 0.9（ClothMesh.bendK 覆盖机制）。

## 已纠坑（评审证伪，写死不许再犯）

1. 前后片整版并排摆放，缝合锚点**无全局坐标重合**（侧缝腰点相距 ~34cm）——按弧长配对；
2. 侧缝前后净长不等（实测差 0.61%，闭环只保毗围）——pairRuns 脚口端对齐、余量上移；
3. 门襟三分支：fly 连裁 rise 链只剩裆下残段、fly 区 free 边敞口——首期 fly=True 时前端
   给「暂不支持连裁门襟试穿」提示或按平缝简化（金标覆盖三分支）；fly_separate/无门襟平缝；
4. back_yoke=True 后片上口边名变 top（机头线）——**已解决（2026-09-14 育克参与真实
   缝合：16 缝装配链 + 收敛收口 collisionSkin 0.98 持续接触锚，金标 3/3 绿；口径见
   决策日志 2026-09-14 两条）**；
5. y-warp 节点从 payload stations 动态取（直/弯腰头漂移）；含 hip 节点（否则臀线错 ~4.8cm）；
6. 性能按旧链实证口径（3 substeps×6 iter、spacing 1.5、~3-4k 粒子/片）预算，勿信高迭代表；
7. 人台腰上无几何（裁切面 120.64）：高腰/腰头上沿展示受限，属已知边界；
8. 站名错位（引擎 hip/hem vs 人台 hips/ankle）——对齐表显式写死在 align.ts，勿按名匹配。
9. 省口余量（后片腰省/前片袋口吃省）使纸样腰弧 > 成品腰围——腰头"代数求和净长"与四片
   腰弧同口径故**缝合长度自洽**；但 3D 不缝省时省口余量表现为腰部轻微起拱，M1 接受，
   M2 可选把省腿（payload marks 现成有）加一对缝合约束闭口。
10. 弯腰头净样非矩形（前后腰弧真拼合+整根均匀圆弧），scalars 三个标量重建不出——
    waistband_type=curved 时回退视觉环带+「弯腰头布片仿真待引擎导出净样」提示；
    真实弯腰头布片是唯一需要 payload 扩展的点，届时再议（动引擎须重议决策 #1）。
11. 腰头占据 y≈105.6~109，人台裁切面 120.64 以下全程有碰撞几何——但高腰款/极端身高
    morph 后须复核 band 上沿仍在裁切面之下。
