# 3D 人台试穿（一期：前后片 PBD 布料 + 参数化人台）

## Context

用户反馈：整版 2D 视图太抽象，看不到「穿在身上的效果」。行业常见做法是 3D 人台试穿：调参数 → 看 3D 穿着效果 → 满意后导出 DXF。本计划为 Web 前端新增 3D 试穿视图，导出链路不改（现有 stale 门控已覆盖「调好再导出」）。

**用户已拍板的方向**：
1. **轻量物理仿真**：自研 PBD（位置动力学）布料解算——前后片网格 + 缝合约束 + 人台碰撞 + 重力，呈现真实悬垂/褶皱/松紧；纯 TS 实现。
2. **参数化人台，但体型围度与成衣尺寸分离**（2026-09-09 用户纠偏）：尺寸单围度是**成衣量**（含松量/调节量），不能直接当人台围度，否则松紧效果是假的（永远显示先验松量）。体型（腰/臀/大腿/膝围）为**独立参数组**：前端独立 state + localStorage 持久化，不进引擎 `Measurements`（引擎只认成衣量）、不进 DraftPayload、不影响打版；默认值从成衣尺寸按先验松量**反推估计**（标注「估计值」），用户可改成真实测量值。人台站点高度仍取整版构造线（垂直定位跟版走）。附带收益：可做逐站点松量读数（成衣围 − 人体围）。不引入外部模型资产。
3. **一期范围**：前后片布料缝合 + 腰头以环带呈现；口袋口/门襟/机头/贴袋等以结构线绘制在片面上（随布料变形）；小裁片不做独立缝合（二期）。
4. **辅助功能（2026-09-09 用户全选）**：应变热力图（紧绷红/贴合绿/松弛蓝）、视角快捷按钮（正/侧/背/斜 45°）、透明度控制（布料半透明/隐藏人台）、3D 截图导出 PNG；3D tab 内**快捷参数滑杆**（腰/臀/膝/脚口/裤长等，debounce 自动重算重试穿，所见即所得）；**体型管理三件套**——内置预设库（标准 160/64A、165/66A、170/70A、沙漏 165、直筒 165）+ 自定义命名保存/列表/删除/设默认 + JSON 导入导出。

## A. 引擎侧：fitting payload 出口

### A1 两个核心决策

1. **统一序列化到整版全局坐标 cm、Y 向上**：前后片反变换仅 `global=(lx+ox, oy−ly)`。收益：初始摆位直接用全局 Y 当人体高度、marks 零换算、金标可写「hem 边折线所有点 y == front.hem_line.a.y」强断言。**例外**：腰头是旋转局部系（origin=后中、X̂=后弧切向）且 3D 只作环带 → 序列化为 `frame:"local"` + 标量（top/bottom 净长、宽），规避旋转逆推。
2. **origin 补法 = `PatternPiece` 追加尾部默认字段** `origin: Point | None = None`、`frame: str = "reflect_y"`，仅前后片 flow 构造时传入；3 处重建点（pieces.py×2 + cutter.py:132）同步透传。不动任何现有测试。备选（flow 往 local ctx 塞 NamedPoint）会破 `test_front_piece.py:186` 等断言——不取。

### A2 JSON 契约（v1）

```
顶层：ok / schema_version(1) / units("cm") / frame{system:"sheet",y_axis:"up"} / body / pieces / warnings

body:
  stations: [{key:"waist"|"hip"|"thigh"|"crotch"|"knee"|"hem",
              y, girth_finished, per:"body"|"leg"}]        // y 取 front.*_line.a.y；thigh 未录省略
  points: {front_crotch_vertex:[x,y], back_crotch_vertex:[x,y]}
  crotch_drop / waistband_width / waistband_type("straight"|"curved") / outseam

pieces: [front_piece, back_piece, waistband]（固定序）
  通用: key, name, origin([x,y]|null), frame("reflect_y"|"local"), bbox
  edges: [{name, kind:"line"|"bezier", role, pts:[[x,y]...], length}]   // 净边链原序
    role 表（引擎常量）：front {waist:top_chain, hem:hem, mouth/fly_*:free, rise/inseam/side:seam}
                        back  {top/waist:top_chain, hem:hem, cb/inseam/side:seam}
  marks: [{pts}]；notches；grain
  腰头专属: origin=null, frame="local", scalars{top_length, bottom_length, width}
```

要点：`girth_finished` 中 waist/hip 为整圈围、thigh/knee/hem 为单腿围（与尺寸单录入口径一致，均为**成衣量**）——供前端松量读数（成衣 − 体型）用；**人台围度不来自 payload**，来自独立 BodyProfile（B2）；引擎不含体型先验（改先验/体型不用重打引擎 zip）；折线密度 0.01cm 弦高，三片 <40KB；请求体 = 现有 `DraftRequest`。

### B3 裁片→布料网格（mesh.ts）

- boundary 弧长重采样 h=1.5cm；内点 = grain 向扫描栅格（h×h·0.866 错排）+ 多边形内测试。
- 三角化 = **新依赖 delaunator**（~10KB 纯 JS）+ 丢弃质心在外三角形（被拒备选：扫描线条带剖分，+150 行）。
- 输出 ClothMesh：positions/rest 全局系、triangles、boundary 边标记（role/边名/弧长参数）、2D 点定位结构。
- 规模：4 半片 ~8800cm² → ~5k 粒子 / 15k 距离 / 10k 弯曲约束，1 万粒子内达标。

### B4 初始摆位与缝合（seams.ts）

- 镜像：as-drafted = 左半（约定常量）；右片 Z 取反。
- 初始包裹：布点全局 y 直接当人体高度；θ = θ_base + span×(片内 x 归一化)（front 左片 浪→0°、侧→−90°；back 左片 cb→180°、侧→270°）；径向 = R(y,θ)+松量半径。初态贴终态 → 收敛快不炸。
- 配对表（弧长参数配对，两端各重采样 ceil(len/1cm)）：
  `(f,L).side↔(b,L).side`（脚口端起）、`(f,L).inseam↔(b,L).inseam`（脚口端起）、`(f,L).rise↔(f,R).rise`、`(b,L).cb↔(b,R).cb`（腰口端起）+ 右侧镜像；`free`（mouth/fly_*）与 hem 不配对。
- 缝合 = 零静止长度距离约束 + 高刚度（不稳时降级为焊合粒子）。
- **腰口：视觉环带 + pin，不做腰头布片**（腰头近无弹性、仿真只引入高刚度→小步长稳定性代价）。top_chain 点 pin 到「各点自己 drafted 高度处的人台环+松量半径」（yoke 开启时 back 顶链天然 pin 在机头缝高度；与环带间缺口记为一期已知简化）；环带 = 腰口开闭周长与 scalars.top_length 间放样 + 外扩 0.3cm，深色静态；pin 权重 0.9 防整裤下滑。

### B5 PBD 解算器（pbd/）

- verlet（dt=1/60、重力 −980cm/s²、阻尼 0.985）+ **Gauss-Seidel** 顺序投影；3 substeps × 6 iterations，rAF 内 1 step；连续掉帧>2 自适应降 substep；tab 隐藏暂停。
- 约束：结构+剪切=全边距离（0.9~1.0）、弯曲=相邻三角形对点（0.3）、缝合、pin；自碰撞一期不做。
- 参数变更 → 网格重建 + **旧解热启动**（新 2D 点在旧网格重心插值继承位置与 0.5×速度）；边名序列变化/无旧解 → 冷启动 + 预松弛 200 次离线迭代（进度条）。
- 发散兜底阶梯：NaN/超大坐标检测 → 恢复上一好快照（阻尼×0.9、iterations×2 重试）→ 仍败冻结当前帧 +「仿真已暂停」角标。
- settled 检测（均速<阈值×30 帧）→ 停解算只渲染。
