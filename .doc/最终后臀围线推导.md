# 牛仔裤打版：后片臀围线绘制核心技法（定长斜截法）

> **核心逻辑**：将后臀围内缝点沿后浪线**同等上移**顺应臀腰起翘，再以**已确定的后臀围长**为固定半径，斜截**原始后臀围水平基础线**，精准定位后臀围外缝顶点。

---

## 一、 核心操作三步法

### 1. 内缝顶点上移（确定最终后臀围内缝顶点）
* **测量基准**：测量 **后中内收点** 沿后中斜线向上至 **后浪顶点** 的移动距离 $d$。
* **同距上移**：将原始后臀围线与后中斜线的交点，沿后中斜线向上**平移等距离 $d$**，定位为 **「最终后臀围内缝顶点」**。
  * *目的：让整条后臀围线跟随后浪起翘，立体包容臀大肌凸量。*

---

### 2. 定长斜截找点（确定后臀围外缝顶点）
* **操作方式**：以 **「最终后臀围内缝顶点」** 为固定起点，以已求出的 **「后臀围长」** 为尺长（或半径），斜向向下截取 **「原始后臀围水平基础线」**。
* **交点锁定**：尺子与水平基础线的相交点，即为 **「最终后臀围外缝顶点」**。

```
最终后臀围内缝顶点 O (沿后浪斜线上移距离 d)
                  \
                   \  固定线段长度 = 已计算的后臀围长
                    \
---------------------X (最终后臀围外缝顶点) <--- 原始后臀围水平基础线
```

---

### 3. 连接确定最终后臀围线
* **连接两点**：用直尺连接 **最终后臀围内缝顶点** 与 **最终后臀围外缝顶点**。
* **形态特性**：此线为一条**内高外低**的倾斜直线，直线长度严格等于设计的后臀围长，且外缝点回落于基础线，保证与前片侧缝臀围高度等齐对位。

---

## 二、 关键注意事项 (Checklist)

| 核对项目 | 关键要求 | 操作说明 |
| :--- | :--- | :--- |
| **上移量一致性** | 内缝点上移距离必须与后腰起翘移动量相等 | 确保整个后背核心段整体同步起翘，不拉扯变形 |
| **外缝点水平高** | 外缝顶点必须准确落在**原始臀围水平基础线**上 | 保证前、后片在侧缝臀围点位处零高差完美拼接 |
