# 牛仔裤腿部弧线程序化控制点推导规范

---

## 一、 几何构建核心准则

* **膝围以下（膝口 $\rightarrow$ 脚口）**：升级采用**自适应二次贝塞尔曲线（Adaptive Quadratic Bézier）**连接，实现“同宽为直，异宽微弧”的人体工学动态拟合。
* **膝围以上（大腿段）**：采用**三次贝塞尔曲线（Cubic Bézier Curve）**拟合 [cite: 6]。
* **$C^1$ 连续性约束（切线平滑准则）**：大腿弧线进入膝围端点时的切线向量，**必须与膝下小腿曲线顶端的切线斜率严格共线**，保证膝围接点处平滑无转角、不突起 [cite: 6]。

---

## 二、 三次贝塞尔曲线通用几何方程

参数化设计共需定义 4 个控制点 $(P_0, P_1, P_2, P_3)$，其数学曲线公式为 [cite: 6]：

$$B(t) = (1 - t)^3 P_0 + 3(1 - t)^2 t P_1 + 3(1 - t) t^2 P_2 + t^3 P_3, \quad t \in [0, 1]$$

---

## 三、 小腿段弧线（膝口 $\rightarrow$ 脚口）自适应二次贝塞尔曲线公式

小腿段由 3 个控制点 $(P_{\text{knee}}, P_{\text{mid}}, P_{\text{hem}})$ 决定的二次贝塞尔方程，可统一拟合“直筒平直、修身微弧、喇叭顺向”三种裤型：

$$B_{\text{lower}}(t) = (1-t)^2 P_{\text{knee}} + 2(1-t)t P_{\text{mid}} + t^2 P_{\text{hem}}, \quad t \in [0, 1]$$

### 控制点 $P_{\text{mid}}$ / $Q_{\text{mid}}$ 自适应推导：
1. **直线中点坐标**：设起点（膝口）与终点（脚口）的几何中心为 $M = \left(\frac{X_{\text{knee}} + X_{\text{hem}}}{2}, \; \frac{Y_{\text{knee}} + Y_{\text{hem}}}{2}\right)$
2. **横向单边差量**：$\Delta x = X_{\text{knee}} - X_{\text{hem}}$
3. **中位控制点公式**：引入弓高控制系数 $\alpha \in [0.08, 0.12]$，则内缝或外缝的中介控制点横坐标自适应补偿为：
   $$P_{\text{mid}} = \left( X_M + \alpha \cdot \Delta x, \; Y_M \right)$$

| 裤型形态 | 规格条件 ($\Delta x$) | 中点 $P_{\text{mid}}$ 坐标特性 | 曲线形态与人体工学作用 |
| :--- | :--- | :--- | :--- |
| **直筒裤 / 上下同宽** | $\Delta x = 0$ | $P_{\text{mid}} = M$ （无差量偏移） | **100% 绝对直线**（数学上自然退化为纯线段） |
| **修身裤 / 上宽下窄** | $\Delta x > 0$ | $P_{\text{mid}}$ 向外部肌肉侧微凸偏移 | **微凸平滑曲线**（顺应小腿肚/腓肠肌凸起，避免裤管绷直） |
| **喇叭裤 / 上窄下宽** | $\Delta x < 0$ | $P_{\text{mid}}$ 向内部方向微凹偏移 | **顺滑展开曲线**（自膝口向下呈现流畅喇叭口，无突兀折线） |

## 四、 内缝弧线（小裆 $\rightarrow$ 膝内缝）控制点计算公式

设：**前小裆顶点** $P_0 = (X_{\text{crotch}}, Y_{\text{crotch}})$，**膝围内缝点** $P_3 = (X_{\text{knee}}, Y_{\text{knee}})$，**脚口内缝点** $P_{\text{hem}} = (X_{\text{hem}}, Y_{\text{hem}})$ [cite: 6]。
* 高差量 $\Delta Y = Y_{\text{crotch}} - Y_{\text{knee}}$ [cite: 6]
* 宽差量 $\Delta X = X_{\text{crotch}} - X_{\text{knee}}$ [cite: 6]

| 控制点 | 物理节点 | 几何推导与参数方程 | 参数意义与默认值 |
| :--- | :--- | :--- | :--- |
| **$P_0$** | **曲线起点** | $P_0 = (X_{\text{crotch}}, Y_{\text{crotch}})$ [cite: 6] | 匹配小裆底尖端坐标 [cite: 6] |
| **$P_1$** | **上控制点** | $P_1 = (X_{\text{crotch}} - k_1 \cdot \Delta X, \; Y_{\text{crotch}} - k_y \cdot \Delta Y)$ [cite: 6] | 控制小裆弧弯度急缓 [cite: 6]<br>推荐常量：$k_1 \in [0.15, 0.25], \; k_y = 0.28$ [cite: 6] |
| **$P_2$** | **下控制点** | $P_2 = P_3 + k_2 \cdot \vec{u}$<br>其中 $\vec{u} = \frac{P_3 - P_{\text{mid}}}{\|P_3 - P_{\text{mid}}\|}$ | **强制切线共线约束**<br>$\vec{u}$ 为从 $P_{\text{mid}}$ 指向 $P_3$ 的单位斜率向量（保障与膝下切线重合）<br>推荐模长参数：$k_2 = 0.35 \cdot \Delta Y$ [cite: 6] |
| **$P_3$** | **曲线终点** | $P_3 = (X_{\text{knee}}, Y_{\text{knee}})$ [cite: 6] | 匹配膝围内侧定位点 [cite: 6] |

---

## 五、 外缝弧线（臀外缝 $\rightarrow$ 膝外缝）控制点计算公式

设：**臀围外缝顶点** $Q_0 = (X_{\text{hip}}, Y_{\text{hip}})$，**立裆线高度** $Y_{\text{crotch}}$，**膝围外缝点** $Q_3 = (X_{\text{knee}}, Y_{\text{knee}})$，**脚口外缝点** $Q_{\text{hem}} = (X_{\text{hem}}, Y_{\text{hem}})$ [cite: 6]。

| 控制点 | 物理节点 | 几何推导与参数方程 | 参数意义与默认值 |
| :--- | :--- | :--- | :--- |
| **$Q_0$** | **曲线起点** | $Q_0 = (X_{\text{hip}}, Y_{\text{hip}})$ [cite: 6] | 匹配臀围线上端侧缝点 [cite: 6] |
| **$Q_1$** | **上控制点** | $Q_1 = (X_{\text{hip}} - \delta x, \; Y_{\text{crotch}})$ [cite: 6] | 控制大转子外凸饱满度 [cite: 6]<br>$\delta x \approx 0.1 \sim 0.2\text{cm}$（或顺直 $\delta x = 0$） [cite: 6] |
| **$Q_2$** | **下控制点** | $Q_2 = Q_3 + m_2 \cdot \vec{v}$<br>其中 $\vec{v} = \frac{Q_3 - Q_{\text{mid}}}{\|Q_3 - Q_{\text{mid}}\|}$ | **强制切线共线约束**<br>$\vec{v}$ 为从 $Q_{\text{mid}}$ 指向 $Q_3$ 的单位斜率向量（保障外侧缝膝口0拐角）<br>推荐模长参数：$m_2 = 0.4 \cdot (Y_{\text{crotch}} - Y_{\text{knee}})$ [cite: 6] |
| **$Q_3$** | **曲线终点** | $Q_3 = (X_{\text{knee}}, Y_{\text{knee}})$ [cite: 6] | 匹配膝围外侧定位点 [cite: 6] |

## 六、 程序化 CAD 实现核心逻辑

无论采用何种语言开发，实现无拐角过渡的核心都在于 **$P_2, P_3, P_{\text{mid}}$（及 $Q_2, Q_3, Q_{\text{mid}}$）三点严格共线**：

1. **锁死斜率**：下控制点 $P_2 / Q_2$ 的位置，**只能**在 $(X_{\text{mid}}, Y_{\text{mid}}) \rightarrow (X_{\text{knee}}, Y_{\text{knee}})$ 的射线延伸方向上移动。
2. **仅调节系数**：版师调整尺寸或弧形时，程序只需改变纵向伸展参数 **$k_2 / m_2$** 的模长系数，即可实现“直筒 -> 修身 -> 紧身”曲线的参数化自适应变化 [cite: 6]。
