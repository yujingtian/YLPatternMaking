# 参数推测知识库（索引）

照片提取（`agent extract`）推测规则的**唯一权威**。本文件夹即知识库本体：**一个参数组一篇文档**（用户收集 + 固定字段头），本文件只做索引、总表与裁定记录，不放规则正文。与[款式判据手册](款式判据手册.md)（待建）并列：知识库管*怎么推*，手册管*怎么看*。

**代码对应约定**：`extract/derive.py`、`prejudge.py`、`families.py` 的每个函数必须注明所抄录的条目号（K1~K4…）；无条目号的表值禁止进代码。prompt 生成（schema.py）从各条目的「输入依赖」字段抽取「该参数需要模型提供什么视觉信息」。

**口径优先级**：本文件夹（预测口径）> 项目 .doc 推导文档（引擎实现口径）> 通用工业惯例。冲突时见下方裁定记录。

## 四、区间 → 定值的三级定位机制（全条目通用，各条目「区间内定位」字段细化）

1. **连续锚点插值**（主）：区间端点绑连续量（X 按臀腰差、基准带按归一化 front_rise、省宽=K4 缺额连续算出再 clamp）——算式本身就是定位器，区间只做上下限。
2. **多轴偏移**：其余轴把取值推向区间端点的方向规则（紧身/无弹靠上限、宽松/高弹靠下限）。
3. **中值兜底 + 评分步进**：无锚点键取带中值；打版后特征评分出界在区间内步进（一期警示、二期回喂）。

模型在此的角色：**不口算绝对 cm**；只做分类（形状/弧深三档/轴确认）与带证据的 override。

## 五、K5 部件尺寸初版子规则（暂居本文件，攒金标后独立成篇）

2026-09-30 袋贴×门襟重合事故催生（决策日志同日条）：extract 固定发射
front_pocket_p1_dist=10.0 不随码自适应——W=66 款袋贴腰侧边界与独立门襟
顶边共占腰弧（s_fw + fly_width ≥ 腰弧长），整版静默重合、探针 L0 无感。
p1 按四则组合（代码：families.part_family / derive.derive_all）：

- **K5-a 腰围锚点插值（兜底带值）**：无照片比例（或比例不被采纳）时
  p1 = 8.8 + (W−64.3)×1.2/9.7，钳 [8.8, 10.0]。锚点：W64.3→8.8（金标
  example）/ W74→10.0（金标照片 29 码；165 款照片比例 0.53×腰弦 18.9≈10.0
  交叉印证）；W<64.3 取下锚 8.8 并披露「无实测锚」。
- **K5-b 腰弧预算 clamp（防重合，主/兜底两通道统一生效）**：独立门襟
  顶边占腰弧前中端 [lw−fly_width, lw]、袋贴腰侧边界占 [0, p1+facing_width]，
  相交即重合。p1 ≤ 前腰弦 − fly_width 4.0 − facing_width 3.5（facing 开；
  关不扣）− 安全间隙 1.0，floor 0.1。前腰弦 = waist_front_target(W,
  waist_balance, 0, ③袋口)（弦 ≤ 腰弧实测，保守安全侧）；引擎侧同步上
  守卫（front_pocket_steps，消息含三键字面量供探针 L1 归因，见决策日志）。
- **K5-c 小表袋下界（watch 开；袋口宽随 K5-d 可变 → 2026-10-01 动态化）**：
  p1 ≥ ceil0.1(offset_from_side 2.0 + 袋口宽·cos8° + 间隙 0.5 − 袋贴腰头
  端宽 3.5)——袋贴内边射线相交的必要条件；袋口宽取 watch_pocket_width
  终值（K5-d 换算值已过 G 表带 5.0~6.5 钳制）；袋口宽 5.5（G 表兜底）时 = 4.5
  （必要非充分：引擎默认 s_fw=12.0 有炸点实证，充分性由探针 L0 兜底）；
  与 K5-b 冲突时下界胜出 + 披露（可归因侧失败优于射线空归因直掉 L2）。
- **K5-d 比例读图 v1（照片主通道，用户口径 2026-09-30；2026-10-01 扩至
  p2 与小表袋宽）**：腰围/前浪已知 → 前后腰宽、前浪有效高可算 → 模型
  只报 0~1 比例（不出 cm）、代码 × 已算锚长换算：
  分母一律取**单侧腰宽**（照片上该侧侧缝腰点到前中门襟纽扣中线的腰头
  可见长度，约为整条腰头全宽的一半——分母锚 = 前腰弦是单侧值，读全宽
  比例会系统性腰斩一半）：
  p1 = clamp(袋口上端离侧缝距离 ÷ 单侧前腰宽, 0.40, 0.65) × 前腰弦；
  p2_drop = clamp(袋口下端到腰头下缘的竖直距离 ÷ 腰头下缘到裆底的竖直
  距离, 0.20, 0.40) × 前浪有效高（= front_rise − 腰头宽 4.0；examples
  实测比例 0.27~0.31）；
  watch_pocket_width = clamp(小表袋袋口宽 ÷ 单侧前腰宽, 0.22, 0.40) ×
  前腰弦，换算值过 G 表带 5.0~6.5 钳制（G 表 5.5 在 examples 实测
  0.29~0.35）；
  back_patch_width = clamp(袋口宽 ÷ 单侧后腰宽〔照片上贴袋所在那一侧
  后中到侧缝腰点的腰头可见长度〕, 0.55, 0.80) × 后腰弦
  （= W/4 + waist_balance + Σ后省口）。conf>0.6 且 parse 窗 [0.10, 0.90]
  内才采纳；出物理窗钳窗后照算、出 parse 窗整条丢弃视为未观测回退 K5-a/
  腰位分档/G 表。换算后照常过 K5-b / K5-c（动态）/ 静态值域；p2 出界由
  引擎 P2 主切口守卫兜底（消息含 front_pocket_p2_drop 键字面量供探针
  L1 归因）。**无金标集验证**（用户裁定提前做）——物理窗取自 examples
  实测（p1：165 比例 0.53 / 5015 0.61）防幻觉极端值。
