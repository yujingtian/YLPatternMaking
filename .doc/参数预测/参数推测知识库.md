# 参数推测知识库（索引）

照片提取（`agent extract`）推测规则的**唯一权威**。本文件夹即知识库本体：**一个参数组一篇文档**（用户收集 + 固定字段头），本文件只做索引、总表与裁定记录，不放规则正文。与[款式判据手册](款式判据手册.md)（待建）并列：知识库管*怎么推*，手册管*怎么看*。

**代码对应约定**：`extract/derive.py`、`prejudge.py`、`families.py` 的每个函数必须注明所抄录的条目号（K1~K4…）；无条目号的表值禁止进代码。prompt 生成（schema.py）从各条目的「输入依赖」字段抽取「该参数需要模型提供什么视觉信息」。

**口径优先级**：本文件夹（预测口径）> 项目 .doc 推导文档（引擎实现口径）> 通用工业惯例。冲突时见下方裁定记录。

## 四、区间 → 定值的三级定位机制（全条目通用，各条目「区间内定位」字段细化）

1. **连续锚点插值**（主）：区间端点绑连续量（X 按臀腰差、基准带按归一化 front_rise、省宽=K4 缺额连续算出再 clamp）——算式本身就是定位器，区间只做上下限。
2. **多轴偏移**：其余轴把取值推向区间端点的方向规则（紧身/无弹靠上限、宽松/高弹靠下限）。
3. **中值兜底 + 评分步进**：无锚点键取带中值；打版后特征评分出界在区间内步进（一期警示、二期回喂）。

模型在此的角色：**不口算绝对 cm**；只做分类（形状/弧深三档/轴确认）与带证据的 override。
