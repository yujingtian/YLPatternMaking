## 一、口径：臀腰同调

腰围的前后片分配量**默认等于臀围的前后片分配量 Δ**。Δ 已有五档预设路由
（DELTA_PRESETS：men_straight 0.6 / women_curvy 1.35 / high_stretch 0.4 /
loose_wide 0.25 / women_standard 1.0）+ 大差侧缝前移修正（H−W > 25 时
+0.5、clamp 2.0），waist_balance 不再有独立派生逻辑，直接取 Δ 终值。

**旧口径退役**（2026-09-29，决策日志 §九）：`curvy_waist_balance` 独立
派生桩（curvy + skinny/slim 给 −0.5、其余恒 0）删除——它让腰围调节量
不参与臀腰分配，实测症状：前片腰侧点与臀侧点共竖直线（前侧收量塌零）、
后片臀腰差巨大、差额全压后片。

## 二、fi / bi 算术（引擎精确律，2026-09-29 实测校准）

前侧收量 fi（front.hip_outseam_point 到 hip_inner_point 臀宽弦长 −
front.waist_side_point 到 rise_top_point 腰宽弦长）的引擎精确律：

```
fi = (H−W)/4 + (waist_balance − Δ) − 前腰长调节(front_waist_dart)
                                        − 袋口吃省(ΔW = front_pocket_dart_width)
```

- 各分项斜率均为 1（实测逐项验证）：balance 每加 0.25 → fi 恰加 0.25；
  前腰长调节与袋口吃省 1:1 吃掉 fi；
- **①前中内收（front_intake_ratio）不进 fi**——实测 ratio 0.2 与 0.9
  fi 逐位相同。机理：前浪顶点由前浪弧长闭合反推、腰侧点由腰长定位
  （|AB| = 腰长，腰头绘制推导.md §4.2），① 只挪前浪起点 a0、改形不改
  腰长。早期设计稿（智能体闭环一期设计 §1.2）把 ① 列为 fi 压缩项，
  系未实测的推导错误，本文档为准；
- 后侧对称式：bi = (H−W)/4 − (waist_balance − Δ) − Σ后省口；
  **curvy 大差款 fi > bi 接受**（后片吃量本就靠育克与省道，2026-09-29
  用户确认）——旧「前 ≤ 后」倒挂判据随之退役（score S3 换塌零警项）；
- 塌零的驱动只有三个：balance−Δ 偏离（调版单动一键时）、前腰长调节、
  袋口吃省。同调基线下健康身材（H−W ≥ 10 → fi ≥ q − 省口）常规不塌；
  塌零组合 = 中等臀腰差 + 深腰长调节/宽袋口吃省。

## 三、塌零守卫（agent/extract/balance.py，谓词单源）

**判据只有一条：前侧塌零**（用户症状的直接度量——fi = 0 即腰侧点与
臀侧点共竖直线）：

- 病态：fi < 0.5 且 H−W ≥ 10；豁免区 H−W < 10（直筒身材前侧近铅垂
  合法，不警不治）；后侧不设带（balance 前减后加 1:1 对搬，前侧抬起来
  后侧自动让位）；
- 阈值 0.5 定稿（用户口径，不做工厂定标；矫正过度/不足只调这一个数）；
- 回喂：挂 extract_from_input 探针 **L0 直接过**之后（L0.5/L1+ 已有
  回退语义不叠加），balance += 0.25 步进**整版重跑**（复用毗围闭环
  哲学，闭包不变量自动保持），≤ 2 轮、累计 |Δ| ≤ 1.0；到顶仍塌取
  最接近版 + 披露「建议核对腰臀尺寸」；
- **用户亲说优先**：waist_balance ∈ seed_overrides（调版账本设定过）
  时守卫只量只披露、不改值；
- score「前侧收量塌零」警项与守卫共用同一谓词：score 只警不改，
  守卫负责改。

## 四、调版联动（映射层口径）

用户要求整体前后互换/侧缝前移（「侧缝往前挪」「前后片调换」）时，
「前后片臀围调节量」与「腰围前后分配」两键**同向同幅联动**（两键同发，
本口径的映射层体现；adjust.py prompt 规则 5，不做代码活链）。

映射面范围 [−2.0, 2.0]（对齐 Δ 上限，防 1.35 档顶穿钳位端点致步进
方向反转）。
