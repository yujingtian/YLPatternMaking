# 牛仔裤前口袋统一打版架构：基于策略路由的参数化流水线 (Unified Denim Pocket Architecture)

> **文档性质**：核心几何算法与系统架构规范  
> **设计模式**：策略路由模式（Strategy Pattern）—— **统一特征点驱动 + 分流结构拓扑联动 + 组合配置化**  
> **支持类型**：挖削嵌入式（Inset / Scoop）与表面外贴式（Patch / Baker）

---

## 一、 顶层架构与流水线路由 (Pipeline Routing)

系统以腰侧交点为局部原点 $O(0,0)$，通过公共输入点位与属性，经由 `pocket_family` 分流入不同样板几何计算管线：

```
 前片大片原形 (Front Panel Baseline) + 定位锚点 P1(腰), P2(侧缝)
                               │
                               ▼
                【策略路由：pocket_family ?】
                ┌──────────────┴──────────────┐
                ▼                             ▼
    [ INSET：挖削嵌入式管线 ]             [ PATCH：表面外贴式管线 ]
                │                             │
    ├─► 1. 参数化共线渐变转省                 ├─► 1. 前身大片保持 100% 完整 (无挖除)
    │      计算自上而下的省量衰减切线            │
    ├─► 2. 前大片布尔切削 (Boolean Cutout)    ├─► 2. 前片表面标记定位线 (Drill & Marking)
    │      生成被挖掉后的有效大片样板           │
    ├─► 3. 内层袋布贴与底袋拓扑生成           ├─► 3. 贴袋独立表布多边形拓扑
    └─► 4. 止口与明线轨线生成                 └─► 4. 四周包边与口缝拓展 (Hemming)
```

## 二、 公共几何基础与参照轴系 ($\Sigma_L$)

1. **原点 $O(0,0)$**：前片样板顶部腰线上端与外部侧缝线的角交点。
2. **主特征锚点**：
   * 腰线入口端点：$P_1$ —— 腰弧上自原点 $O$（腰外缝顶点）朝前浪顶点沿弧量取 `p1_dist`
   * 侧缝出口端点：$P_2$ —— 外缝弧上自原点 $O$ 向下沿弧量取 `p2_drop`

> **弯腰头情形（有效腰口，Curved-Waistband Effective Waistline）**：若为**弯腰头**，腰头为独立裁片（上腰弧 → 下腰头线之间裁除，见 前腰头绘制推导.md §4.3/§5.2），裤身顶边是**下腰头线**。此时**挖削嵌入式（INSET）主切口**的原点 $O$ 取**下侧缝腰点 $B'$**（外缝弧自腰外缝顶点 $B$ 向下量取腰头宽 $W$ 处），$P_1$ 改在**下腰头线**上自 $B'$ 朝前浪顶点量取 `p1_dist`、$P_2$ 在外缝弧上自 $B'$ 向下量取 `p2_drop`，挖除区侧缝边界 $P_2 	o O$ 亦截至 $B'$（不伸入腰头裁除区）；**直腰头**时 $O$ 即腰外缝顶点 $B$、相对上腰弧定位（行为不变）。袋布锚点与主切口同一基准（见 袋布绘制.md §六.五）。**表面外贴式（PATCH）** 虽为独立定位、与 INSET 锚点解耦（§四.2），其袋口外上角基准点同样按弯腰头取**下侧缝腰点 $B'$**、直腰头取腰外缝顶点 $B$。程序化实现统一收敛于 `steps/front_steps.effective_waist`（返回有效侧缝腰点 / 有效腰弧 / 侧缝点在外缝弧上的弧长位置；PATCH 仅用有效侧缝腰点）。
3. **几何母线 $C(t)$**：由端点 $P_1, P_2$ 及曲线控制函数求出的归一化参考路径，$t \in [0, 1]$。曲线控制函数三种模式：**弧高式**（三次贝塞尔浅弧，弧高 + 弧顶位置参数）、**两端垂直式**（$P_1$ 端切线 $\perp$ 腰弧切线、$P_2$ 端切线 $\perp$ 外缝弧切线，均指向裤片内部，形状由两端切线柄长控制）、**折角式**（带倒角折线：$P_1 	o K_1 	o \cdots 	o K_n 	o P_2$ 多段直线，折角列表 `corners` 逐角给（弦上位置， 内推深度），位置严格递增；空列表 = 直袋口）。

## 三、 分支 A：挖削嵌入式管线 (Inset Pipeline)

此策略适用于经典 5 袋款、工装斜切插袋，核心特点为 **需要消化腰部省量** 且 **前身大片会裁除右上角切区**。

### 1. 统一共线渐变转省算法 (Collinear Tapered Dart Absorption)
采用同形轨迹自上而下汇合的**“渐变衰减偏置法（Collinear Tapered Paring）”**，将前腰省量与防翻撇量一并消化在袋口线上。
* **输入参数**：腰头吃省总宽 $\Delta W_{	ext{dart}}$（常规 $15\sim25	ext{ mm}$），衰减幂指数 $n$（常规 $1.5\sim2.0$）。
* **渐变吃量方程**：设由腰头端点 $P_1$ ($t=0$) 和侧缝端点 $P_2$ ($t=1$) 定义的主设计路径为 $C(t)$。省顶点沿腰头线取得：$P_1'$ = $P_1$ 沿腰弧朝前浪顶点量取 $\Delta W_{	ext{dart}}$，撇削向量 $ ec{V} = P_1' - P_1$。前大片实际挖掘切削的曲线为设计净线的**共线**渐变偏置：
  $$C_{	ext{cut}}(t) = C(t) + (1 - t)^n \cdot  ec{V}$$
  * **当 $t = 0$（腰缝端点 $P_1$）：** $(1 - 0)^n = 1$，切削起点 $C_{	ext{cut}}(0) = P_1'$ 落在腰头线上，精确吃掉设定的腰省量 $\Delta W_{	ext{dart}}$，不向裤片内折。
  * **当 $t = 1$（侧缝端点 $P_2$）：** $(1 - 1)^n = 0$，缩进量衰减至 $0$，与原侧缝端点严格重合，不破坏侧缝与臀围数据。
* **制版表现**：缩量后的前片与净线袋布贴对位车缝，形成上紧下顺的立体碗状包裹力，**完全免去 2D 空间旋转**，且完美兼容贝塞尔圆弧与多边形折线。

---

### 2. 前大片布尔切削数学模型 (Front Panel Boolean Cutout)
前片样板被主切口线截去右上区域，需严密表达裁区减法关系。

* **挖除目标区域 ($\Omega_{	ext{cutout}}$)**：
  $$\Omega_{	ext{cutout}} = 	ext{Polygon}\Big(O 	o P_1 	o C_{	ext{cut}}(t)	ext{ 序列} 	o P_2 	o O\Big)$$
* **有效裁剪前身大片 ($\Omega_{	ext{front\_final}}$)**：
  设初始前身裤片外圈多边形为 $\Omega_{	ext{front}}$，则最终发往切割机的真实主样板为布尔差集：
  $$\Omega_{	ext{front\_final}} = \Omega_{	ext{front}} \setminus \Omega_{	ext{cutout}}$$

```
  +--- O(0,0) ---------- P1 (腰缝断点) -------+  ---
  |      \    [被挖除区域]  / |                 |    |
  |       \   Ω_cutout     /  | 主线 C(t)       |    |
  |        \              /   | 实际切削        |    +-- 原始前大片
  |         +--- P2 -----+----+ C_cut(t)        |        Ω_front
  |         |                                   |    |
  |         |  有效前身大片样板                   |    |
  |         |  Ω_front_final                    |    |
  +---------+-----------------------------------+  ---
```

### 3. 袋布贴与底袋计算 (Facing & Pouch Topology)

#### (1) 前口袋袋贴绘制几何算法 (Pocket Facing Generation)
袋贴（Facing，又称袋贴布）作为表布裁片附着于底袋布上，用于遮盖袋口挖空区域，避免露出内衬袋布。其几何轮廓根据是否有腰省及内边生成模式自适应计算：

* **特征端点定位**：
  * **袋贴腰头顶点 $P_{	ext{facing\_waist}}$（即代码中 $P_{	ext{fw}}$）**：
    * **有省量**：自口袋省顶点 $P_1'$（即实际切削起点 $C_{	ext{cut}}(0)$）沿腰头线（腰弧）朝前浪顶点方向量取腰头端袋贴宽 $w_{	ext{waist}}$（`facing_width`）；
    * **无省量**：自袋口腰头顶点 $P_1$（即设计母线起点 $C(0)$）沿腰头线（腰弧）朝前浪顶点方向量取腰头端袋贴宽 $w_{	ext{waist}}$。
  * **袋贴侧缝顶点 $P_{	ext{facing\_side}}$（即代码中 $P_{	ext{fs}}$）**：
    * 自口袋侧缝顶点 $P_2$ 沿外缝弧向下量取侧缝端袋贴宽 $w_{	ext{side}}$（`facing_side_w`，未指定时默认 $w_{	ext{side}} = w_{	ext{waist}}$）。
* **基准参考线 $C_{	ext{ref}}$ 判定**：
  * **有省量**：以含省实际切削线 $C_{	ext{cut}}(t)$ 为基准；
  * **无省量**：以口袋净线 $C(t)$ 为基准。
* **袋贴内边缘形态模式 ($L_{	ext{facing\_inner}}$)**：
  支持三种内边缘生成策略（通过 `facing_mode` 配置）：
  1. **两端垂直式 (`tangent`，打版师推荐模式)**：
     * 腰端点 $P_{	ext{fw}}$ 处切线严格垂直于腰弧切线，侧缝端点 $P_{	ext{fs}}$ 处切线严格垂直于外缝弧切线（切线方向均指向裤身内侧）；
     * 曲线由三次贝塞尔曲线构建，形状与丰满度由两端切线柄长 $h_1, h_2$（`facing_h1`, `facing_h2`）精确控制：
       $$L_{	ext{facing\_inner}} = 	ext{CubicBezier} ig(P_{	ext{fw}},\, P_{	ext{fw}} + h_1 \cdot  ec{N}_{	ext{waist}},\, P_{	ext{fs}} + h_2 \cdot  ec{N}_{	ext{side}},\, P_{	ext{fs}} ig)$$
     * **制版优势**：保证裁片拼缝边缘无尖角、起翘与“狗耳（Dog-ears）”，缝合过渡平顺。
  2. **法向偏置式 (`offset`)**：
     * **Bézier 曲线模式**：内部控制点按其影响峰位（$t=1/3, 2/3$）沿基准线内法向 $ ec{N}(t)$ 偏置 $w_{	ext{waist}}$，两端点精确锁定到 $P_{	ext{fw}}$ 与 $P_{	ext{fs}}$ 以保证闭合拓扑：
       $$p_{1,	ext{off}} = C_{	ext{ref}}(p_1) + w_{	ext{waist}} \cdot  ec{N}(1/3), \quad p_{2,	ext{off}} = C_{	ext{ref}}(p_2) + w_{	ext{waist}} \cdot  ec{N}(2/3)$$
       $$L_{	ext{facing\_inner}} = 	ext{CubicBezier} ig(P_{	ext{fw}},\, p_{1,	ext{off}},\, p_{2,	ext{off}},\, P_{	ext{fs}} ig)$$
     * **Polyline 折角模式**：将基准折角链各中间折角顶点沿弦法向向裤身内侧平移 $w_{	ext{waist}}$，端点锁至 $P_{	ext{fw}}$ 与 $P_{	ext{fs}}$，形成逐段平行的多段折线。
  3. **弧高浅弧式 (`bulge`)**：
     * 直接过 $P_{	ext{fw}}$ 与 $P_{	ext{fs}}$ 构造三次贝塞尔浅弧，由弧高（`facing_bulge`）和弧顶分位参数（`facing_bulge_at`）控制饱满度与曲率。
* **袋贴裁片闭合拓扑 ($\Omega_{	ext{facing}}$)**：
  由以下三段边缘逆时针/顺时针闭合构成完整袋贴多边形裁片：
  $$\Omega_{	ext{facing}} = 	ext{ClosedLoop}\Big(	ext{腰弧段 } [O 	o P_{	ext{fw}}] \;\cup\; L_{	ext{facing\_inner}} \;\cup\; 	ext{外缝弧段 } [P_{	ext{fs}} 	o O]\Big)$$
  *(其中原点 $O$ 在弯腰头时取下侧缝腰点 $B'$，直腰头时取腰外缝顶点 $B$)*

#### (2) 防翻吃边与储物袋布
* **防翻吃边 (Edge Ease)**：在前大片曲线 $C_{	ext{front}}(t)$ 计算弧长时，比贴布曲线 $C_{	ext{facing}}(t)$ 缩减 $\Delta S_{	ext{ease}} = -3.5	ext{ mm}$。
* **底部储物袋布**：以侧缝下切线延伸点为起始，闭合生成 `SLANTED_ROUND` / `SQUARE_BOX` 形态多边形。

## 四、 分支 B：表面外贴式管线 (Patch Pipeline)

此策略适用于 70s 复古阔腿裤贴袋、贝克军工装袋（Baker/Fatigue Pocket），核心特点为 **前片完全不裁切，样板独立生成叠加**。

### 1. 前大片零裁剪与样板定位印标记 (Intact Front Panel & Marking)
* **前大片保持完整**：$$\Omega_{	ext{front\_final}} = \Omega_{	ext{front}} \quad (\Omega_{	ext{cutout}} \equiv \emptyset)$$
* **表面定位点 (Drill Holes / Placement Lines)**：程序在 $\Omega_{	ext{front\_final}}$ 图层上方直接打印外贴边界参考多边形 $M_{	ext{placement}} = P_1 	o C(t) 	o P_2$。

---

### 2. 贴袋独立样板外向拓展 (Patch Pocket Pattern Hemming)
贴袋为独立裁片，**独立定位**（与 INSET 锚点解耦）：袋口外上角 = 自有效腰口的侧缝腰点 $O$ 垂直向下 `top_drop`、水平向内 `top_inset`（弯腰头取**下侧缝腰点 $B'$**、直腰头取腰外缝顶点 $B$，见 §二 弯腰头情形）；袋口宽 `width` 向内量取、袋身高 `height` 向下量取。净形三种形态（§五 `net_outline_type`）：
* **RECTANGLE 方底**：四边形；
* **BAKER_SHIELD 盾形尖底**：底边换为底中尖点（额外加深 `tip_depth`）的五边形；
* **ANGULAR 底角斜切**：两底角各斜切 `chamfer` 的六边形；
* **CUSTOM 全自定义**：角点列表 `custom_points`（相对锚点的 dx/dy，顺时针）+ 每边形态 `custom_edges`（(弧高, 弧顶位置)，弧高 0 = 直线，正值沿左手法向凸）。

补充控制参数（各形态通用）：
* **袋底宽 `bottom_width`**（BAKER_SHIELD / ANGULAR）：0 = 与袋口同宽，否则底边两侧对称内收；
* **整体旋转 `rotate_deg`**：绕袋口外上角旋转（顺时针为正），用于调整贴袋摆放角度。
贴袋本体为独立单层/双层裁片，以母线 $C(t)$ 为净尺寸（Net Outline），需向外部添加扣向底侧的包缝与反折缝量。**（实现注记：本工程先画后裁，缝份与缩水不在绘制阶段添加，裁片分离后由裁切层统一外拓。）**

* **左右底缝拓展量 (Side/Bottom Hemming, $d_{	ext{side}} = 12	ext{ mm}$)**：
  $$L_{	ext{patch\_side}}(t) = C(t) - d_{	ext{side}}  ec{N}(t)$$
* **上方袋口折贴量 (Top Opening Fold Allowance, $d_{	ext{top}} = 30	ext{ mm}$)**：
  对原线段顶部沿垂直向上平移生成厚大扣折边，用于内部明线折边车压。

## 六、 输出图层规范 (Standard Output Layers)

最终生成的 CAD DXF / SVG 样板必须按照标准图层分别承载两类拓扑：

* `Layer 01_FRONT_PANEL`: 有效前身大片（INSET 表现为被挖除后；PATCH 为完整大片）
* `Layer 02_STITCH`: 明线、打结及定位标记印（Drill/Placement lines）
* `Layer 03_FACING_OR_PATCH`: 袋口贴布（INSET）或独立贴袋裁片（PATCH）
* `Layer 04_POUCH`: 内部纯棉/化纤储物袋布大片（仅 INSET 需要）
