# 牛仔裤打板：直裆深（立裆深）推导公式与结构控制指南（纯结构/不含缩率版）

## 一、 核心概念：直裆深（垂直线）与前浪（弧线）的区别

在牛仔裤（Jeans）结构打板中，直裆深（立裆深）直接决定了裤子的腰位高低、小腹平整度以及坐立时的裆部舒适度。在平面网格定线时，必须严格区分**直裆深**与**前浪**：

1. **成品规格先行原则（不含缩率）：** 本指南所有公式与计算均基于**洗后成衣/成品目标规格（Finished Spec）**。打板时暂不揉入水洗缩率，确保网格几何逻辑直观清晰，待结构完形后再统一加算放大。
2. **直裆深（垂直高度/作图基准）：** 沿裤中线（或垂直基准线）从腰头水平线向下垂直量取至横裆线的 **$90^\circ$ 垂直距离**。
   * **公式推导得出的数值 100% 为直裆深（垂直线）。**
3. **裤片净直裆：** 
   $$\text{裤片净直裆} = \text{含腰总直裆深} - \text{腰头宽度}$$
   *（此数值即为裁片前中线上从腰缝线垂直量至横裆线的实际高度）*
4. **前浪弧线长（Curved Front Rise）：** 顺着前中斜线与前小裆弯弧线测量的**缝线实际长度**。因包含前中收斜与前裆湾弧度，前浪弧线长必定大于直裆深（约大 $0.8 \sim 1.5\text{cm}$）。

---

## 二、 牛仔裤直裆深（垂直线）基于成品臀围（H）的推导公式

在牛仔网格打板时，以**成品目标臀围（Finished Hip Girth, $H$）**为基准推导垂直直裆深：

$$\text{含腰总直裆深（垂直高度）} = \frac{H}{4} + \Delta$$

### 参数详解：
* **$H$：** 洗后成衣目标臀围（已含舒适放松量）。
* **$\Delta$：** 牛仔腰位与风格修正系数。

---

## 四、 牛仔面料特性与弹力扣减规则

牛仔布的**面料弹性**对直裆深的垂直设定有极强约束：

1. **重磅无弹/原色赤耳牛仔布（13oz~16oz Rigid Denim）：**
   * **现象：** 面料无延展性，若直裆过浅，坐下时会产生严重卡裆与拔裆感。
   * **调整规则：** $\Delta$ 取上限（如 $+1.0 \sim +1.5\text{cm}$），前小裆湾与后大裆湾弧度需打得较深，预留足够的坐姿伸展空间。
2. **高弹力塑形牛仔布（Stretch Denim）：**
   * **现象：** 含有氨纶（Spandex），横纵向均可拉伸。若直裆预留过多，拉伸后会在小腹处产生横向猫须状起鼓打褶（Bunching）。
   * **调整规则：** 在公式计算基础上额外 **扣减 $-0.8 \sim -1.5\text{cm}$**，利用面料拉伸力贴合小腹，保持前浪平整。

## 五、 牛仔打板辅助校验：外缝长与内缝长倒推法

在牛仔工厂工艺单（Tech Pack）接单打板时，若客户直接提供了 **成品外缝长（Outseam）** 与 **成品内缝长/股下长（Inseam）**，可直接通过减法倒推含腰总直裆深：

$$\text{含腰总直裆深} = \text{成品外缝长（含腰 Outseam）} - \text{成品内缝长（Inseam）}$$

* **案例校验：** 若作业单标注外缝长 $102\text{cm}$，内缝长 $77\text{cm}$，则含腰总直裆深即为 $102 - 77 = 25\text{cm}$。扣除 $4\text{cm}$ 腰宽，前片净直裆垂直高度定为 $21\text{cm}$。

## 六、 完整实例计算示范（纯成品规格）

设定规格：**成品目标臀围 $H = 92.0\text{cm}$**，**牛仔工字扣弯腰宽 = $4.0\text{cm}$**。

### 案例 1：经典 501 中腰直筒牛仔裤（取 $\Delta = +1.0\text{cm}$）
1. **计算含腰总直裆深：** $\frac{92.0}{4} + 1.0 = 23.0 + 1.0 = \mathbf{24.0\text{cm}}$
2. **扣除腰宽求净直裆深：** $24.0 - 4.0 = \mathbf{20.0\text{cm}}$
3. **打板作图：** 从腰头水平线沿垂直方向向下量取 **$24.0\text{cm}$** 画平行线作为横裆线；扣除 $4.0\text{cm}$ 腰宽后，前片裁片上的垂直净高度为 **$20.0\text{cm}$**。

### 案例 2：低腰弹力修身牛仔裤（取 $\Delta = -3.0\text{cm}$，弹力扣减 $-1.0\text{cm}$）
1. **计算含腰总直裆深：** $\frac{92.0}{4} - 3.0 - 1.0 = 23.0 - 4.0 = \mathbf{19.0\text{cm}}$
2. **扣除腰宽求净直裆深：** $19.0 - 4.0 = \mathbf{15.0\text{cm}}$
3. **打板作图：** 前片裁片上的垂直净直裆高度画为 **$15.0\text{cm}$**。

## 七、 牛仔裤直裆打板实操特别注意事项

1. **弯腰（Curved Waistband）抠块处理：**
   * 牛仔裤腰头大多采用贴合胯部弧度且后腰不翘起的**弯腰**。
   * **实操画法：** 在纸样网格上**先按含腰总直裆深画出完整前片**，在腰部顺沿画出弯腰弧线后，将腰头裁片从顶部“抠下”独立打板，剩余部分即为裤片裁片。
2. **后起翘与后浪倾斜（Back Rise Slant）：**
   * 牛仔后片必须有 $3.5 \sim 5.0\text{cm}$ 的后起翘（后中缝向上抬高并向内倾斜），以补偿弯腰坐下时臀部的纵向拉伸，防止后腰露缝。
3. **低腰与高腰的裆湾弧度（Crotch Curve）：**
   * **低腰牛仔裤：** 直裆浅，前小裆湾必须画得**平缓**，否则前大裆处会严重卡裆拉扯；
   * **高腰牛仔裤：** 直裆深，前小裆湾与后大裆湾需打出**圆润的深弧度**，以贴合腹部与臀底转折。

---

## 八、 阶段性打板流程说明

1. **核对成衣规格：** 在纸样网格上直接核对成衣直裆深、内缝长、外缝长，确保 100% 匹配目标成品规格。
2. **后置加算水洗缩率：** 确认成品结构无误后，按面料实测纵向缩率 $S_v$（如 3%）与横向缩率 $S_h$（如 5%），对成品样板进行按比例放量放大（或在 CAD 软件中一键输入缩率比例），获得最终**裁剪排料样板**。
