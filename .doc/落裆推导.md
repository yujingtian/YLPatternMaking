**(Denim Jeans Back Crotch Drop: Industrial Derivation & Pattern Cheat Sheet)**

## 1. 核心公式：为什么“成品臀围 / 100”更符合工业实战？

在现代工业化牛仔裤制版与 CAD 放码（推档）中，使用 **成品臀围 / 100 + 调节量** 作为后片落裆推导公式，比传统人体净臀围或后翘比例推导更具实战优势：

1. **自带“松量”与“弹性”滤镜**：成品臀围已包含款式放松度以及弹性面料的倒扣量。款式越宽松、成品臀围越大，落裆自动增大；高弹面料款式做缩体设计时，成品臀围减小，落裆量自动减小。
2. **放码（推板）联动极好**：按 `1/100` 的等比关系，大码或小码推档时，臀围每增加 $4.0\text{ cm}$，后片落裆量会自动联动增加 $0.04\text{ cm} (0.4\text{ mm})$，底层几何逻辑自恰，放码线极度顺滑。

## 2. 核心推导公式与实战配置表

### 2.1 工业核心公式

$$D_c = \frac{\text{H}_{\text{finish}}}{100} + \Delta c$$

*   **$D_c$**：后片落裆量（后横裆大裆尖相对前横裆线下移距离，单位：$\text{cm}$）
*   **$\text{H}_{\text{finish}}$**：成品裤臀围规格（单位：$\text{cm}$）
*   **$\Delta c$**：款式与面料弹性调节量（范围：$-0.4\text{ cm} \sim +0.3\text{ cm}$）

> **💡 黄金经验法则**：**标准直筒微弹牛仔裤，后落裆 $\approx$ 成品臀围 / 100**（此时 $\Delta c = 0$）。高弹减，厚重/宽松加。

| :--- | :--- | :---: | :--- | :---: | :---: |

## 3. 结构制版与 CAD 绘图铁律

### 3.1 空间相对关系示意图

```
========================= 前横裆水平基准线 (y = 0) =========================
               |
               |                                /
 后底浪落裆线   | - - - - - - - * (后大裆尖)    /
 (y = -Dc)     |                \             /  <- 后内缝 (较前内缝长 0.6~0.9 cm,
               |                 \           /      集中在横裆至膝围段归吃)
               |                  \         /
---------------+-------------------*-------*------------------
===============+=================== 膝围线 ==============================
               |                   (前后膝围绝对等高一致，禁止联动下垂)
```

### 3.2 纸样生成操作三准则
1. **下落垂移**：根据成品臀围算得 $D_c$ 后，将前小裆尖所在的水平基准线向下平移 $D_c$，确定后大裆尖水平高度。
2. **底弧平顺**：画后浪底部弯度时，最低弧线点不可有硬折角，应平顺切入后大裆尖并过渡至内下缝。
3. **膝围不动**：**绝对禁忌——后裆尖下落时，膝围线禁止随往下移！** 前后片膝围水平线必须保持等高齐平。

## 4. 内下缝车缝工艺与防扭腿（转梁）

由于后片落裆下落，会导致后裤片内下缝（股下缝）总长比前片内下缝长 **$0.6 \sim 0.9\text{ cm}$**：

* **工序操作**：
  * **膝盖线至脚口**：前后片内缝 **1:1 严格平齐**对位车缝；
  * **大腿段（大裆尖至膝盖）**：利用后内缝斜丝绺延展特性，**把 $0.6 \sim 0.9\text{ cm}$ 的差值全部容吃在后片**（俗称“后吃前”），可配合蒸气推烫归拔。
* **物理效益**：该工艺在裤管内侧形成符合大腿向内收弧的微曲张力，是**杜绝洗水后裤腿扭转（转梁）**的核心工艺手段。

## 5. 常见结构排错清单 (Troubleshooting)

| 表现症状 | 原因诊断 | 修正指引 |
| :--- | :--- | :--- |
| **臀沟下方出现向内垂皱 (包大便皱)** | 后落裆设置过大，或 $\Delta c$ 调节正值给多 | 按公式减少 $\Delta c$ 取值 $0.3 \sim 0.5\text{ cm}$，调低落裆量 |
| **下蹲时后腰强烈受拉下滑 (扯腰/卡裆)** | 落裆量不足（$\Delta c$ 负值过大），底部容积不够 | 将 $D_c$ 恢复至至少 `成品臀围 / 100`，补充后纵向余量 |
| **穿著或洗水后内侧向前方扭转 (转梁)** | 忽略了内下缝“后吃前”工艺，前后缝1:1直接硬缝 | 检查膝围以上两缝线长差值，车缝时确保容位于后内缝 |
