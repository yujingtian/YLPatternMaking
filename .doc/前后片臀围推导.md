# 牛仔裤及裤装臀围结构与前后片分配推导指南

在裤装结构制板（特别是牛仔裤）中，臀围（Hip Circumference）是决定裤子穿着合体度、舒适度以及侧缝垂直度的核心部位。本文系统梳理裤装臀围的结构推导逻辑、数学公式、前后片分配调节量（$\Delta$）的确定依据，以及制板实操中的微调方法。

---

## 一、 核心原理与结构组成

裤装臀围处的横向展开总尺寸由两部分构成：

$$\text{底裆横向总宽} = \text{基础臀围片宽（臀围线宽）} + \text{裆宽伸出量（小裆宽 / 大裆宽）}$$

1. **前后片“后大前小”原则**：
   人体后侧有臀大肌凸起，腹部相对平坦，因此后片的臀围分配量及裆弯伸出量均需大于前片。
2. **侧缝垂直原则**：
   前后片臀围分配的极差直接决定侧缝（Outseam）的位置，合理的分配量能确保侧缝线呈铅锤线垂直于地面。

---

## 二、 符号与变量定义

| 符号 | 含义说明 | 单位 |
| :--- | :--- | :--- |
| $H$ | 成品臀围（含放松量 / Ease Allowance） | cm |
| $H_{\text{前}}$ | 单侧前片臀围线净宽 | cm |
| $H_{\text{后}}$ | 单侧后片臀围线净宽 | cm |
| $\Delta$ | 前后片臀围分配单侧调节量（调节因子） | cm |
| $W_{\text{小裆}}$ | 前小裆宽（前裆弯伸出量） | cm |
| $W_{\text{大裆}}$ | 后大裆宽（后裆弯伸出量） | cm |

---

## 三、 臀围公式推导过程

### 1. 基础臀围线宽分配公式

设定单侧前后片的调整极差量为 $\Delta$，即前片减去 $\Delta$，后片加上 $\Delta$：

$$\begin{cases}
2 \cdot H_{\text{前}} + 2 \cdot H_{\text{后}} = H \\
H_{\text{后}} - H_{\text{前}} = 2\Delta \quad (\text{单侧前后片之差})
\end{cases}$$

解此方程组得：

- **单侧前片臀围线宽**：
  $$H_{\text{前}} = \frac{H}{4} - \Delta$$

- **单侧后片臀围线宽**：
  $$H_{\text{后}} = \frac{H}{4} + \Delta$$

---

### 2. 裆弯伸出量（小裆与大裆）推导

裆宽用于容纳人体腿根部及臀部下缘厚度：

- **前小裆宽（$W_{\text{小裆}}$）**：
  取前片臀围的 $1/10$ 或总臀围的 $1/20$，可叠加手工修正量 $a_{\text{小}}$：
  $$W_{\text{小裆}} = \frac{H}{20} + a_{\text{小}} = 0.05 H + a_{\text{小}}$$
  *(紧身牛仔裤实操中常修正为 $a_{\text{小}} = -0.5 \sim -1\text{ cm}$；程序化录入对应 `front_crotch_adjust`)*

- **后大裆宽（$W_{\text{大裆}}$）**：
  取总臀围的 $1/10$，或约为小裆宽的 $2 \sim 2.5$ 倍，可叠加手工修正量 $a_{\text{大}}$：
  $$W_{\text{大裆}} = \frac{H}{10} + a_{\text{大}} = 0.10 H + a_{\text{大}}$$
  *(坐姿伸展需加深裆弯时 $a_{\text{大}}$ 取正；程序化录入对应 `back_crotch_adjust`)*

---

### 3. 横向总宽度汇总

| 裁片部位 | 横向总宽推导公式 | 构成解读 |
| :--- | :--- | :--- |
| **前片底裆横向总宽** | $$\left(\frac{H}{4} - \Delta\right) + \frac{H}{20}$$ | 前片基础臀围宽 + 前小裆宽 |
| **后片底裆横向总宽** | $$\left(\frac{H}{4} + \Delta\right) + \frac{H}{10}$$ | 后片基础臀围宽 + 后大裆宽 |

---

## 四、 调节量（$\Delta$）的确定依据

前后片分配调节量 $\Delta$ 并非固定常数，而是依据以下四个维度综合确定：

### 1. 人体体型（臀凸度与性别）
- **女性标准体**：臀腰差大、臀部凸起明显，$\Delta$ 取 **$1.0\text{ cm}$**（前后极差 $2\Delta = 2.0\text{ cm}$）。
- **女性翘臀/丰满体**：$\Delta$ 可加大至 **$1.2 \sim 1.5\text{ cm}$**。
- **男性体型**：臀部较平坦、骨盆窄，$\Delta$ 取 **$0.5 \sim 0.75\text{ cm}$**。

### 2. 面料弹力与延伸性
- **无弹重磅牛仔（100% Cotton）**：无拉伸空间，结构需严格拟合人体，$\Delta$ 保持在 **$0.8 \sim 1.0\text{ cm}$**。
- **微弹面料（含 1%~2% 氨纶）**：$\Delta$ 取 **$0.5 \sim 0.8\text{ cm}$**。
- **高弹/超弹面料（含 3% 以上氨纶）**：面料靠张力包裹人体，$\Delta$ 可缩减至 **$0 \sim 0.5\text{ cm}$**。

### 3. 版型风格与放松量（Ease）
- **紧身/合体版型（Skinny/Slim）**：放松量小，精确定位至 $\Delta = 0.8 \sim 1.0\text{ cm}$。
- **宽松/工装/阔腿版型（Loose/Cargo）**：整体空间大，人体臀凸被超大放松量吸收，$\Delta$ 缩小至 **$0 \sim 0.5\text{ cm}$**（甚至平分 $\frac{H}{4}$）。

### 4. 常见版型调节量（$\Delta$）对照表

| 版型 / 面料分类 | 单侧调节量 $\Delta$ | 单侧极差 ($2\Delta$) | 适用场景说明 |
| :--- | :--- | :--- | :--- |
| **标准女装西裤 / 无弹牛仔** | **$1.0\text{ cm}$** | **$2.0\text{ cm}$** | 经典工业制板标准经验值 |
| **女性翘臀高腰牛仔裤** | **$1.2 \sim 1.5\text{ cm}$** | **$2.4 \sim 3.0\text{ cm}$** | 配合大后翘与深裆弯 |
| **标准男装直筒牛仔裤** | **$0.5 \sim 0.75\text{ cm}$** | **$1.0 \sim 1.5\text{ cm}$** | 贴合男体平臀特征 |
| **高弹力紧身女牛仔裤** | **$0.3 \sim 0.5\text{ cm}$** | **$0.6 \sim 1.0\text{ cm}$** | 靠弹力补充空间 |
| **超宽松阔腿裤 / 工装裤** | **$0 \sim 0.5\text{ cm}$** | **$0 \sim 1.0\text{ cm}$** | 可直接按 $\frac{H}{4}$ 平分 |

## 五、 试衣检验与样板动态修正

在白胚布试样或 CAD 样板检查中，可通过以下现象检验 $\Delta$ 是否合理：

1. **侧缝位置检验**：
   - **侧缝垂直落向地面** $\Rightarrow$ $\Delta$ 设定正确。
   - **侧缝向后臀倾斜/拉扯** $\Rightarrow$ 后片偏小，需**增大 $\Delta$**。
   - **侧缝往前腹方向偏移** $\Rightarrow$ 后片偏大，需**减小 $\Delta$**。

2. **拉痕与褶皱诊断**：
   - **后臀有水平拉紧横纹，前腹偏松** $\Rightarrow$ **增大 $\Delta$**。
   - **前腹有横向紧绷拉痕，后臀起褶** $\Rightarrow$ **减小 $\Delta$**。

---

## 六、 牛仔裤特有结构微调（Yoke 与后立裆）

1. **后立裆倾斜（后翘）补偿**：
   牛仔裤后斜线进进量（$2 \sim 3.5\text{ cm}$）和抬高量（后翘 $3 \sim 4.5\text{ cm}$）较大。量取后片臀围线时，需**垂直于后立裆斜线**进行测量，并适当增加 $W_{\text{大裆}}$ 或提升 $\Delta$ 补偿横向投影面积的损失。
2. **后约克（Yoke）拼接检查**：
   牛仔裤之后约克取代了腰头省道。推导和校验后片臀围时，必须将后片与 Yoke 闭合拼合后再检查臀围线条的顺滑度与总尺寸。
