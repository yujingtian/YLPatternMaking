# 牛仔裤毗围与立裆深线参数化推导规范

## 一、 核心计算公式汇总

在自定义下移量 d 的测量标准下，生成前、后片零位立裆深（0 cm 处）基准控制框的核心推导表达如下：

W_f0 = (T / 2 - x) + d * (tan(α_f) + tan(β_f))
W_b0 = (T / 2 + x) + d * (tan(α_b) + tan(β_b))
L_b = sqrt(W_b0^2 - d_drop^2)

---

## 二、 算法输入参数与符号定义

| 参数符号 | 物理含义 | 系统默认值 / 示例 | 备注说明 |
| :--- | :--- | :--- | :--- |
| **T** | 成衣成品大腿围总周长 (Thigh) | 实际工单给定 | 包含前片与后片宽度之和 |
| **x** | 前后单片脾围分配调拨量 | **2 cm** | 前片单面 -x，后片单面 +x |
| **d** | 自定义测量下移深度 | **2.54 cm** (1 inch) | 立裆深线向下的实测偏移距离 |
| **d_drop** | 后大裆尖下移量 (落裆深) | **1 cm ~ 1.5 cm** | 适应人体后臀肌下拉伸量的参数 |
| **α, β** | 内、外侧缝向下收窄倾斜角 | 前/后独立输入 | 可根据中裆比率转为线性收缩率 |

---

## 三、 前片 (Front Panel) 精确制图坐标推导

前片无落裆设定，立裆深水平线与前横裆宽重合。算法直接从下移位置 d 处的已知尺寸，逆推 0 cm 顶点的理论框宽。

### 1. 推导与转化公式
* **目标下移处前单片宽 (W_fd)**：
  W_fd = T / 2 - x
* **零位立裆深线目标宽度 (W_f0)**：
  W_f0 = W_fd + d * (tan(α_f) + tan(β_f))
* **中裆比率插值法（无需三角函数）**：
  设从立裆深到膝围线高度为 H_knee，外、内侧缝共计收缩常数为 Δ_total：
  W_f0 = W_fd + Δ_total * (d / H_knee)

### 2. 前片关键控制点输出
* **外侧缝腰侧端点 X 坐标**：0.0（设定为原点参考轴）
* **前裆尖极限点 X 坐标**：W_f0

---

## 四、 后片 (Back Panel) 降维映射与勾股推导

后片需同时满足“下移实测补偿 d”与“后落裆斜边勾股转化 d_drop”。系统通过两次形态变换完成平面纸样坐标锚定。

    (0,0) 外侧缝映射交点 L_b            原立裆深水平轴 (Y=0)
      +------------*-----------------------------+
      |             \                            |
      |              \ 实际纸样横裆宽             | 落裆深 d_drop
      |               \ (定长斜边 W_b0)          |
      |                \                         v
      |                 +------------------------* 后裆尖顶点 (Y = -d_drop)

### 1. 核心公式变换
* **下移实测处后单片宽 (W_bd)**：
  W_bd = T / 2 + x
* **含内收补偿后的后横裆斜边总长 (W_b0)**：
  W_b0 = W_bd + d * (tan(α_b) + tan(β_b))
* **后外侧缝水平映射 X 坐标 (L_b)**：
  运用勾股定理求出与水平基准轴的实际截距，避开繁琐的角度旋转补偿：
  L_b = sqrt(W_b0^2 - d_drop^2)

### 2. 后片关键控制点输出 (以右侧后裆尖为正向)
* **后底裆尖坐标 (Crotch Bottom Point)**：(W_b0, -d_drop)
* **后外侧缝落点坐标 (Outseam Level Point)**：(W_b0 - L_b, 0.0)
* **实际裁片连接斜边长**：sqrt(L_b^2 + d_drop^2) == W_b0
