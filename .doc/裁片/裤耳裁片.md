# 牛仔裤裤耳（袢仔）裁片绘制指南

## 1. 裁片基本信息
* **部件名称：** 裤耳 / 裤袢 (Belt Loop)
* **裁剪数量：** 1条/件（整条裁剪，车缝时再由工人剪断）
* **工艺说明：** 根据指定款式要求，此款裤耳为**无缝边（毛边/不折边）**设计，无需预留卷边和折边量。

## 2. 尺寸计算与绘制
由于不需要预留折边和缝边，裁片的尺寸计算即为成品净尺寸的集合，直接绘制一个长条长方形：

* **宽度：** = **成品净宽度**
  *(例如：要求裤耳成品宽为 1.2cm，则裁片宽度直接绘制 1.2cm，不加任何缝份)*
* **长度：** = **单根成品长度 × 裤子所需裤耳总根数（通常为5根） + 适当损耗**
  *(例如：单根成品长 6cm，共需 5 根，6cm × 5 = 30cm。加上2-3cm的裁剪与机器操作损耗，绘制 32cm 或 33cm 的总长)*

**裁片形状：** 绘制一个完整的 【成品净宽度 × 总长度】 的大长方形。

## 3. 经纬向（布纹线）设置
* **丝缕方向：** 直丝缕（经向）
* **排版参考：** **直接参考前裤片和后裤片的整体经向方向。**
* **原理说明：** 裤耳的布纹线方向必须与前后裤片的主体经向保持一致。这不仅确保了裤耳在承受腰带拉力时具有足够的纵向结构强度，更重要的是，在牛仔面料后续的水洗、摩擦和做旧工艺中，能够保证裤耳的表面落色纹理、纱线缩水率与裤子大身完全协调一致，避免出现拼接部位的纹理冲突。

## 4. 裁片内部标记要求
在纸样（或CAD文件）上绘制完成后，需在裁片内部添加以下标准标记，以便裁剪和生产部门识别：
1. **款号/部件名称：** 裤耳 / Belt Loop
2. **裁剪数量：** 共裁 1 条 (Cut 1)
3. **布纹线符号：** 绘制双向箭头 ↕，确保排料时箭头方向与前后片直丝平行。
4. **工艺备注：** 醒目标注“净裁”、“毛边”或“不折边”，提醒裁剪和车位无需做卷边处理。
