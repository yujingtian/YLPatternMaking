# 牛仔裤前片独立裁片程序化提取逻辑规范

本文档旨在梳理和规范通过CAD程序化算法，从牛仔裤打版全局图稿中分离并生成**前片独立裁片**的核心逻辑与处理步骤，可直接作为开发人员的业务逻辑参考文档。

## 1. 结构剥离与轮廓闭合提取

程序在获取打版基础线条后，需遵循以下顺序进行轮廓的识别、打断与闭合提取：

### 1.1 弯腰头分离判定
* **业务逻辑**：在连身打版模式下，前片上部常与弯腰头相连。
* **程序动作**：检测前片顶部是否与腰头结构连通。若为连通状态，程序需定位腰头底端拼接线，以此为切割路径，将弯腰头区域从前片主体中剥离，确保分离出的前片顶端线条为实际的装腰接缝线。

### 1.2 嵌入式挖削口袋处理
* **业务逻辑**：根据口袋款式的不同，提取路径需要动态调整。
* **程序动作**：
  * **存在口袋省**：程序需读取口袋省弧线路径，以此弧线作为边界，将前片中对应的口袋区域“挖掉”（执行布尔减法操作）。
  * **无口袋省**：程序直接读取常规的口袋开口弧线作为切割边界进行挖除。

### 1.3 门襟（连裁/断裁）判定
* **业务逻辑**：确定门襟是独立裁片还是与前片一体。
* **程序动作**：若属性标记为“连裁门襟”，程序必须将门襟的外部轮廓线与前片前中线及相关轮廓线进行合并提取，确保输出的闭合多边形包含完整的门襟延伸部分。

## 2. 缝边偏移与工程细节处理 (Seam Allowance & Engineering Details)

基础轮廓闭合后，程序需向外偏移生成缝边，并处理关键转角与对位标记。

### 2.1 边缘独立缝宽参数化控制 (Parameterized Seam Width)
* **业务逻辑**：前片四周的缝合工艺各不相同（如侧缝、下裆缝、装腰缝、裤口卷边等），所需的缝边宽度也必然不同。
* **程序动作**：系统必须支持**按线段（边缘）独立设置缝边宽度参数**。算法在执行外偏操作时，需能够读取每条边缘的缝宽属性（如前浪缝1cm、侧缝1.5cm、裤口折边2.5cm等），生成不等宽的缝边，并自动处理相邻不同缝宽线段在交角处的连贯过渡与打角。

### 2.2 前浪浪尖折角生成与参数控制 (Crotch Point Corner Treatment)
* **定位点**：前浪弧线底端与下裆缝（内侧缝）的交汇极点。
* **程序动作**：在此处生成外偏缝边时，需提供一个**参数开关（如：`enable_crotch_corner = True/False`）**供打版师控制：
  * **开启状态（默认）**：算法计算并生成向外凸出的**折角（反转角/镜像角）**，以补偿缝份翻折后的长度差，防止内部“缺肉”，保证厚重面料包缝/埋夹时的受力余量。
  * **关闭状态（纯尖角跟随净样）**：薄面料或包边等工艺不做外凸折角，缝边角部与净样轮廓形态完全一致——两侧缝边各自按**贝塞尔多项式自然外延**（point_at/tangent_at 对 t∉[0,1] 照公式求值，延续曲线自身的张力与曲率），外延偏移链求首个交点成尖，裆尖呈锐利尖角；直线边沿轴向延伸（即切线 miter）。不做任何圆弧抹角、不受尖角限长约束（限长回退的阶梯角会留台阶断点、不圆顺）（2026-08 定稿：等距弧/大圆弧/相切圆角等圆弧抹圆形态全部废除——净样裆尖是尖的，缝边只能是尖的；切线 miter 拉直段亦废除，最终定为多项式自然外延求交）。

### 2.3 关键对位刀口 (Notches) 的提取与生成
* **业务逻辑**：刀口是车缝工序中前后片拼合、辅料定位的核心参照物，提取独立裁片时绝不能遗漏，必须精准映射到最终裁片边缘。
* **程序动作**：
  1. **继承与延伸投影**：程序需扫描打版全局图纸，识别属于前片的刀口属性点。在生成外围缝边后，程序必须将原净样轮廓线上的刀口**垂直（或沿法线方向）延伸投影**到最终放出的缝边外沿线上。
  2. **刀口类型映射**：根据全局设定的刀口类型（如 I型剪口、V型缺口、U型等），在裁片外沿生成对应的刀口几何图形。
* **关键应用位置**：
  * **防扭脚对位**：侧缝与下裆缝上的**膝围线刀口**（必须绝对精准）、臀围线刀口。
  * **工艺定位**：门襟区域的拉链止口位刀口、腰部/侧缝的口袋开口上下端对位刀口、前中装腰对位点等。
  * **裤口线定位刀口**：下摆卷边/折边的起折点对位刀口（明确标示卷边高度），以及侧缝/下裆缝与裤口线交汇处的缝合对位刀口。

## 3. 全局参数映射与后处理 (Post-Processing)

### 3.1 经纬向（纱向）继承
* **程序动作**：读取打版全局设定的基准经纬线向量，并强制映射至新生成的前片独立裁片上，确保排料和裁剪时纱向正确，防止成品扭脚（拔缝）。

### 3.2 缩水率与裁片特性差异化应用
* **主面料（前片主体）**：读取牛仔面料的经纬向缩水率参数（如X: 2%, Y: 3%），对前片轮廓应用相应的缩水形变放码。
* **辅料特例（口袋布）**：牛仔裤口袋布和裤子主材料不一样，程序在提取此类辅料裁片时，**不进行任何缩水率计算与放大**，仅需按照标准逻辑生成其自身的**缝边**与对位**刀口**。

### 3.3 内部辅助线 (Internal Lines) 的映射与绘制
* **业务逻辑**：内部辅助线（如臀围线、毗围线/横裆线、膝围线）不仅是打版参考，更是后续生产中水洗定位（如猫须位置）、对格对条、后整熨烫及排版识别的重要依据。
* **程序动作**：程序需从全局图稿中提取贯穿前片的结构辅助线，包括：
  * **臀围线 (Hip Line)**
  * **毗围线 / 横裆线 (Thigh Line / Crotch Line)**（如全局存在）
  * **膝围线 (Knee Line)**
  * **算法处理**：以剥离后的前片净样轮廓为边界，利用布尔交集（或线段裁剪算法），将这些无限或全局辅助线裁剪截断，保留前片裁片范围内的线段，并以“内部线 (Internal Line)”的属性吸附在独立裁片上。同时，在施加缩水率时，这些内部线需跟随主裁片发生同等比例的几何变换。
