## 一、 模块概述

本文档整合了**直腰头**与**弯腰头（涵盖有省/无省）**完整裁片的程序化生成逻辑。
遵循系统的「先画后裁（Draft-then-Cut）」核心原则：直腰头从整版提取净长后**代数求和**成矩形；弯腰头把前后腰弧**真实几何拼合**（ET 手工流程：前后腰头侧缝拼合 → 后中轴对称 → **整根修成一条顺弧**——可以改变弧的形状、保持拼合的弯曲走势）后作为裁片轮廓，并精准打上边界刀口。最终由 `Cutter` 模块按严格的工艺顺序（净样提取 → 经纬向缩水应用 → 独立缝边外扩）输出独立的 `PatternPiece`。

## 二、 参数扩展 (`params/`)

为了支持腰头的形态控制、缩水处理以及精细化缝边，需要在 `PatternOptions` 中扩展以下参数：

```python
# 1. 形态与结构参数
waistband_type: str = "straight"         # "straight" 直腰头 / "curved" 弯腰头
waistband_width: float = 4.0             # 腰头宽度 (cm)
waistband_fly_extension: float = 3.5     # 门襟搭门量/宝剑头长度 (通常在左侧)
waistband_full_piece: bool = True        # True=输出完整一条，False=沿后中线分两片
waistband_grain: str = "width"           # 腰头经向方向：'width' 宽向(=裤长)为经(默认,横裁) / 'length' 长向为经(直裁)

# 2. 缩水参数 (Shrinkage) —— 经/纬为面料物理方向；映射到腰头 X/Y 轴由 waistband_grain 决定
shrinkage_warp: float = 0.0              # 经向(warp)缩水率 (如 0.03 表示 3%)
shrinkage_weft: float = 0.0              # 纬向(weft)缩水率 (如 0.02 表示 2%)

# 3. 缝边参数 (Seam Allowances - 独立控制)
waistband_seam_allowances: dict = {
    "top": 1.0,         # 上口线缝边
    "bottom": 1.0,      # 下口线(拼接线)缝边
    "left_end": 1.2,    # 左侧端头缝边 (含门襟搭门侧，处理可能不同)
    "right_end": 1.0    # 右侧端头缝边 (常规侧)
}
```

> v0.7 删除 `waistband_front_drop`、v0.8 删除 `waistband_blend_cb/side`（圆顺窗长）：下口线形状不再参数化合成，而是真实拷贝整版前后腰弧（`front/back_waist_curve_sag` 是唯一形状来源，经拼合链净长与末切向传入均匀弧），无圆顺手感参数。`from_dict` 留一次性垫片兼容旧尺寸单（stderr 告警后丢弃）。

## 三、 数据准备：净长提取

* **直腰头（`straight`）**：维持 v0.5「代数求和」口径不变——
  * 前片净长 (`L_front`) = 门襟顶点至侧缝顶点全段弧长；后片净长 (`L_back`) = 侧缝顶点至后浪顶点全段弧长；有省时跳过省宽分段求和。
  * 半片总净长 (`L_half`) = `L_front` + `L_back`。
* **弯腰头（`curved`）**：**上腰弧真拷贝 + 省道真闭口**（提取顺序：闭省 → 拼合放置 → 投影局部系，均为刚体变换、次序可换）：
  1. 取整版 `front.waistline_arc` / `back.waistline_arc`（上腰头线，裁片顶边依据）。
  2. **闭省**（在主版坐标进行）：
     * 后省：省腿线 ∩ 腰弧（线-贝塞尔求交），绕省尖旋转远侧子链使两腿贴合；多省时同步变换后续省的腿/尖（共轭复合）。闭口即切除省口弧段——注意省口两点定义在腰头直线（弦）上，腿延到下凹的弧上后弧段略窄于省宽（二阶量 ≈ 2·sag·sin(腿半角)），这正是物理闭省口径。
     * 前口袋吃省：切点取上腰头线法足（`front.pocket_p1_top` / `pocket_p1_transfer_top`——弯腰头+吃省时 P1/P1′ 本体在下腰头线上，距上腰弧约一个腰头宽，法足才是腰头裁片的省位），切除中段后远侧刚体变换使 P1′→P1 **且切向对齐**（C1 闭口 = 吃省缝平物理口径）。
  3. **拼合放置**：前弧绕侧缝腰点旋转对齐后弧侧缝端（旋转角 = 前后真实侧缝线夹角），再**跨后片侧缝线反射**（物理平摊缝拼合；同侧旋转是退化口径）。
  4. **局部系**：原点 = 后弧后中端、X̂ = 后弧起切向（90° 法则保证 X̂ ⟂ 后中斜线 ⇒ 镜像轴 ∥ 后中缝）、Ŷ 取垂向朝下者。
  5. **整根均匀圆弧**（`curves.uniform_arc_cubic`，§四.分支B）：以链净长为弧长、链末切向角为总转角、起端切向水平（后中镜像 C2）构造均匀圆弧的三次贝塞尔表达（封闭解，无拟合）。
  6. `L_front` / `L_back` / `L_half` = **闭省后链实长**（报表/丝缕用；均匀弧弧长 = `L_half` 精确）。

## 四、 核心生成步骤 (`steps/`)

在独立的 `DraftSheet` 局部坐标系中（原点 `O(0,0)` 设为后中点，X轴向右朝前中、Y轴向下），按 `waistband_type` 执行不同绘制逻辑：

### 1. 基础轮廓绘制 (半片)

**分支 A：直腰头 (`straight`)** —— 全路径 v0.5 零改动
* 前后片裤身已在基础框架阶段扣除腰头宽。
* 直接绘制矩形：长度为 `L_half`，高度为 `waistband_width`。底边水平。

**分支 B：弯腰头 (`curved`)** —— v0.9 真拼合 + 整根均匀圆弧
* 下口线 = **一条均匀圆弧**（`curves.uniform_arc_cubic`，R = L_half/|turn|）——「保持拼合的弯曲，整个腰头一条顺滑的弧（类似抛物线）」：
  * **三锁**：弧长 = 闭省后链净长 `L_half`（缝制硬约束，精确）；总转角 = 拼合链末切向角（弯曲总量——sag/裆深/前后裆差经它传入）；起端切向恒水平（过原点切 X̂ ⇒ 后中镜像自动 C1/C2）。
  * **一匀**：曲率恒 1/R 全弧均匀——后段/前段同弯度，无集中肘弯。v0.8 拟合忠实保留拼合链「平后段+侧缝肘弯」结构（后弧 sag 垂直弦度量、局部系中主要显形为端点下落/旋转而非后段曲率——17.5cm 后段 sagitta 仅 ~0.16），后段视觉近直；v0.9 改为均匀弧后侧缝位下凹 ~3.1cm、后段中点 ~0.79（M=70/96 无省态；v0.8 同位 -0.7/+0.1）。
  * **派生量**：端点位置 = (R·sinθ, −R·(1−cosθ))——独立带状裁片端点无装配语义，净长与刀口位置才是缝制输入；均匀弧与拼合真形的中段偏差 ~1~2.5cm（ET 修顺口径：整体顺滑优先，缝纫吃势沿缝吸收）。
  * **求解**：封闭解——手柄长 h = 4/3·tan(θ/4)·R（经典圆弧贝塞尔），θ ≤ 60° 最大径向误差 < 0.01%·R；|turn| ≤ 0.5° 退化为直线。
  * sag 全量响应：sag 0.2→0.4 经总转角传入——zhitong 实参 R 106.6→86.4、端点下落 7.02→8.64、侧缝下凹 1.77→2.19（逐点最大 ~1.6cm，金标 ≥0.2）。
* 上口线 = 均匀弧沿端点法向偏移 `waistband_width`（端控制点各用端法向——端切向与下口严格平行，平移性质）；`right_end`/`left_end` 与端切向严格直角。
* 边名与直腰头同构（`wb.bottom_right` / `wb.bottom_left` / `wb.top_right` / `wb.top_left` 单名，无分段后缀）。

### 2. 打刀口（Notch 标记体系）
腰头的刀口仅标记在关键对位与边界位置，**不在上下口线中段打省位或侧缝对位刀口**：
1. **后中对位点**：在腰头的正中心（即原点 `O(0,0)` 所在的垂直线）打上刀口，用于标识后中缝位置（毛样刀口打在该垂直线与下口缝边的交点上）。
2. **左侧边界点**：
   * 在左侧**下顶点**有一个顺着腰头宽线向下的刀口，需在对应的缝边位置打上（沿着腰头宽线和缝边相交的地方）。
   * 在左侧**上顶点**有一个顺着腰头线向左的刀口，需在对应的缝边位置打上（沿着腰头线和缝边相交的地方）。
3. **右侧边界点**：
   * 在右侧**下顶点**有一个顺着腰头宽线向下的刀口，需在对应的缝边位置打上（沿着腰头宽线和缝边相交的地方）。
   * 在右侧**侧上顶点**有一个顺着腰头线向右的刀口，需在对应的缝边位置打上（沿着腰头线和缝边相交的地方）。

### 3. 对称镜像与非对称处理
1. **生成完整腰头**：若 `waistband_full_piece = True`，以 Y 轴（后中线）为对称轴，将半片轮廓及后中刀口标记完整镜像至左侧。
2. **附加搭门量**：在左片前中端沿下口线**切线方向**向外延伸 `waistband_fly_extension`（与下口线顺势顺滑相接、弯腰头随弧端斜出），封闭端点沿端点法向、与搭门边成直角（亦可改圆角/斜角宝剑头），并在此端点打上边界刀口。

## 五、 裁切输出：缩水与缝边的严密执行 (`Cutter`)

步骤层完成绘图后，在版上形成自闭合的大型轮廓及内部的刀口点。`Cutter` 必须严格按照以下顺序处理，以保证工艺精准度：

1. **净样提取 (Net Pattern)**：直接提取上述边界线组成的闭合多边形作为基础净样，刀口附着在多边形边上。cutter/pieces/exporters 对多段边零改动（同名 role 边平滑续接已支持）。
2. **应用缩水 (Apply Shrinkage)**：
   * 依据腰头设定的丝缕线方向（`waistband_grain`）确定经向映射，对整个净样几何体应用仿射变换（Scale 缩放矩阵）。经向是面料属性、全局统一（前后片丝缕线=裤中线沿裤长，即经向=裤长）：
     - `width`（默认，横裁）：腰头宽向（=裤长 Y）为经向 → `x_new = x/(1-shrinkage_weft)`、`y_new = y/(1-shrinkage_warp)`
     - `length`（直裁）：腰头长向（周向 X）为经向 → `x_new = x/(1-shrinkage_warp)`、`y_new = y/(1-shrinkage_weft)`
   * 丝缕线方向随 `waistband_grain`：`width` 画竖向（沿裤长）、`length` 画水平（沿周向）。
   * *口径（2026-08 起，除法）：缩水率以缩水前（毛坯）尺寸为基准——净样先除以 (1-率) 放大，洗水按率缩回后恰好回到净样；旧乘法 `x·(1+率)` 以净样为基准，洗后偏小约 率² 量级，已弃用。*
   * *注：缩水放大后，附着在边上的刀口坐标会自动按等比例同步偏移。*
3. **外扩缝边 (Add Seam Allowance)**：
   * 针对缩水放大后的“含缩水净样”，按 `waistband_seam_allowances` 字典分别读取上、下、左、右四边的独立参数。
   * 对各边进行不等距的外围偏移生成最终的**毛样 (Gross Pattern)**。缝份本身不叠加缩水率。
4. **格式导出**：最终将包含了缩水与缝边信息的 `PatternPiece` 输出为分层的 SVG 或对应的 DXF Block。

## 六、 推码不变量（多码 DXF 前提）

**弯/直边数同构恒 8**（下口右/左 + 上口右/左 + 两端封边 + 两搭门；fly=0 时 6——零长搭门边装配滤除），不随省数变化——闭省/拼合/均匀弧全部收敛在**单条下口弧**内，省数只改弧的形状、不改拓扑。同一 options 跨码恒定（跨码点云对应/发射点数不漂移以此为前提）。
