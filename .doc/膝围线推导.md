# 牛仔裤结构打版：膝围线（KL）推导与定位指南（纯结构/不含缩率版）

## 一、 核心推导逻辑与牛仔结构原理

在牛仔裤（Jeans）网格打版中，**膝围线（Knee Line, 简称 KL）** 是决定裤腿包覆感、下垂平顺度、水洗做旧（猫须/蜂窝）位置以及防拧腿偏针的关键基准线。

* **成品规格先行原则（不含缩率）：** 本指南所有公式与计算均基于**洗后成衣/成品目标规格（Finished Spec）**。打板时暂不揉入水洗缩率，确保几何逻辑直观清晰，待结构图完形后再统一加算放大。
* **基础测量段（成品股下长 $L$）：** 从**立裆深线（横裆线/前大裆点）** 到 **成品裤脚线** 的垂直距离，即成衣目标裤内长 $L$（Inseam）。
* **人体解剖中点：** 人体自然膝关节大致位于股下长的正中点（$\frac{L}{2}$ 处）。
* **牛仔视觉与拉长修正：** 平面打版时，若将膝围线画在正中点，穿用后视觉上会显小腿短、重心偏低。因此需将膝围线向腰部方向**向上抬高 $3.5 \sim 5.0\text{cm}$**。
* **旋转支点（Pivot Point）作用：** 在牛仔斜纹布（Twill Denim）防拧腿（Leg Twist）打板中，膝围线是下半段裤中线（丝缕线）向内/外缝偏移倾斜的**核心旋转轴线**。

---

## 二、 牛仔裤核心推导公式

在纯结构打板网格中，从**横裆线垂直向下量取**膝围线位置的计算公式如下：

$$\text{横裆线至膝围线垂直距离 } D = \frac{L}{2} - \Delta$$

### 参数详解：
* **$L$（成品股下长）：** 成衣目标裤内长（Finished Inseam Length）。
* **$\Delta$（膝围线向上抬高量）：** 修正系数，牛仔裤通用标准取值范围为 **$3.5 \sim 5.0\text{cm}$**（默认取 $4.0\text{cm}$）。

---

## 三、 经典牛仔版型实操计算案例（纯成品规格）

假设成衣目标股下长 **$L = 76.0\text{cm}$**，自横裆线向下垂直量取膝围线的计算过程如下：

### 案例 1：经典复古直筒牛仔裤（Classic Straight / 501 Fit）（取 $\Delta = 4.0\text{cm}$）
1. **计算股下中点：** $\frac{76.0}{2} = 38.0\text{cm}$
2. **向下量取距离：** $38.0 - 4.0 = \mathbf{34.0\text{cm}}$
3. **打板实操：** 从横裆线沿裤中线垂直向下量取 **$34.0\text{cm}$** 画平行线，标注为 **KL**。
   > **穿用效果：** 保证腿部活动度，膝盖后方蜂窝落色（Honeycomb）折痕自然平顺。

### 案例 2：靴型 / 微喇牛仔裤（Bootcut / Flare Jeans）（取 $\Delta = 5.0\text{cm}$）
1. **计算股下中点：** $\frac{76.0}{2} = 38.0\text{cm}$
2. **向下量取距离：** $38.0 - 5.0 = \mathbf{33.0\text{cm}}$
3. **打板实操：** 从横裆线垂直向下量取 **$33.0\text{cm}$** 画平行线。
   > **穿用效果：** 将牛仔裤最窄收腰点（Narrowest point）向上提，使从膝盖向下扩张的喇叭弧度更高，极大拉长小腿视觉比例。

### 案例 3：修身 / 紧身弹力牛仔裤（Slim / Skinny Denim）（取 $\Delta = 3.5\text{cm}$）
1. **计算股下中点：** $\frac{76.0}{2} = 38.0\text{cm}$
2. **向下量取距离：** $38.0 - 3.5 = \mathbf{34.5\text{cm}}$
3. **打板实操：** 从横裆线垂直向下量取 **$34.5\text{cm}$** 画平行线。
   > **穿用效果：** 贴合高弹牛仔面料的包裹特性，准确定位膝关节凹陷处，减少屈膝时的过度积布。

## 五、 牛仔裤平面打板实操步骤（纯结构）

1. **绘制基准横线：** 在图纸网格上准确绘制出 **横裆线（立裆深线）** 和 **成品脚口线**。
2. **定位膝围线（KL）：** 套用公式 $D = \frac{L}{2} - \Delta$，自横裆线垂直向下量取距离 $D$，画出平行线 **KL**。
3. **防拧腿（Leg Twist）偏针处理：**
   * 以 **KL 膝围线与裤中线的交点** 为旋转支点（Pivot Point）；
   * 将 KL 线以下的裤脚部分裤中线，向内缝（右斜纹 RHT 布料）偏斜 $0.8 \sim 1.5\text{cm}$；
   * 连接横裆点、膝围点与修正后的裤脚点，完成防扭腿打板。

---

## 六、 阶段性打板与缩率后置说明

1. **结构核对：** 完成纯结构图纸后，直接在纸样上核对洗后成衣目标规格（如膝围大、内缝长等），确保 100% 符合作业单（Tech Pack）要求。
2. **统一加算水洗缩率：** 确认结构无误后，按面料实测纵向缩率 $S_v$（如 3%）与横向缩率 $S_h$（如 5%），对成品样板进行按比例放量放大（或在 CAD 软件中一键输入缩率比例），获得最终**裁剪排料样板**。
