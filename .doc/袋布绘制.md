# 牛仔裤嵌入式前口袋：袋布参数化拓扑与多点路径推导规范 (Parametric Denim Pocket Pouch Architecture)

> **文档性质**：核心几何算法与袋布子系统规范  
> **设计模式**：基于「边界锚点锁定 + 内部自由节点驱动 + 两点间曲线插值控制」的拓扑算法  
> **适用范围**：牛仔裤挖削嵌入式前口袋（INSET）的储物袋布大片（连垫布）与袋布小片（连主袋口边）

---

## 一、 系统几何拓扑定义 (System Topology)

嵌入式前口袋的储物袋布（Pocket Pouch / Bag）是由**「固定组合边界」**与**「自由形态边界」**组合而成的二维封闭多边形区域：
* **固定组合边界 (Garment Seam Boundary)**：必须严密拼合在裤身腰线与侧缝线上，承担储物受力的支点与悬挂结构；
* **自由形态边界 (Free Pouch Boundary)**：悬垂于裤片内部，决定真正的储物容积、人体手部插袋工学及裁剪排版省布比。

```
                    腰缝接触锚点 P_w0
            O(0,0) +------------------+ -----------> X (向门襟中心线)
              |    |                  |
              |    |  (固定大片接触角)   |  自定义控制点 K_1 (内宽深控制)
              |    |                  |
              |    |                  +--+
     侧缝锚点  +-- P_s0                  |  线段形状：直线 / 弧高偏置 / 贝塞尔双点
      P_s0    |                           |
              |                           |
              +---------------------------+
               自定义控制点 K_n (内底深控制)    自定义控制点 K_2 (底部过渡转角)
              |
              v Y (向裤脚方向)
```

## 二、 边界基准锚点方程 (Boundary Anchor Points)

针对嵌入式前袋，系统基于主切口入口端点 $P_1(x_1, y_1)$ 和侧缝出口端点 $P_2(x_2, y_2)$，优先在样板边沿建立两颗**不可越界的基准接触锚点**：

### 1. 腰缝接触锚点 $P_{w0}$ (Waistband Anchor)
为保证袋布不从前端主切口弧线中外漏，腰缝锚点 $P_{w0}$ 必须位于前身腰弧上，且向门襟中心（正 X 轴方向）越过主袋口起端 $P_1$ 一段安全内延间距 $\Delta W_{	ext{safe}}$（推荐默认 $35\sim50	ext{ mm}$）：
$$P_{w0} = (x_{w0}, y_{w0}) = (x_1 + \Delta W_{	ext{safe}}, \, f_{	ext{waist}}(x_1 + \Delta W_{	ext{safe}}))$$

### 2. 侧缝接触锚点 $P_{s0}$ (Side Seam Anchor)
侧缝锚点 $P_{s0}$ 必须沿前身侧缝线下探，垂直间距深于口袋出口端点 $P_2$ 一段安全垂深 $\Delta H_{	ext{safe}}$（推荐默认 $60\sim100	ext{ mm}$）：
$$P_{s0} = (x_{s0}, y_{s0}) = (g_{	ext{side}}(y_2 + \Delta H_{	ext{safe}}), \, y_2 + \Delta H_{	ext{safe}})$$

## 三、 自定义内部控制点列表与线段形状插值 (Custom Internal Nodes & Edge Equations)

系统可通过传入自定义的内部特征点有序数组 $\mathbf{K} = \{K_1, K_2, \dots, K_n\}$（要求节点数 $n \ge 2$）来配置底袋容积及任何复杂造型。

### 1. 点序拓扑路由
完整的袋布外部顺时针闭合路径 $\Omega_{	ext{pouch}}$ 恒定遵从以下连线顺序：
$$\Omega_{	ext{pouch}} = P_{w0} \longrightarrow K_1 \longrightarrow K_2 \longrightarrow \dots \longrightarrow K_n \longrightarrow P_{s0} \longrightarrow O(0,0) \longrightarrow P_{w0}$$

### 2. 两点间线段形态的三种控制模式
在节点列表序列中，任意相邻两个锚点 $[A, B]$（即 $P_{w0} 	o K_1$、$K_i 	o K_{i+1}$ 或 $K_n 	o P_{s0}$），其连接路径 $L_{AB}(t)$（参数 $t \in [0, 1]$）支持三种可精确控制弧度的几何算法：

```
模式 1: 纯直截线 (LINE)
  A ========================================> B

模式 2: 服装 CAD 弧高控制法 (ARC_HEIGHT) —— 0 个外部控制点，仅需 2 个直观物理量
  A ------------------- t_peak --------------- B (弦长边 AB)
       \                  |                 /
         \     左手法向 N  | 弧高 h         /
           ---________    v           ____--
                      '-- P_peak ---''

模式 3: 三次贝塞尔双手柄法 (BEZIER_CUBIC) —— 严密操控 2 个外部控制点 (C1, C2)
  A ---------[C1 手柄]                      B
    \            \                         /
     \             \______          ______/ [C2 手柄]
      \                   '--------'     /
```

#### (1) 纯直线模式 (`LINE`)
完全不带曲线或倒角，两坐标间的基础线性欧几里得插值：
$$L(t) = (1-t)A + tB$$

#### (2) 服装 CAD 弧高控制法 (`ARC_HEIGHT`)
不依赖外部手柄坐标，基于物理裁纸工程逻辑，通过 **2 个物理参数** 确定任意弦边 $AB$ 上的二次样条弯凸：
* **弧高（Sagitta Height, $h$）**：沿线段 $ ec{AB}$ 前进方向左手法向（向袋布内部膨胀方向）的最大凸高，正值外滚、负值内缩；
* **顶点分位比（Peak Ratio, $t_{	ext{peak}} \in [0.1, 0.9]$）**：调控弧峰发生于线段前段、正中央（0.5）或靠近末尾；
* **极值坐标 $P_{	ext{peak}}$**：
  $$P_{	ext{peak}} = (1 - t_{	ext{peak}})A + t_{	ext{peak}}B + h \cdot  ec{N}_{AB}$$

#### (3) 矢量三次贝塞尔双点法 (`BEZIER_CUBIC`)
拥有 **2 个独立切线控制手柄 $C_1, C_2$**，满足高难度人体工学 S 型反拐或平角悬弓曲线要求：
$$L(t) = (1-t)^3 A + 3(1-t)^2 t C_1 + 3(1-t) t^2 C_2 + t^3 B$$
由起止夹角 $ lpha,  eta$（相对直线 $ ec{AB}$ 方向）及手柄权重 $\kappa_1, \kappa_2$（占弦长 $L_0 = \|B-A\|$ 比）推导控制点：
$$C_1 = A + \kappa_1 L_0 \cdot  ec{u}( lpha), \quad C_2 = B + \kappa_2 L_0 \cdot  ec{u}( eta)$$

## 四、 典型款型节点组合配置表 ($N=2$ 与 $N=3$)

| 款型风格分类 | 节点数量 | 关键坐标位置逻辑 | 连接线形态配置 (`mode`) | 制版美学与实际工学作用 |
| :--- | :--- | :--- | :--- | :--- |
| **基础实切工装底** | $N = 2$ | $K_1$: 居于 $P_{w0}$ 正下方<br>$K_2$: 处于侧缝下部深点 | 全部取 **`LINE`** | 方正锐利，最大程度节省布料用量，便于车床大批量快速生产 |
| **经典西部 J 型兜底** | $N = 2$ | $K_1$: 向门襟内推，深度最深<br>$K_2$: 连接侧缝起坡点 | **`ARC_HEIGHT`**<br>($h=25	ext{ mm}, t_{	ext{peak}}=0.6$) | 利用底部分段弧高，自然托托住掌心握下坠空间，手伸入流畅无缝缝阻挡 |

## 五、 袋布大片与袋布小片的分层样板推导 (Pattern Layer Split)

在实际装配缝合中，一个内衬前兜需被切分为互为镜像重贴的**袋布大片（包含袋口后方垫布背景）**与**袋布小片（与大身开袋缝缘拼接）**：

```
+-- 袋布大片 (Pouch Large / Back Bag) ----+    +-- 袋布小片 (Pouch Small / Front Bag) ---+
|  完整覆盖所有节点闭合：                   |    |  靠前侧右上边缘跟随主切口弧线 C_cut(t)     |
|  P_w0 -> K1..Kn -> P_s0 -> O -> P_w0     |    |  内部下沿路线与大片 100% 相同：           |
|  (右上侧面料外露部分充当主兜垫布底背景)     |    |  P_w0' -> K1..Kn -> P_s0' -> C_cut(t)   |
+------------------------------------------+    +------------------------------------------+
```

1. **袋布大片 ($\Omega_{	ext{pouch\_large}}$)**：
   严密覆盖前片挖除缝隙并承载表布视觉底色，连接裤顶角原点 $O(0,0)$：
   $$\Omega_{	ext{pouch\_large}} = \Omega_{	ext{pouch}}$$
2. **袋布小片 ($\Omega_{	ext{pouch\_small}}$)**：
   下端与底兜内侧序列 $\{K_1, \dots, K_n\}$ 与大片**完全 1:1 重合**，但在其右上边缘改沿 **主进袋口曲线 $C_{	ext{cut}}(t)$** （额外添加 10 mm 内翻止口缝边）闭合，两者对齐重叠合缝。

## 六.五、 实现注记 (Implementation Notes)

程序化实现（steps/front_pouch_steps.py）与本文档的口径差异：
* **P_w0 定位**：按**沿腰弧弧长**自 P1 内延 ΔW_safe（与本系统其他锚点"沿弧量取"口径一致），本文档 §二.1 的 x 坐标偏移为同向等价近似；
* **P_s0 定位**：自 P2 垂直下探 ΔH_safe 后落在**外缝链**上（高于臀围线取外缝弧，低于臀围线取大腿外缝弧，自动选择），坐标系换算：本文档 Y 向下，本系统 Y 向上（y_s0 = y_2 − ΔH_safe）；
* **节点坐标**：`front_pouch_nodes` 按本文档局部坐标系录入（O = 腰外缝顶点，x 朝门襟 +、y 向下 +），程序内部转换为全局 Y 向上坐标；
* **小片止口**：§五.2 的 10mm 内翻止口缝边按本工程"先画后裁"口径留待裁切层统一添加；
* **输出图层**（§七）：SVG 导出暂无分层机制，袋布以结构线（实线）上版。
