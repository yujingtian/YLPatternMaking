## 这份语料是什么

意图层（D1）给映射 prompt 加了规则 0：先判 `action`（adjust / recheck /
none）再谈参数。**语料是动 prompt 前的尺子**——每条给一句用户原话 + 期望
判定，审过后固化成金标：FakeVLM 按期望回放、断言 action/target/键面。

- 判 recheck 的判据：要求「再看/复查/仔细看/确认」某部位，**但没说要怎么改**；
  此时 adjustments 必空、target 填复查组名，note 说明重点复查什么（禁
  「暂不改动」式不作为表述——原症状③：「后贴袋你再仔细看看」被答成
  「暂不改动参数」）。
- 判 adjust 的判据：**方向性修改意图**（太大/太小/太凸/太浅/改成某形态…），
  有明确改动方向就走参数映射，哪怕话里带「不对」。
- 判 none 的判据：纯确认/寒暄/与版型无关，adjustments 空。
- 失败回退：意图解析失败/输出非法 → 默认 adjust（= 现状行为，天然回退）。

复查组名 7 选 1（D2 路由表）：**前口袋 / 后贴袋 / 腰头 / 育克后片 / 门襟 /
版型腰位 / 兜底**（指不清部位或整版观感 → 兜底）。组名决定取哪类照片：
前口袋/门襟取正面照，后贴袋/育克后片取背面照，腰头/版型腰位/兜底正背都取。

## 一、recheck 正例（14 条）

| # | 用户原话 | 期望 target | 判定依据 |
|---|---------|------------|---------|
| R1 | 后贴袋你再仔细看看 | 后贴袋 | 原症状句；「仔细看」无改法 |
| R2 | 后袋再确认一下形状 | 后贴袋 | 「后袋」=后贴袋口语；只确认不指定改法 |
| R3 | 口袋那里不太对，你再看看 | 前口袋 ⚑ | 「口袋」裸词默认前口袋（牛仔裤语境）；最佳猜测进 note |
| R4 | 腰头那块再看看 | 腰头 | 部位明确无方向 |
| R5 | 后育克的形状你再确认下 | 育克后片 | 「后育克」归育克后片组 |
| R6 | 门襟这里好像不太对，再仔细看看 | 门襟 | 「好像不对」+复查请求，无改法 |
| R7 | 整体版型再检查一遍 | 兜底 | 整版观感 → 兜底（全键+三类照片） |
| R8 | 这个弧线看着怪怪的，你再看看 | 兜底 | 指不清部位 → 兜底 |
| R9 | 后贴袋你再仔细看看，我总觉得哪里不对 | 后贴袋 | R1 加情绪铺垫，判据不变 |
| R10 | 再看看后片省道的位置 | 育克后片 | 「省道」归育克后片组（后片腰省） |
| R11 | 小表袋你再确认一下 | 前口袋 | 小表袋键在前口袋组 |
| R12 | 裤耳的位置再看看 | 腰头 | 裤耳键在腰头组 |
| R13 | 袋口再看看 | 前口袋 | 袋口键在前口袋组（不是后袋袋口——后袋袋口会说「后袋」）⚑ |
| R14 | 你再看看背面这张照片，袋子的形状对吗 | 后贴袋 | 疑问+复查；背面照在手 → 同轮直执行（无握手） |

## 二、adjust 正例（14 条）

| # | 用户原话 | 期望键面（最小断言） | 判定依据 |
|---|---------|--------------------|---------|
| A1 | 后贴袋太大了，改小一点 | back_patch_width step −1 | 方向明确（太大→改小） |
| A2 | 后贴袋形状不对，改成盾形 | back_patch_shape level baker_shield | **边界主例**：带「不对」但给了明确改法（盾形档）→ adjust 非recheck |
| A3a | 侧缝往前挪一点 | delta step +1 **且** waist_balance step +1（同向同幅） | A3 联动规则 5：两键同发，note 说明联动 |
| A3b | 前后片调换一下，臀部往前片挪 | delta step +1 且 waist_balance step +1 | A3 联动正例二 |
| A4 | 袋口弧线再深一点 | front_pocket_mouth_depth level deep ⚑ | 弧深档位键（shallow/standard/deep）；也可能落 front_pocket_p2_drop，见 ⚑ |
| A5 | 整体再宽松一点 | fit level loose | 整体松紧找「版型松紧」（规则 6） |
| A6 | 脚口再小一点，要小脚裤 | hem_adjust step −1 | 脚口大小调节量 |
| A7 | 后袋袋口撇势再大一点 | back_patch_top_hem_taper step +1 | 部位+方向明确 |
| A8 | 门襟做宽一点 | fly_width step +1 | 门襟宽 |
| A9 | 腰头做成弯的 | waistband_type level curved | 形态档位直给 |
| A10 | 育克再浅一点 | back_yoke_side_dist step −1（或 back_yoke_cb_dist）| 机头深度方向收浅 |
| A11 | 后省道再加长一点 | back_dart_length step +1 | 省长调节 |
| A12 | 前浪太长了，改短些 | rise_adjust step −1 ⚑ | 方向性改浪长；数值键沿当前值同向步进（规则 2） |
| A13 | 后袋往中间挪一点 | back_patch_inset_x step ±1 ⚑ | 距后浪距离；左右按版面方位（规则 4），方向待审 |
| A14 | 袋口明线再浅一点，太深了 | front_pocket_p2_drop step −1 | 「太深」+方向（浅）；重复强调不再加步 |

## 三、none 正例（5 条）

| # | 用户原话 | 判定依据 |
|---|---------|---------|
| N1 | 好的，知道了 | 纯确认 |
| N2 | 就这样，可以了 | 纯确认（交卷收尾） |
| N3 | 这个系统挺好用的 | 寒暄 |
| N4 | 明天我要去工厂一趟 | 与版型无关 |
| N5 | 我再想想，稍等 | 请求等待，无版型内容 |

none 轮 note 应说明理解到了什么（如「好的，等你」），不产生任何参数动作。

## 四、边界与反例（5 条）

| # | 用户原话 | 期望 | 判定依据 |
|---|---------|------|---------|
| B1 | 后贴袋好像不太对 | recheck / 后贴袋 | **recheck↔adjust 分界主例**：只说不适、无方向 → 复查取证，不瞎改 |
| B2 | 后贴袋是不是歪了？你再看看 | recheck / 后贴袋 | 疑问句+复查请求 → 先验证（歪只是怀疑不是结论） |
| B3 | 后贴袋歪了，帮我摆正 | adjust / back_patch_rotate_deg step −1 | 祈使句+明确动作（摆正）→ 直接改；与 B2 一词之差 |
| B4 | 腰围改 75 | none（数值走测量面）| 规则 6：尺寸数字不归映射管——S1 测量补漏接管 waist=75 |
| B5 | 后贴袋你再仔细看看，如果确实是盾形就改成方的 | recheck / 后贴袋 ⚑ | 条件改法：先取证再定改——复查先行，改法作为复查后的执行候选进 note |

## 待审要点（⚑ 汇总）

1. **R3「口袋」裸词**：默认前口袋是否合意？（备选：兜底全量复查）
2. **R13「袋口」**：归前口袋组；若用户口语里「袋口」常指后袋袋口需改判。
3. **A4 袋口弧线深浅**：档位键 front_pocket_mouth_depth（弧深伪轴）与
   数值键 front_pocket_p2_drop（袋口深浅）二选一——口语「弧线深」倾向前者，
   待打版口径定夺。
4. **A12 前浪方向性**：改短走 rise_adjust（直裆调节量）还是拒绝映射请用户
   报数（规则 6 浪长数字不归管）？本表按「方向性可改、数字不可」取前者。
5. **A13 方位词**：后袋「往中间挪」= inset_x 步进方向按规则 4 版面方位换算，
   期望步进符号待审。
6. **B5 条件改法**：复查先行、改法挂 note——还是应拆成 adjust 直接改？

## 转金标方式（审后执行）

- recheck 条 → tests/test_agent_recheck.py：FakeVLM 映射轮回放
  `{"action":"recheck","target":"…","adjustments":[],"note":"…"}`，断言
  AdjustResult.action/target、entries 清空 + dropped 披露。
- adjust 条 → tests/test_agent_adjust.py：断言期望键 ⊆ applied、action=adjust、
  绝无 cm 绝对值；A3a/A3b 额外断言两键同发同向。
- none/边界条 → 同上两文件：action 断言 + adjustments 空。
