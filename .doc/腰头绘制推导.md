# 牛仔裤前腰头参数化打版（自顶向下约束法）程序化设计文档

## 1. 概述
在传统服装纸样设计中，前腰头通常依赖“先定侧缝倾斜角度，再寻找截取点”的顺序画图，容易带来腰围线条长度不均和角度误差。

本设计文档采用**“自顶向下几何约束（Top-Down Constraint Method）”**，以“真实腰围长度 $L$”和“动态腰头抬高量 $h$”作为基本约束条件，通过解析几何反算点位坐标，确保在任何体型参数调整下，样板的腰围线长度恒定精准。

---

## 2. 坐标系建立 (Coordinate System)

以**前中垂直基础线**与**水平腰围基础线**的参考交点为坐标原点 $(0, 0)$：
* **X 轴（水平方向）：** 向右为正，向左为负（侧缝点位于 X 轴负半轴方向）。
* **Y 轴（垂直方向）：** 向上为正，向下为负。

---

## 3. 核心参数定义 (Input Parameters)

| 参数符号 | 变量名称 | 含义说明 | 默认/经验参考值 | 数据类型 |
| :--- | :--- | :--- | :--- | :--- |
| $L$ | `waist_len` | 理论单片前腰长（通过计算公式得到） | **20 cm** | Float |
| $x_{in}$ | `fc_inset` | 前中内收量 | **1.2 cm** | Float |
| $d$ | `fc_drop` | 前中下落量 | **1.0 ~ 1.5 cm** | Float |
| $h$ | `side_rise` | **侧缝腰头动态抬高量** | **0 ~ 1.5 cm** | Float |
| $l_{rect}$ | `rect_len` | 侧缝直角修正段水平延伸长度 | **1.0 ~ 1.5 cm** | Float |
| $c$ | `curve_sag` | 前腰弧线微调下凹量 | **0.3 ~ 0.5 cm** | Float |

---

## 4. 关键点位解析几何推导 (Mathematical Derivation)

### 4.1 前中腰点 A (Front-Center Waist Point)
前中腰点 $A$ 作为腰围右侧固定终点，由“前中内收 $x_{in}$”和“前中下落 $d$”直接确定：
$$A = (x_a, y_a) = (-x_{in}, -d)$$

### 4.2 侧缝腰点 B (Side-Seam Waist Point)
侧缝腰点 $B$ 的垂直高度坐标由动态参数 $h$ 直接约束：
$$y_b = h$$

基于欧几里得距离约束（点 $A$ 到点 $B$ 的直线距离恒等于腰长 $L$）：
$$(x_b - x_a)^2 + (y_b - y_a)^2 = L^2$$

由于点 $B$ 位于点 $A$ 的左侧（$x_b < x_a$），解得水平坐标 $x_b$ 的解析式为：
$$x_b = x_a - \sqrt{L^2 - (y_b - y_a)^2}$$

将坐标代入可得点 $B$ 的完整坐标公式：
$$B = \left( -x_{in} - \sqrt{L^2 - (h + d)^2},\ h \right)$$

---

## 5. 腰部曲线生成：三次贝塞尔曲线 (Bézier Curve Setup)

在 CAD 生成最终成衣裁剪线时，需确保左侧端点具有 **90° 直角展开性** 且整条腰线顺滑下凹。采用**三次贝塞尔曲线 (Cubic Bézier Curve)** 进行拟合：

* **起点 ($P_0$)：** 侧缝腰点 $B(x_b, y_b)$
* **控制点 1 ($P_1$)：** 沿侧缝展开切线方向水平向右延伸，保证直角过渡。
  $$P_1 = (x_b + l_{rect},\ y_b)$$
* **控制点 2 ($P_2$)：** 向中心线倾斜，并结合垂直下凹量 $c$ 构建弧度。
  $$P_2 = \left( x_a - \frac{L}{3},\ y_a - c \right)$$
* **终点 ($P_3$)：** 前中腰点 $A(x_a, y_a)$

> **提示：** 若算法要求“曲线本身弧长刚好等于 $L$”而非“端点距离等于 $L$”，可在计算点 $B$ 的坐标后，利用贝塞尔曲线弧长积分对 $x_b$ 向内微调收缩 **0.1 ~ 0.15 cm**。

---

## 6. 程序化计算流程 (Algorithm Flowchart)

1. **读取输入：** 接收用户或基础原型提供的 `waist_len` ($L$)、`side_rise` ($h$) 及固定制图公差。
2. **边界验证：** 验证勾股定理闭环条件，严格判定：
   $$L > (h + d)$$
   *若该条件不成立，说明参数输入异常（高度差超出斜边长），系统需抛出错误。*
3. **坐标计算：**
   * 输出 $A$ 点坐标：`A = Point(-fc_inset, -fc_drop)`
   * 输出 $B$ 点坐标：`B = Point(-fc_inset - sqrt(L**2 - (h + fc_drop)**2), h)`
4. **控制点计算：** 根据预设的 `rect_len` 和 `curve_sag` 算得贝塞尔控制点 $P_1, P_2$。
5. **绘图输出：** 渲染贝塞尔曲线 `CubicBezier(P0=B, P1=P1, P2=P2, P3=A)`。
6. **侧缝联动：** 将点 $B$ 与下方的臀围点连结，完成前片样板闭环。

---

## 7. Python 核心算法伪代码示例

```python
import math

class DenimWaistlineGenerator:
    def __init__(self, waist_len=20.0, fc_inset=1.2, fc_drop=1.3, side_rise=1.0):
        self.L = waist_len        # 腰围长
        self.x_in = fc_inset      # 前中内收
        self.d = fc_drop          # 前中下落
        self.h = side_rise        # 侧缝腰头抬高（动态参数）
        
    def get_waist_points(self):
        # 1. 计算垂直高度差
        delta_y = self.h + self.d
        
        # 2. 异常捕获：检查几何关系是否成立
        if delta_y >= self.L:
            raise ValueError("侧缝抬高量过大，无法在合理空间内构成腰线。")
            
        # 3. 计算坐标
        x_a = -self.x_in
        y_a = -self.d
        
        delta_x = math.sqrt(self.L**2 - delta_y**2)
        x_b = x_a - delta_x
        y_b = self.h
        
        point_A = (round(x_a, 4), round(y_a, 4))
        point_B = (round(x_b, 4), round(y_b, 4))
        
        return {
            "Point_A_FrontCenter": point_A,
            "Point_B_SideSeam": point_B,
            "Horizontal_Span": round(delta_x, 4)
        }

# 示例调用
if __name__ == "__main__":
    generator = DenimWaistlineGenerator(waist_len=20.0, side_rise=1.0)
    points = generator.get_waist_points()
    print("前中点 A:", points["Point_A_FrontCenter"])
    print("侧缝点 B:", points["Point_B_SideSeam"])
