# 前浪弧线（前立裆线）算法化绘制与逻辑规范

本文档用于指导程序/AI（如 Python, Canvas, SVG, CAD 脚本）参数化绘制裤装的前浪线。

---

## 1. 核心几何思想

前浪线是由 **一段直斜线** 与 **一段平滑凹贝塞尔曲线** 组合而成的复合线：

1. **分段构成**：
   - **上段（线段 $AB$）**：前中内收点 $A$ 至臀围线内缝点 $B$，为纯直线段。
   - **下段（弧线 $BC$）**：臀围线内缝点 $B$ 至前小裆顶点 $C$，为三阶贝塞尔曲线。
2. **$C^1$ 相切连续性**：
   - **$B$ 点（拐点）**：弧线 $BC$ 的起始切线方向必须沿向量 $\vec{AB}$ 的延伸线方向，保证无折角。
   - **$C$ 点（底裆点）**：弧线 $BC$ 的终点切线方向自水平向下倾 **出口角 $\theta$**（默认 $\theta = 0$，即水平、平行于立裆线；见 §3.3）。
3. **弧长闭合约束**：
   $$\text{总前浪长 } L_{\text{target}} = L_{AB} + \text{ArcLength}(BC)$$

---

## 2. 几何点与向量表达

### 2.1 输入点
- **点 $A (A_x, A_y)$**：前中内收点
- **点 $B (B_x, B_y)$**：臀围线内缝点
- **点 $C (C_x, C_y)$**：前小裆顶点
- **目标长 $L_{\text{target}}$**：前浪固定总长

### 2.2 方向向量
- 斜线 $AB$ 的单位方向向量：
  $$\vec{d}_{AB} = \frac{(B_x - A_x, B_y - A_y)}{\sqrt{(B_x - A_x)^2 + (B_y - A_y)^2}}$$

---

## 3. 三次贝塞尔曲线（弧线 $BC$）表达

弧线 $BC$ 由四个控制点 $P_0, P_1, P_2, P_3$ 定义，三个形态参数
$\alpha$（上控制柄系数）、$\beta$（下控制柄系数）、$\theta$（裆底出口角）：

- **起点**：$P_0 = B$
- **起点控制点**：$P_1 = B + k_1 \cdot \vec{d}_{AB}$，其中 $k_1 = \alpha \cdot \|B - C\|$
- **终点控制点**：$P_2 = C - k_2 \cdot \vec{t}(\theta)$，其中 $k_2 = \beta \cdot \|B - C\|$，
  $\vec{t}(\theta) = (\cos\theta, -\sin\theta)$ 为出口切向
- **终点**：$P_3 = C$

### 3.1 控制柄系数 α / β（弯度分布）

- $\alpha$ 控拐点侧：越大近臀段越平直、弯度下移（0.25~0.45）；
- $\beta$ 控裆底侧：越大裆底越饱满（0.25~0.45）；
- 默认 $\alpha = \beta = \frac{1}{3}$（§4 标准控制柄，与旧单比例口径 $k_1 = k_2$ 严格等价）。

### 3.2 起端固定

起点切线恒沿 $\vec{d}_{AB}$（拐点无折角），**不参数化**——这是各流派共识的不变量，
放开会破坏前中斜线的"直"。

### 3.3 裆底出口角 θ（裆尖 ↔ 圆角形态）

- $\theta = 0$：终点切线水平（平行立裆线），教科书口径，裆底与下裆缝
  夹角 $\approx 90°$，留裆尖（cutter 裆尖角部处理的前提）；
- $\theta > 0$：终点切线自水平向下倾，裆底夹角 $= 90° + \theta$，
  裆底连续圆角化（紧身/弹力款 10~25，上限 30；负值不允许——
  比教科书更尖的裆底形态不存在）；
- $C$ 点恒为弧线端点（$\theta > 0$ 时曲线到达 $C$ 仍向内侧进给，
  小裆宽名义点不变，浪长闭合、cutter 裆尖逻辑均不受影响）。

---

## 4. 前浪固定长度求解算法

### 方案：延伸点 $A$（推荐，符合服装打板习惯）
1. 设定控制柄参数（默认 $\alpha = \beta = \frac{1}{3}$、$\theta = 0$，即 $k_1 = k_2 = \frac{\|B - C\|}{3}$），生成标准弧线 $BC$。
2. 积分计算弧线长 $L_{BC} = \int_0^1 \|P'(t)\| dt$。
3. 计算所需直线段长度：$L_{AB\_new} = L_{\text{target}} - L_{BC}$。
4. 将点 $A$ 沿 $\vec{d}_{AB}$ 的反方向移动，更新点 $A$ 坐标：
   $$A_{\text{new}} = B - L_{AB\_new} \cdot \vec{d}_{AB}$$
