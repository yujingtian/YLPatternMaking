# 服装打版：牛仔裤后中内收点定位与斜率推导指南

---

## 一、 核心概念与推导原理

**后中内收点（腰头倒量点）** 是决定后浪斜率（后中线倾斜度）的核心制图参数。  
在打版体系中，**$15 : X$ 是一个“斜率比例（几何角度比）”**，而非绝对固定数字：
* **$15$ — 比例参照模数：** 标准常态下的臀腰距参考基数。
* **$X$ — 比例倒量模数：** 对应该基数下的水平内收系数。

### 核心计算公式
当版样的**实际臀腰高（后臀围线到后腰围线的垂直距离）**为 $H_v$ 时，**后中实际内收量 ($D_h$)** 按同比例折算：

$$D_h = H_v \times \frac{X}{15}$$

> **计算示例：**  
> 假设所采用的斜率比为 **$15 : 2.5$**：  
> * 若实际后臀腰距 $H_v = 15\text{cm}$，则内收量 $D_h = 15 \times \frac{2.5}{15} = \mathbf{2.5\text{cm}}$  
> * 若实际后臀腰距 $H_v = 12\text{cm}$（如中低腰版），则内收量 $D_h = 12 \times \frac{2.5}{15} = \mathbf{2.0\text{cm}}$  
> * 若实际后臀腰距 $H_v = 18\text{cm}$（如超高腰版），则内收量 $D_h = 18 \times \frac{2.5}{15} = \mathbf{3.0\text{cm}}$

## 二、 核心比例系数表 ($15 : X$)

| 倾斜比例 ($15 : X$) | 比例系数 ($X/15$) | 倾斜特征 | 适用版型与效果 |
| :--- | :--- | :--- | :--- |
| **$15 : 1.5 \sim 15 : 2$** | **$0.10 \sim 0.13$** | **偏直** | **宽松/松弛款：** 阔腿裤、休闲工装裤、松紧腰裤。包容度高，不着重臀部凸显与提臀。 |
| **$15 : 2.5 \sim 15 : 3$** | **$0.17 \sim 0.20$** | **标准** | **基础/合体款：** 标准直筒牛仔裤、通勤合体裤。贴合正常人体自然腰臀差，舒适与平服兼备。 |
| **$15 : 3.5 \sim 15 : 4$** | **$0.23 \sim 0.27$** | **大倾斜** | **紧身/提臀款：** 弹力高腰提臀牛仔裤。强力裹夹并产生斜向拉托张力，提臀并消除大腿下缘皱褶。 |

## 三、 核心几何制图步骤（三步定位法）

1. **定支点（支点 O）：**  
   找出 **后臀围线** 与 **后中垂直基准线** 的交点，作为后浪倾斜旋转的**基准支点 O**。
2. **算比例并定位内收点（点 A）：**  
   先量取实际图纸上“后腰围线”到“后臀围线”的垂直高度 $H_v$，按选定风格代入公式计算实际内收量：
   $$D_h = H_v \times \frac{X}{15}$$
   在 **后腰围线** 上，从后中垂直基准线向内（裤片主体方向）水平量取 **$D_h$**，定出 **后中内收点 A**。
3. **延伸基础斜率线：**  
   连接 **支点 O** 与 **内收点 A** 并按版型要求的后翘高度向斜上方延长，这条直线即为所求的**后中心基础斜率线**。
