## 一、腰头裁片（v0.5 → v0.9）

- **v0.5 两标量参数化合成**：弯腰头下口线由两个标量参数拼合 → 废弃（对 curve_sag 响应失真）。
- **v0.6 cap_sag 限幅**：给 sag 加上限防变形 → 废弃（cap 限 sag 破坏弯曲总量传递，被拒）。
- **v0.7 圆顺窗长**（`waistband_blend_cb/side`）+ **`waistband_front_drop`**：分段圆顺 → v0.8 随整根拟合删除，两键走 from_dict 一次性垫片（stderr 告警后丢弃）。
- **v0.8 `fit_fair_cubic` 数值拟合**：忠实保留拼合链「平后段+侧缝肘弯」结构 → v0.9 删（后段本就近直，小 sag 时视觉与均匀弧无差，拟合复杂度不值）。
- **v0.9 整根均匀圆弧**（现行）：三锁（弧长=净长精确 / 总转角=链末切向角 / 起端切向沿 X̂ 保后中镜像 C2）+ 一匀（曲率恒 1/R）；端点位置派生（独立带状裁片端点无装配语义）。`g2_blend` 一并删除。
- **`_auto_drop` 同侧旋转拼合**：旧拼合把前弧绕侧缝腰点旋转同侧放置 → 删（退化口径，对 curve_sag 零响应）；改**跨后片侧缝线反射**（物理平摊缝拼合）。
- **2026-08-30 `waistband_fly_extension` 默认 3.5 → 0**：有些款搭门量加在 left_end 缝份上而非外延净样；>0 仍可用（弯腰头随弧端斜出 ~40° 转角时 3.5cm 使左端低 ~2.3cm，属设计非 bug）。
- **2026-08 新增 `waistband_shrinkage_warp/weft`**：腰头原是唯一直读全局率、无专用覆盖的主面料裁片，与机头/门襟等七片同口径。

## 二、前片裆尖角部（四轮目检定稿）

- **默认限长 miter 静默回退阶梯角**：尖裆内角 ≈75°、miter ≈1.64·缝宽 > 1.5 限长，角部留「竖一刀+斜一刀」台阶（用户目检发现，金标 M 尺寸角度缓未暴露）→ cutter 增显式 `"miter"` 取值绕过限长。
- **圆弧抹角家族全部废除**（2026-08 用户三轮目检）：等距圆弧 `"round"`、数值半径大圆弧、浪尖相切圆角——「净样裆尖就是尖的」，缝边只能是尖的。`_round_join_points`/`_circle_seg_cross`/`_arc_points`/`_tip_round_points` 整体删除；能力后又在 cutter 恢复（`"round"`），但前片裆尖不再使用。
- **轮廓延伸态**（`front_piece_crotch_contour`，前浪净边 C2 延续越出裆尖交下裆缝缝份边界）→ 删：弯腰头形态前浪曲率大，C2 延续越摆越远，缝边翘成高尖角且非真等距。
- **两偏移切线内切圆**→ 删：75° 尖角处内切圆深嵌角内，弧顶距净尖仅 ≈0.3cm，缝份塌陷破坏不变量。
- **尖角跟随净样 + 显式 miter**：中间态。
- **「等曲率延续弯向角点转向 + G1 单曲率弧重建过渡链」**：解决拉直与鼓包 → 被用户手改为纯贝塞尔多项式自然外延（`_natural_join_sharp`）并目检通过。
- **2026-08-24 定稿切线直线延伸 miter**（现行 False 态，`"miter_line"`）：多项式外延在锐角下交点远飞、缝边顶点高出裆尖 ~1.8cm；端切线直线延长交点近而有界（= sa/sin(θ/2)，实测恰高 1.0）。多项式求交解保留作后片 False 态。
- **同日「钝角平顶」**（`_blunt_join` 单边多项式外延 + `front_piece_crotch_lift` 固定抬高截断）→ 上线即废，选项一并回收。
- **mirror 折角键序误置**（("inseam","rise")，折轴错成下裆缝）：裆尖内角 ≈87° 近直角时镜像退化 ≈miter，角点「向内平切」不报错（用户目检发现）→ 更正 ("rise","inseam")。
- **2026-08-19 mirror 改真反折角构造 + 补轴穿越点 X**：旧实现只镜像方向、锚点不动，斜角翻折短缺（机头 (bottom,side) 角 0.66）；且直接连偏移链自然端点到 M 的弦，被镜像边缝边到不了角点等高处（后片内缝短 0.22，用户目检）。新构造经 X 中转后翻折像与被镜像边毛缝边界全线重合（金标：翻折像距线 == 0）。
