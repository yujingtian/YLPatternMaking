# 牛仔裤打版：后片腰头线绘制核心技法（定长斜截法）

> **核心逻辑**：以**后浪顶点**为圆心、**已确定的后腰总长**为固定半径，斜截**与前片侧缝起翘等高**的腰围辅助线，确定侧缝顶点后进行**弧线优化**。

---

## 一、 核心操作三步法

### 1. 绘制「起翘等高」辅助线
* **操作**：在后腰围水平基准线上方，绘制一条平行的腰围辅助线。
* **高度**：辅助线高出水平线的距离 ＝ **前片腰侧缝的起翘高度**（确保前后片侧缝拼合后腰口平顺、高度等齐）。

---

### 2. 定长斜截找点（确定后侧缝顶点）
* **操作方式**：以已经确认的 **「后浪顶点」** 为固定起点，以已求出的 **「后腰长」** 为半径（或尺长），斜向相交于刚画好的起翘辅助线，**相交点**即为 **「后腰侧缝顶点」**。

```
后浪顶点 O
         \  固定线段长度 = 已计算的后腰长
      -------X (后腰侧缝顶点)-----------------  <-- 起翘等高辅助线
--------------------------------------  <-- 后腰围水平基准线
```

---

### 3. 勾勒与优化腰头线（关键形态处理）
* **基础辅助线**：先用直尺连接 **后浪顶点** 与 **后腰侧缝顶点**。
* **微微下弧**：以直连线为基准，向下（向内）顺画出一条**微微下凹的自然弧线**，使其更贴合腰背背弓的立体形态。
* **垂直后浪（核心要点）**：弧线趋近 **「后浪顶点」** 处时，切线方向必须与 **后浪线（后中斜线）** 保持 **90° 垂直（正交）**。
  * *原因：保证左右后片在后中缝合后，腰上口呈平滑连续曲线，不生成“尖角”或“窝陷”。*
* **侧缝顺接**：弧线趋近 **「后腰侧缝顶点」** 时，与后侧缝臀弧线圆顺过渡。

```
       后浪线
         /
        /  _| 90° 垂直（正交）
       O------------------------- X (后腰侧缝顶点)
        \___  微微下弧（自然凹顺） ___/
            \__________________/
```

---

## 二、 关键注意事项 (Checklist)

| 核对项目 | 关键要求 | 操作说明 |
| :--- | :--- | :--- |
| **后中正交性** | 腰线与后浪线呈 **90° 垂直** | 在后浪顶点附近保留约 1cm 的垂直平顺段，再过渡到弧线 |
| **下弧自然度** | 腰头线需**微微下弯** | 不可直白相连，稍微向内下顺弧（通常凹深约0.3~0.5cm） |
| **侧缝长度等长** | 前后腰侧缝点至臀围线的高差匹配 | 用软尺或CAD功能复核侧缝弧长，微调时确保弧线流线顺畅 |
