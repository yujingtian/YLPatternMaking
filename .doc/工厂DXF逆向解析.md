# 工厂 DXF 逆向解析（`ylpattern reverse`）

> 把工厂打版 DXF（布衣科技 BUYI-TECH CAD 导出）反解析成本项目的尺寸单
> TOML：层 1（尺寸单 8 测量值）+ 层 2（可直接量测/观测的 `PatternOptions`）
> + 层 3（多码档差 `[size_run]`）。**形状系数逆拟合（层 4）不在本期**；
> 几何上不存在的参数族（层 5）保持引擎默认并在报告明示。
>
> 代码：`src/ylpattern/reverse/`（reader → identify → measure → grade →
> emit / report；只 import params + geometry + stdlib，ezdxf 仅 reader 惰性
> 引入）。本文是该包的口径权威。

## §1 结构事实（DXF 方言，两款实测）

- **R12 / AC1009、mm**、POLYLINE **无 bulge**——ET 把弧离散成密顶点，
  弧长 = 分段求和，无需圆弧重建。
- 每裁片一个 BLOCK，名 `款号#.件名.码`；**一个块可含 N 个子片**：
  各 = 层 1 毛样闭合折线 ×1 + 层 14 净样闭合折线 ×1（**已含缩水放大**）
  + 层 8 内部线 ×K + 层 7 丝缕线 + 5 行元数据 TEXT + 层 2/3/4 点。
  子片分离 = 层 1/14 环为种子的空间聚类，其余实体按 bbox 包含
  （±5mm）/质心最近归属。
- **块内坐标即铺版绝对坐标**（INSERT 恒等变换；非恒等只告警）——跨片
  全局几何（袋口弧全等、机头拼回）直接可做。
- 乱码还原：`encode('latin-1')` 失败再 `cp1252` → `decode('gbk')`，
  失败原样返回（结构化解析按 `.` 三段拆分，不依赖中文名成功）。
- 层语义：1=毛样、14=净样、8=内部线（缝线/折线/**水平辅助线**）、
  7=丝缕、2=放码点（仅基码块带 `# N` TEXT）、3=毛边密采样（诊断）、
  4=刀口。
- 缩水双源：文件名 `W15%-L8%`（主）+ 每块 Annotation `横:15.0%，直:8.0%`
  （交叉校验，互差 >0.5 个百分点抛 `ReverseError`）。
- 头标 6 行 TEXT（模型空间层 1）：`SAMPLE SIZE` = 基码；`STYLE NAME`
  含款号。
- 顶点数随码漂移（188→195）：**任何跨片/跨码对应禁用顶点索引**，
  用等弧长重采样（`ring_gap_best` / `resample_chain`）。
- 两款块清单：
  - **5015**（单码 S）：`前`、`机头`（**×2 子片 = 后片 + 真机头，陷阱一**，
    净面积降序对位）、`腰`、`前代`（贴+袋身一体曲边三角：净边 = 顶边
    腰弧段 + 右边外缝段 + **底部大弧 = 袋贴内边**，袋口缝线是片内
    层 8 线 162.6mm）、`双排`/`单排`/`裤耳`、匿名 ×2（后贴袋+表袋，
    面积降序）。
  - **5028**（6 码 S~3XL，基码 M）：同构 + `火机袋`（表袋命名块）+
    匿名 ×5（其中 156×52 细条语义未知 → `unknown_strip` 告警不入测量）。

## §2 几何算子（geomops.py）

mm 域纯几何，measure 的口径全部落在这层算子上；关键约定：

- 弦宽 `chord_span_mm`：无限直线穿环的首末交点距（导线族）；
- `chain_above(y)`：近水平切割取上方链（严格 `>`，恰过顶点退化返回空，
  measure 告警不静默）；
- `shallow_run_at_extreme`：含 y 极值顶点的缓段（|dx|≥|dy|）游程——
  机头上/下口、后片顶边的直线边提取；**bbox 角点锚会被斜端虚拟角
  吸偏（实测顶弧虚长 +20mm），禁用**；
- `strip_long_edges`：条带环两条长边（腰头）；`strip_width_mm`：闭式解
  `W²−(P/2)W+A=0` 取小根（弯条带 bbox 高被矢高虚高，禁用 bbox）；
- `corner_turns`：折线角点（|Δ角| ≥ 阈值取 ±180 环绕最短）；
- `chord_profile`：开放链对首末弦的法向偏差剖面 → (弧高, 弧顶弦位,
  折角表)——弧高符号以内侧参考点定「向片内凹入为正」，挖削袋口
  bulge/polyline 形态反推用；
- `rigid_fit_offset` / `chain_congruence_rms`：**只许平移不许旋转**的
  拟合口径（机头拼回、袋口弧全等；嵌套摆放可镜像，取正向/反向最小）；
- `resample_chain`：开放折线等弧长重采样（`Ring.resample` 是闭环绕向，
  开放链禁用）。

## §3 裁片识别（identify.py + profiles_*.py）

- 两款特化档案（`StyleProfile.block_map` + `anonymous` + 谓词打分）；
  款号识别：头标 STYLE NAME 优先、块名款号段多数表决兜底；
  未登记款 → `ReverseError`（提示 `--probe` 看清单后补档案）。
- 块内多子片 / 匿名子片一律按**净面积降序**对位 SubSpec 序；
  计数失配按面积降序对位尽力而为并告警。
- 谓词（0..1，<0.5 低置信告警）：后片 bbox 高 ≥600、机头高 ≤150、
  腰头长短边比 ≥4 且宽 ≤120、前代近方片 + 100~200mm 层 8 弧。
- `--probe`：只读取+识别出件清单报告（新款 bring-up 入口）。

=warp。乘法口径（缩水前毛坯为基准的逆运算），与 cutter 的除法口径
`净样÷(1−率)` 互逆。

  出 2× 深的袋口/袋贴（6.72/12.40cm 级，视觉夸张）——发射端换算
  （÷2 + 弧顶弦位映射），不动引擎（默认值 mouth 0.5、outseam 0.3
  等全按 2× 行为调定）；回环复测引擎实测弧高 = 工厂真值逐位吻合
  （mouth 3.36 @0.391、facing 6.20 @0.489）；
- 5015/5028 袋口与袋贴同族（真弧高袋口 3.36 @ 弦位 0.39、facing
  2.15 / 4.80~4.85 / +6.20~6.24 @0.49，仅 p2_drop/side_w 微差），
  工厂口袋不随码变化，基码发射即全码代表。

**腰口锚定细则**：顶链（臀线以上）角点 = 转角 ≥50°；腰 CB 角 = 距裆区
x 极值最近者、腰侧角 = 距顶链 x 极值最近者（**侧缝参考取顶链**——裆区
窗口上限 hip+80 会切掉高位侧腰角）；袋口起 = 顶链角点中除腰 CB/腰侧外
的剩余角（排除法，非离裆尖排序）。

## §6 推码档差（grade.py，层 3）

逐码独立测量（**绕开跨码顶点漂移**——5028 前片净样顶点数 188→195
随码漂移，跨码索引对应禁用）→ 相邻码差分 → 步长均匀（段内逐键与
中位数偏差 ≤0.15cm）单 band，否则贪心分段；base = 头标 SAMPLE SIZE、
style = 款号 ASCII。发射 `[size_run]` 段（enabled=true）。

- **差分基准 = 原始测量值**（步进 = 段内中位数、圆整 0.01）：比在
  0.1 圆整值上差分的多码累积漂移小一个量级（5028 实测 3XL 腰围
  0.02 vs 0.1cm）。
- **band 与差分的对应**（params/sizerun.py 语义）：码 i 到 i+1 的
  步进取 **i+1 所属 band**、自基码双向累加——即"进入某码的过渡"
  一律取该码所在段步进；差分组 d_p..d_q 对应 band 码集
  order[p+1..q+1]（首组再并入 order[0]，其无入过渡）。
- **展开复检**：按同规则自基码双向累加与逐码圆整值比对，最坏漂移
  超 0.1cm 告警（信息性不阻塞——band 步进表示法的固有下限：逐码
  步进微变 + 基码圆整；5028 实测最坏 S hip 0.08cm，线内无告警）。
- **5028 金标**：6 码 S/M/L/XL/2XL/3XL 基码 M，单 band 全码，步进
  waist +2.37 / hip +2.34 / knee +0.91 / hem +0.69 / front_rise +0.45 /
  back_rise +0.43 / outseam +0.49 / thigh +1.11；前片净样 bbox 线性
  dW 约 6.8 / dH 5.3 mm 每码（信息性旁证，本期拟合测量不拟合形状）。
