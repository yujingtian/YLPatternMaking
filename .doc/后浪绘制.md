# 后浪弧线（后中心缝与大裆弯）算法化绘制与逻辑规范

本文档用于指导程序/AI（如 Python, Canvas, SVG, CAD 脚本）参数化绘制牛仔裤后浪线，重点强化了后裆深弯曲线的切线控制与提臀版型适配。

---

## 1. 核心几何思想

后浪线是由 **一段直斜线（后中斜坡）** 与 **一段深凹三阶贝塞尔曲线（大裆弯）** 组合而成的复合线：

1. **分段构成**：
   - **上段（线段 $AB$）**：后中内收点 $A$ 至臀围线内缝点 $B$，为合体直斜线段。
   - **下段（弧线 $BC$）**：臀围线内缝点 $B$ 至后大裆顶点 $C$，为三阶贝塞尔曲线（深度深于前浪）。
2. **$C^1$ 相切连续性**：
   - **$B$ 点（上拐点）**：弧线 $BC$ 的起始切线必须严格同向共线于向量 $\vec{AB}$ 的延伸线，杜绝臀接缝处出现折角或凸包。
   - **$C$ 点（底裆点）**：弧线 $BC$ 的终点切线方向必须处于**水平方向**（平行于后立裆线/零斜率），确保裤子前后底裆缝合后会阴底部平顺。
3. **后坐围长闭合约束**：
   $$\text{总后浪长 } L_{\text{target}} = L_{AB} + \text{ArcLength}(BC)$$

---

## 2. 几何点与向量表达

### 2.1 输入点
- **点 $A (A_x, A_y)$**：后中内收点（受后翘高与倒量控制）
- **点 $B (B_x, B_y)$**：臀围线内缝交点
- **点 $C (C_x, C_y)$**：后大裆宽顶点
- **目标长 $L_{\text{target}}$**：裤装规格测定的后浪总长

### 2.2 基础切线向量
- 斜线 $AB$ 向后裆底延伸的单位方向向量：
  $$\vec{d}_{AB} = \frac{(B_x - A_x, B_y - A_y)}{\sqrt{(B_x - A_x)^2 + (B_y - A_y)^2}}$$

---

## 3. 三阶贝塞尔曲线（后大裆弯 $BC$）控制点拆分与计算

后大裆弯需容纳臀大肌下部实体并消除下垂皱褶，其核心在于四个控制点 $P_0, P_1, P_2, P_3$ 的**权重调节（$k_1, k_2$）**：

- **起点**：$P_0 = B$
- **起点控制点（控制弯缘下探速度）**：
  $$P_1 = B + k_1 \cdot \vec{d}_{AB}$$
- **终点控制点（控制底裆回勾度与托臀空间）**：
  $$P_2 = C - k_2 \cdot (1, 0)$$
- **终点**：$P_3 = C$

### 3.1 牛仔裤控制柄系数规范（与前浪对比）
因为后裆弯比前裆弯更深、弯度更急，其控制柄张力需显著大于前浪（前浪通常 $k \approx 0.33 \|B-C\|$）：

$$\|B - C\| = \sqrt{(C_x - B_x)^2 + (C_y - B_y)^2}$$

| 控制系数 | 取值计算公式 | 几何作用 | 牛仔裤推荐值 |
| :--- | :--- | :--- | :--- |
| **$k_1$ (上控制柄)** | $k_1 = \alpha \cdot \|B - C\|$ | 控制斜度自然过渡，防止臀围下侧夹裆 | **$\alpha \in [0.38, 0.42]$** |
| **$k_2$ (下控制柄)** | $k_2 = \beta \cdot \|B - C\|$ | 控制底裆勺形深度（Scoop），包积臀底面积 | **$\beta \in [0.48, 0.55]$** |

> **关键建议：** 紧身提臀裤需调大 $\beta$ 至 **0.55**，使曲线底部形成更平坦宽广的“U”型托底部，防止卡臀。

## 4. 后浪固定长度求解算法

为确保样板的后浪长度与设计规格完全一致，采用 **“反推点 $A$（后腰翘高点）延伸法”**：

1. **构造标准弯弧：** 根据上述系数推荐值（例：$\alpha = 0.40, \beta = 0.50$）生成贝塞尔弧线 $BC$。
2. **积分计算弧线真实长度：**
   $$L_{BC} = \int_0^1 \sqrt{X'(t)^2 + Y'(t)^2} \, dt$$
3. **计算直斜线段修正目标长：**
   $$L_{AB\_new} = L_{\text{target}} - L_{BC}$$
4. **沿主向量逆向定位最终后中内收点 $A_{\text{new}}$：**
   $$A_{\text{new}} = B - L_{AB\_new} \cdot \vec{d}_{AB}$$
