# 牛仔裤前后片裤中线（烫迹线/丝缕线）全场景推导与自定义调节量规范

---

## 一、 核心逻辑与理论基石

1. **等量对称法则**：裤中线从**膝围线（Knee Line）到裤脚线（Hem Line）**是裤管的物理重心轴与对称中线。在标准制版中，前、后片的内缝（下裆缝）与外缝（侧缝）应遵循**左右对称、等量加放**原则，使裤中线在人体及裁剪面布纹上绝对重合。
2. **前后结构异构原则**：
   * **前横裆可对称二等分**：前大腿处受力较为均匀且小裆较短，前片裤中线基础基准处于前横裆总宽度的 **1/2** 处。
   * **后横裆严禁二等分**：人体臀部丰满向后突出，且后大裆极长、受力不对称。**若误用“后横裆总宽 ÷ 2”推算后裤中线，必会导致最终成衣侧缝向前转扭、整条裤管向内倒折。**
3. **实战动态平衡原则**：
   * 在特体制版、高弹面料或特定修身美学造型（如显瘦视觉导向）中，基础绝对对称等分无法完全满足工业实战，因此需在公式中增加**自定义调节量 ($e$)**，形成全场景兼容的推导矩阵。

---

## 二、 前片裤中线计算公式（含自定义调节量 $e$）

前片裤中线以**前侧缝点**为出发起点，穿过前横裆基础中点，并叠加针对特殊体型与面料的**自定义调节量 ($e_{\text{front}}$)**。

### 1. 全场景计算公式
$$X_{\text{前中线距前侧缝}} = \frac{W_{\text{前横裆总宽}}}{2} + e_{\text{front}} = \frac{W_{\text{前臀宽}} + W_{\text{前小裆宽}}}{2} + e_{\text{front}}$$

### 2. 基础尺寸推导参考
* **前臀宽 ($W_{\text{前臀宽}}$)** $\approx \frac{H}{4} - k$ （$H$ 为成品目标臀围，$k$ 一般取 $1.0 \sim 1.5\text{cm}$）
* **前小裆宽 ($W_{\text{前小裆宽}}$)** $\approx \frac{H}{20}$ （或参考经验常规数值 $3.5 \sim 4.8\text{cm}$）

### 3. 定位与绘制说明
从前横裆线的**前侧缝端点**向内侧（裆端方向）量取 $X_{\text{前中线距前侧缝}}$ 的长度得到定点。过该点作横裆线的垂直准线，向上延伸至腰围线、向下延伸至脚口线，即为前片裤中线（经向布纹线）。

## 三、 后片裤中线计算公式（三大工业实战场景）

| 场景分类 | 适用实战场景 | 核心推导公式 / 结构定位方法 | 实操指南与避坑要求 |
| :--- | :--- | :--- | :--- |
| **场景 A：原位合版法<br>（前盖后直接打版）** | 手工制版、原型借片推导 | **继承前片裤中线坐标**<br>后膝围、脚口在前片中线两侧各对称加放 $\frac{W_{\text{后}} - W_{\text{前}}}{2}$ | 前后中线完全重合。即使有调整量 $e$，两片均基于同一主轴扩展，无需重复运算。 |
| **场景 B：CAD 独立制图法<br>（分片算数定位）** | CAD 独立画片、数字化制单推导 | **$X_{\text{后中线距后侧缝}} = X_{\text{前中线距前侧缝}} + \Delta + e_{\text{back}}$**<br>*注：$\Delta$ 为外侧缝单边放大量* | **切勿平分后横裆！** 后大裆加长仅发生在内侧缝，不可影响重心垂线离侧缝的相对间距。 |
| **场景 C：几何自检逆推法<br>（无基线样板验算）** | 定做改版、样板平衡性质检 | 找准**后膝口宽度中点**与**后脚口宽度中点**，连接两点并向上作垂直射线至后腰 | 适合自检纸样垂度。后翘及后裆缝偏移腰口，不改变这根垂轴在腿部的相对对称性。 |

> **公式参数说明：**
> * **$\Delta$**：内外缝单边等量差值。如裤口后片比前片大 $2.5\text{cm}$ 时，单边外侧缝差值 $\Delta = 1.25\text{cm}$。
> * **$e_{\text{back}}$**：后片自定义调节量。一般常规版型中 $e_{\text{back}} = e_{\text{front}}$；仅在偏平臀、特大臀峰或提臀造型时需独立设定。

## 四、 侧缝加大差量 ($\Delta$) 与脚口规格换算表

在分离制版时，后片侧缝到裤中线的标准基准宽度，取决于前片的坐标与侧缝单边扩张值 ($\Delta$)：

$$\Delta = \frac{\text{后底边总宽} - \text{前底边总宽}}{2}$$

| 裤型规格设计（底边差额） | 内/外缝单边等量差 ($\Delta$) | 后裤中线距后侧缝基础推导公式 | 数值演算示例（设前中线距前侧缝 $13.5\text{cm}$，调节量 $e=0$） |
| :--- | :--- | :--- | :--- |
| **后脚口比前大 2.0cm** | 单边多出 **1.0cm** | 前裤中线距前侧缝 + **1.0cm** | $X_{\text{后中线}} = 13.5 + 1.0 = \mathbf{14.5\text{cm}}$ |
| **后脚口比前大 2.5cm** | 单边多出 **1.25cm** | 前裤中线距前侧缝 + **1.25cm** | $X_{\text{后中线}} = 13.5 + 1.25 = \mathbf{14.75\text{cm}}$ |
| **后脚口比前大 3.0cm** | 单边多出 **1.5cm** | 前裤中线距前侧缝 + **1.5cm** | $X_{\text{后中线}} = 13.5 + 1.5 = \mathbf{15.0\text{cm}}$ |
| **前减 2.5cm / 后加 2.5cm<br>（前后总共相差 5.0cm）** | 单边多出 **2.5cm** | 前裤中线距前侧缝 + **2.5cm** | $X_{\text{后中线}} = 13.5 + 2.5 = \mathbf{16.0\text{cm}}$ |

## 五、 自定义调节量 ($e$) 的实战场景应用规范

在工业打版中，自定义调节量 $e$ 的正负取值遵循以下物理与美学坐标方向：
* **负值 ($-e$)**：代表裤中线往**内缝（下裆缝）方向**移动，即靠近内侧；
* **正值 ($+e$)**：代表裤中线往**外缝（侧缝）方向**移动，即靠近外侧。

| 工业应用场景 | 前片调节量 ($e_{\text{front}}$) | 后片调节量 ($e_{\text{back}}$) | 原理分析与解决的技术痛点 |
| :--- | :--- | :--- | :--- |
| **常规基础直筒 / 标准工业样板** | $0\text{cm}$ | $0\text{cm}$ | 标准人体重垂线通过两腿中心，内外缝两侧受力完全一致。 |
| **修身显瘦 / 亚洲小腿笔直造型** | $-0.5 \sim -0.8\text{cm}$ | $-0.5 \sim -0.8\text{cm}$ | 将前后面板视觉中心微向内聚拢，减轻大腿外侧臃肿感，让腿型更显直长。 |
| **O型腿（罗圈腿）下身修正** | 膝底段 $-0.8 \sim -1.2\text{cm}$ | 膝底段 $-0.8 \sim -1.2\text{cm}$ | 对消腿骨内倾造型导致的裤腿外翘，使中线平复于偏斜小腿上方。 |
| **粗腿 / 健身大腿 / 特大腰峰体型** | $+0.5 \sim +1.0\text{cm}$ | $+0.8 \sim +1.5\text{cm}$ | 赋予臀外侧与粗壮股四头肌充足的外部包覆容量，避免外侧缝被向前拉扯变形。 |
| **高弹牛仔布 (Power Stretch) + 酵磨洗** | $+0.5\text{cm}$ | $+0.5\text{cm}$ | 抵消高强洗水后，由于内缝弧线缝制或双针线迹张力较强带来的向内收缩力。 |

## 六、 斜纹牛仔布防拧腿 (Leg Twist) 预偏度补偿

除了数学推导的中线坐标外，由于牛仔布通常为 **3/1 右斜纹（RHT）** 织造，洗水后会有自然顺时针释放斜纹应力的现象。为避免裤脚拧歪，需在**推断好基础中线**的基础上，做物理裁剪丝缕线的旋转偏角（预偏斜补偿）：

```
      [ 膝围线中心点 ] (支点 Pivot Point - 原坐标不动)
             |
             |  <-- 几何理论基础中线 (自然重心线)
              \
               \  <-- 最终面料裁剪经丝线 (防拧偏斜线)
       [底裤端向内缝偏置 1.0~1.5cm]
```

* **右斜纹牛仔布 (RHT, 最普遍)**：水洗导致裤腿顺时针转，裤中线自膝围点向裤脚处的 **内缝 (Inseam)** 偏移 **1.0 ~ 1.5cm**（原色生坯未缩布料可增至 **2.0 ~ 2.5cm**）。
* **左斜纹牛仔布 (LHT)**：应力相反，裤中线向 **外侧缝 (Outseam)** 偏移 **1.0 ~ 1.5cm**。
* **破斜纹 / 人字斜 (Broken Twill)**：正反组织互相抵消应力，**保持 0 偏置**（按照计算得到的理论中线直接排布裁剪）。
