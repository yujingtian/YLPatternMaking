# 牛仔裤前后片裤中线推导公式与结构平衡指南（纯结构/不含缩率版）

## 一、 裤中线（丝缕线）的定义与核心作用

在牛仔裤（Jeans）结构打板中，**裤中线**（Centerline，亦称**丝缕线**、**烫迹线**或**前/后平衡线**）是决定整条裤子重心平衡、下垂平顺度以及腿围左右对称的垂直基准线。

* **成品规格先行原则（不含缩率）：** 本指南所有公式与算例均基于**洗后成衣/成品目标规格（Finished Spec）**。在画结构网格时暂不代入水洗缩率，确保几何逻辑直观清晰，待结构图完形后再统一加算放大。
* **经缕对齐基准（Grainline Standard）：** 裤中线即为裁片在牛仔布上的物理经丝方向（Warp Direction）。
* **左右等分分配轴（Symmetric Base）：** 膝围线（Knee Line）与裤脚线（Hem Line）的宽度放量，均必须以裤中线为对称轴向左右等分分配。
* **防拧腿修正基底（Leg Twist Compensation Base）：** 裤中线是针对牛仔斜纹布（Twill Denim）水洗后向一侧扭转的应力，进行预偏斜修正（Pre-tilt Adjustment）的直接依据。

## 二、 前片裤中线（Front Centerline）代数与几何推导

前片裤中线的定位是以**前片成品横裆线（Croch Line / Hip Level Line）**的物理宽度为基准进行等分计算。

### 1. 基础变量与推导公式

以**成品目标臀围（Finished Hip Girth, $H$）**为推导基准：

| 参数名称 | 符号表示 | 推导公式 | 备注说明 |
| :--- | :--- | :--- | :--- |
| **成品目标臀围** | $H$ | 实测/设计目标值（如 $96\text{cm}$） | 包含成衣舒适放松量 |
| **前片成品臀宽** | $W_{\text{front\_hip}}$ | $W_{\text{front\_hip}} = \frac{H}{4} - k$ | $k$ 为前减后加调节量，常规取 $1.0 \sim 1.5\text{cm}$ |
| **前小裆宽（前裆冲出量）** | $W_{\text{front\_crotch}}$ | $W_{\text{front\_crotch}} = \frac{H}{20}$ 或 $\frac{W_{\text{front\_hip}}}{4}$ | 决定前裆弯弧度与舒适度 |
| **前横裆总宽** | $W_{\text{front\_thigh}}$ | $W_{\text{front\_thigh}} = W_{\text{front\_hip}} + W_{\text{front\_crotch}}$ | 前侧缝至前裆尖端总长 |

### 2. 前片裤中线定位公式

前裤中线在几何结构上必须穿过**前横裆总宽度的精确中点**：

$$X_{\text{centerline}} = \frac{W_{\text{front\_thigh}}}{2} = \frac{W_{\text{front\_hip}} + W_{\text{front\_crotch}}}{2}$$

**几何画法：**
自前片侧缝线向前裆尖方向量取 $X_{\text{centerline}}$ 距离，过该点画出与横裆线相互垂直（$90^\circ$）的直线，向上延伸至腰围线，向下延伸至裤脚线。此线即为**前片裤中线**。

## 三、 后片裤中线（Back Centerline）的推导与对齐

后片打板建立在前片网格的基础上。由于人体制态后臀丰满且腿部向后延伸，后片需要额外的后裆冲出量（大裆宽）与后斜翘（Back Rise Slant）。

### 1. 后片基础参数计算

| 参数名称 | 符号表示 | 推导公式 |
| :--- | :--- | :--- |
| **后大裆宽（后裆冲出量）** | $W_{\text{back\_crotch}}$ | $W_{\text{back\_crotch}} = \frac{H}{10}$ 或 $2.0 \sim 2.2 \times W_{\text{front\_crotch}}$ |
| **后横裆总宽** | $W_{\text{back\_thigh}}$ | $W_{\text{back\_hip}} + W_{\text{back\_crotch}}$ |

### 2. 后片裤中线的定位规则

牛仔裤打板中最主流的方法为 **同轴平行法（直下对齐法）**：
* 直接引用前片裤中线作为后片的水平基准线；
* 后片膝围与脚口直接在前裤中线两侧左右各加宽 $\Delta$（通常 $\Delta = 1.0 \sim 1.5\text{cm}$）；
* **优势：** 最大的程度保证牛仔裤后片横向经丝的平衡，防止裁片斜扭。

## 四、 膝围与脚口的对称分配（Symmetric Allocation）

确立裤中线后，成品膝围（Knee）与成品脚口（Hem）的放量遵循**以裤中线为中心左右对称分配**原则：

$$\text{前片半膝围} = \frac{W_{\text{knee\_front}}}{2}, \quad \text{距裤中线左/右侧各放 } \frac{W_{\text{knee\_front}}}{2}$$

$$\text{前片半脚口} = \frac{W_{\text{hem\_front}}}{2}, \quad \text{距裤中线左/右侧各放 } \frac{W_{\text{hem\_front}}}{2}$$

同理，后片膝围与脚口在前片规格的基础上两侧各等量扩展 $\Delta$（使内缝与外缝缝合长度契合）。

## 五、 牛仔裤特有修正：斜纹布防拧腿（Leg Twist）预偏推导

注意：防拧腿偏针是**针对牛仔面料斜纹应力的物理角度修正**，与尺寸放缩无关。

### 1. 扭腿（Leg Twist）产生的原因
牛仔布多数采用 **3/1 右斜纹（Right-Hand Twill, RHT）** 织造。水洗后由于纬纱向右倾斜的拉力，裤腿会产生顺时针方向扭转（即右腿外侧缝向前移，左腿内侧缝向前移）。若使用 **左斜纹（LHT）**，扭转方向则相反。

### 2. 预偏修正（Pre-tilt / Grain Bias Shift）推导公式

以**成品目标内缝长（Inseam, $L_{\text{inseam}}$）**与面料水洗扭转角 $\theta_{\text{twist}}$ 进行几何偏移：

$$\Delta X_{\text{hem}} = L_{\text{inseam}} \times \tan(\theta_{\text{twist}})$$

**工程经验简易偏针表（基于裤脚处偏斜量）：**

| 布料斜纹类型 | 面料物理特性 | 裤脚处裤中线预偏方向 | 裤脚处偏斜量（$\Delta X$） |
| :--- | :--- | :--- | :--- |
| **右斜纹（RHT）** | 常规右斜牛仔布 | 向内缝（Inseam）方向偏移 | $0.8 \sim 1.5\text{cm}$ |
| **右斜纹（RHT）** | 原色赤耳/未预缩牛仔布 | 向内缝（Inseam）方向偏移 | $1.5 \sim 2.5\text{cm}$ |
| **左斜纹（LHT）** | 左斜牛仔布 | 向外缝（Outseam）方向偏移 | $0.8 \sim 1.5\text{cm}$ |
| **破斜纹（Broken Twill）** | 人字斜/破斜纹（应力互抵） | **不需偏移** | $0\text{cm}$ |

## 六、 完整实例计算示范（纯成品规格）

以标准修身男款牛仔裤为例，**设定成品目标规格**如下：
* **成品目标臀围 $H$** = $96.0\text{cm}$
* **成品目标内缝长 $L_{\text{inseam}}$** = $80.0\text{cm}$
* 前后片臀围调节量 $k$ = $1.0\text{cm}$

### 推导计算步骤：

1. **计算前片成品臀宽：**
   $$W_{\text{front\_hip}} = \frac{96.0}{4} - 1.0 = 23.0\text{cm}$$

2. **计算前小裆宽：**
   $$W_{\text{front\_crotch}} = \frac{96.0}{20} = 4.8\text{cm}$$

3. **计算前横裆总宽：**
   $$W_{\text{front\_thigh}} = 23.0 + 4.8 = 27.8\text{cm}$$

4. **定位理论裤中线（距前侧缝距离）：**
   $$X_{\text{centerline}} = \frac{27.8}{2} = \mathbf{13.9\text{cm}}$$
   *自侧缝向内量取 $13.9\text{cm}$ 作垂直平行线，即为理论前裤中线。*

5. **防拧腿（Leg Twist）偏针处理（RHT 右斜纹面料）：**
   * 以**膝围线与裤中线的交点**为支点（Pivot Point）；
   * 从膝围线向下至裤脚线，将底端裤中线向**内缝方向**偏移 **1.2cm**；
   * 连接膝围中点与偏移后的裤脚点，重新绘制下半段裤中线，作为最终裁片的裁剪经丝线。

## 七、 阶段性打板与缩率后置说明

1. **结构核对：** 完成上述纯结构绘制后，直接在纸样上核对洗后成衣目标尺寸（如腿围、脚口大、内缝长等），确保 100% 符合作业单（Tech Pack）要求。
2. **统一加算水洗缩率：** 确认成品结构图无误后，按照面料实测的横向缩率 $S_h$ 与纵向缩率 $S_v$，对成品样板进行按比例放量放大（或在 CAD 中一键输入缩率比例），即可生成**最终裁剪样板**。
