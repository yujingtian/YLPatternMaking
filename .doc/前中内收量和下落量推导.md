# 牛仔裤前中内收量与前中下落量推导指南

## 一、 核心功能：它们解决了什么问题？

在牛仔裤平面打版中，**前中内收（前中进量）** 与 **前中下落（前降/落势）** 是配合人体工学与结构美学极其关键的微调技术。

| 微调项目 | 解决的核心物理/生理问题 | 不做调整的负面后果 |
| :--- | :--- | :--- |
| **前中内收（进量）** | 消除拉链区鼓包与“猫胡须”横褶；贴合骨盆向内倾斜的生理结构 | 前浪（拉链处）凸起拱起、产生“骆驼趾”或多余堆褶 |
| **前中下落（落势）** | 预留弯腰/坐下时腹部挤压空间；适应人体侧高前低的自然腰线 | 坐下或弯腰时腰头严重“卡肚/勒肚”，或导致后腰严重下拉 |

---

## 二、 计算基准：成品腰臀差

在推导内收量与消纳量时，必须明确一个核心原则：

$$\text{成品腰臀差}(\Delta_{HW}) = \text{成品臀围}(H) - \text{成品腰围}(W)$$

* **关键原则：** 打版推导**必须基于“成品腰臀差”**，而非“人体净腰臀差”。
* **消纳量分配：** 前中内收量、后中进量、侧缝收进量以及腰省，共同分担了 $\Delta_{HW}$ 在纸样四分之一截面上的总消纳布料量。

---

## 三、 前中内收量（进量）推导逻辑与算式

### 1. 推导逻辑
前中内收量主要受 **成品腰臀差** 和 **裁片立裆深度（腰位高低）** 的双重影响：
* **腰臀差越大** $
ightarrow$ 腰部收拢越剧烈 $
ightarrow$ 内收量加大。
* **腰位越高（立裆越深）** $
ightarrow$ 从臀围线向上延伸到腰线的斜长越长 $
ightarrow$ 内收量加大。

### 2. 经验推导算式与分配

在前片四分之一纸样的总消纳量中，前中内收量通常占 **$15\% \sim 20\%$**：

$$\text{前中内收量} \approx \frac{\text{成品臀围}(H) - \text{成品腰围}(W)}{16} \quad (\text{参考值})$$

### 3. 不同腰位（高/中/低腰）实操对照表

| 腰位类型 | 成品腰臀差特征 | 立裆深度特征 | **前中内收推荐值** |
| :--- | :--- | :--- | :--- |
| **超高腰裤** | 腰臀差极大（约 $24 \sim 30\text{cm}$） | 立裆极深 | **$1.5 \sim 2.0\text{cm}$** |
| **标准中腰裤** | 腰臀差适中（约 $20 \sim 24\text{cm}$） | 立裆标准 | **$1.0 \sim 1.5\text{cm}$**（工业标准常用 $1.2\text{cm}$） |
| **低腰牛仔裤** | 腰臀差极小（腰头卡在胯骨） | 立裆极浅 | **$0.5 \sim 1.0\text{cm}$** |

## 四、 前中下落量（前降/落势）推导逻辑与算式

### 1. 几何推导画法（直角垂直法）

前中下落量最科学的来源是**前中斜线与腰线做直角投影后的几何落差**：

1. 当前中线向内倾斜（内收 $1.2\text{cm}$）后，形成一条**前中斜线**。
2. 过斜线顶点作**垂直于前中斜线**的直角延伸线（作为自然腰线方向）。
3. 此时，直角延伸线相对于原本的水平基准腰线，自然会产生一个向下倾斜的几何落差，这个落差通常在 **$1.0 \sim 1.2\text{cm}$** 左右。

### 2. 人体工学与体型修正算式

$$\text{前中实际下落量} = \text{几何落差值}(1.0 \sim 1.2\text{cm}) + \Delta_{\text{体型与面料}}$$

* **微胖/腹部有肉体型（$\Delta = +0.5\text{cm}$）：** 坐下时腹部挤压更明显，下落量扩大至 **$1.5 \sim 2.0\text{cm}$**。
* **高弹力牛仔面料（$\Delta = -0.2\text{cm}$）：** 面料纵向可拉伸，可微减下落量至 **$1.0\text{cm}$**。
* **平腹/紧身低腰裤（$\Delta = 0$）：** 取基础几何下落量 **$1.0 \sim 1.2\text{cm}$**。

## 五、 平面打版实操画线顺序

1. **第一步（画内收量）：** 在前片纸样腰线位置，从原始前中垂直基准线向内平移量取 **前中内收量**（如 $1.2\text{cm}$），过此点与前中臀围线交点连斜线，得到 **前中斜缝线**。
2. **第二步（做直角）：** 过内收后的前中顶点，作**垂直于前中斜缝线**的辅助线。
3. **第三步（定下落点）：** 从辅助线垂直向下量取 **前中下落量**（如 $1.2\text{cm}$），定出真正的 **前中腰头点**。
4. **第四步（顺弯腰线）：** 用服装弯线板，将前中腰头点与侧缝腰头点用光滑微凹的弧线顺连接，完成前腰线的绘制。
