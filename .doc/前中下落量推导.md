# 牛仔裤前中下落量（前降/落势）推导指南

> 前中内收量部分见 [前中内收量推导.md](前中内收量推导.md)。
> 前中下落解决的核心问题：预留弯腰/坐下时腹部挤压空间；适应人体侧高前低的自然腰线。不调整的负面后果是坐下或弯腰时腰头严重“卡肚/勒肚”，或导致后腰严重下拉。

## 一、 几何推导画法（直角垂直法）

前中下落量最科学的来源是**前中斜线与腰线做直角投影后的几何落差**：

1. 当前中线向内倾斜（内收 $1.2\text{cm}$）后，形成一条**前中斜线**。
2. 过斜线顶点作**垂直于前中斜线**的直角延伸线（作为自然腰线方向）。
3. 此时，直角延伸线相对于原本的水平基准腰线，自然会产生一个向下倾斜的几何落差，这个落差通常在 **$1.0 \sim 1.2\text{cm}$** 左右。

## 二、 人体工学与体型修正算式

$$\text{前中实际下落量} = \text{几何落差值}(1.0 \sim 1.2\text{cm}) + \Delta_{\text{体型与面料}}$$

* **微胖/腹部有肉体型（$\Delta = +0.5\text{cm}$）：** 坐下时腹部挤压更明显，下落量扩大至 **$1.5 \sim 2.0\text{cm}$**。
* **高弹力牛仔面料（$\Delta = -0.2\text{cm}$）：** 面料纵向可拉伸，可微减下落量至 **$1.0\text{cm}$**。
* **平腹/紧身低腰裤（$\Delta = 0$）：** 取基础几何下落量 **$1.0 \sim 1.2\text{cm}$**。

## 三、 平面打版实操画法（配合前中内收使用）

1. **做直角：** 过内收后的前中顶点，作**垂直于前中斜缝线**的辅助线。
2. **定下落点：** 从辅助线垂直向下量取 **前中下落量**（如 $1.2\text{cm}$），定出真正的 **前中腰头点**。
3. **顺弯腰线：** 用服装弯线板，将前中腰头点与侧缝腰头点用光滑微凹的弧线顺连接，完成前腰线的绘制。
