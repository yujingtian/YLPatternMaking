# 牛仔裤门襟程序化制版与几何算法规范 (AI/CAD Automation Spec)
**Denim Pants Fly Procedural Pattern Generation Specification**

---

## 1. 程序化建模补充说明（为什么需要算法规约）

为确保 AI 或参数化 CAD 引擎能够稳定、正确地生成牛仔裤门襟纸样，必须补充**数学坐标系、左右片非对称逻辑、G1 连续性切弧条件、厚重牛仔布补偿**等人工制版中容易默认忽略的技术约束。

### 1.1 左右前片非对称结构声明 (Left/Right Asymmetry Constraint)
AI 程序化建模必须将前片（Front Panel）分为互反镜像但结构不同的两个独立实体：
*   **左前片（Left Front Panel）：** 携带**门襟（Fly Facing）**（连裁出，或预留 $1.0	ext{ cm}$ 拼缝用于接驳独立门襟）。
*   **右前片（Right Front Panel）：** **不生成门襟**，直接沿前浪直线保留标准拉链止口缝份（$SA = 1.0	ext{ cm}$），并配套独立生成的**底襟/小股（Fly Shield）**。

---

## 2. 坐标系定位与核心参数（Parametric Schema）

### 2.1 坐标系定义
*   **原点 $O(0,0)$：** 前浪直线与前端腰口缝合线的交点。
*   **Y 轴（前浪轴线 AB）：** 沿前浪直线下行方向为正方向（$Y > 0$）。
*   **X 轴：** 垂直于 Y 轴向外延伸方向为负方向（$X < 0$ 表示向裁片内部， $X > 0$ 表示门襟外凸方向）。

### 2.2 核心输入参数表
| 参数常量 | 符号 | 标准牛仔裤默认值 / 计算公式 | 算法约束边界 |
| :--- | :--- | :--- | :--- |
| **前立裆长 (Front Rise)** | $H_{	ext{rise}}$ | 由主款纸样提供 | $20.0 \le H_{	ext{rise}} \le 35.0	ext{ cm}$ |
| **门襟开深 (Fly Length)** | $L$ | $L = 0.35 	imes H_{	ext{rise}} + 2.0	ext{ cm}$ | $14.0 \le L \le 18.0	ext{ cm}$ |
| **门襟宽度 (Fly Width)** | $W$ | $W = 3.8	ext{ cm}$ (常规 YKK 5# 拉链) | $3.5 \le W \le 4.2	ext{ cm}$ |
| **止口缝份 (Seam Allowance)**| $SA$ | $SA = 1.0	ext{ cm}$ | 锁边 / 拼合缝份恒定 |
| **牛仔面料折转退层补偿** | $\Delta w$ | $\Delta w = 0.25	ext{ cm}$ | 解决中重磅丹宁折折转堆积 |

## 3. 连裁门襟几何推导与 G1 顺弧连续算法

```
         O(0,0) +---------------+ 顶部镜像腰口 (已做 Δw 缩进补偿)
                |               |
                |               | W = 3.8 cm
                |               |
   Y 轴 (前浪轴) |               |
                |               |
                |               + P1 (X=W, Y=L-D1) <--- G1切弧起点
                |              / 
          (L,0) +             / R2 圆弧切线 (G1连续)
                 \           /
                  +---------+ P2 (前浪弯切口点)
                  裆底弯弧 E(x,y)
```

### 3.1 顶部腰口（镜像 + 牛仔布退层补偿）
1.  **坐标镜像：** 取腰口线段 $[O, P_{	ext{waist}}]$，以 Y 轴为中心进行对称变换。
2.  **牛仔面料退层（Turnback Allowance）：** 由于牛仔布较厚，内折后会把上侧撑凸，**门襟腰口顶端水平宽度必须减去 $\Delta w$**：
    $$X_{	ext{top\_outer}} = W - \Delta w \quad (\Delta w  pprox 0.25	ext{ cm})$$

### 3.2 底角顺弧融合（G1 连续切角算法 - G1 Continuity）
为达到数控裁剪（CNC Cutter）与锁边机一笔连续走线，底角切弧必须满足 **G1 连续（切线相切无角点）**：

1.  **起弧点 $P_1$ 坐标（位于门襟外侧垂直线上）：**
    $$P_1 = (W, \; L - D_1) \quad 	ext{其中 } D_1 = 1.2	ext{ cm}$$
    *(在此点处的初始切线方向矢量为垂直向下：$ ec{v}_1 = (0, 1)$)*
2.  **底角相切弧公式 ($R_2$)：**
    *   设定过渡圆弧半径 $R_2 = 1.8	ext{ cm}$；
    *   利用圆弧圆心求解器，在 $P_1$ 处做相切圆弧，并使其向左下方与**前浪底弧曲线 $C_{	ext{crotch}}(t)$** 于点 $P_2$ 产生正切交汇（Tangent Intersection）；
    *   **判定条件：** 在交点 $P_2$ 处，过渡圆弧的切矢量必须等于下方前浪曲线的切矢量，且相切角 $ lpha \in [30^\circ, 45^\circ]$。

## 4. 牛仔裤专有工艺与定位标记点（AI 需直接输出坐标）

程序化脚本必须将以下工程关键点作为标记（Notch / Drill Hole / Bar-tack Point）一起输出：

### 4.1 拉链止口定位剪口 (Fly Notch)
*   位于原点 $O(0,0)$ 与开深点 $(0, L)$ 处，需输出深度 $0.4	ext{ cm}$ 的剪口标记，供车间折转对位。

### 4.2 J 字压明线与打枣锚点 (J-Stitch & Bar-tack Anchor)
AI 需生成真正可见的 J 字形明线路径，并标注高应力打枣点位置：
*   **明线外延宽度：** $W_{	ext{stitch}} = W - 0.6	ext{ cm}  pprox 3.2	ext{ cm}$
*   **打枣套结锚点 (Bar-tack Point)：** 
    $$P_{	ext{bartack}} = (-W_{	ext{stitch}}, \; L - 0.3	ext{ cm})$$
    *(注意：该锚点垂直向下至裁片最外缘毛边的安全应力距离必须 $\ge 1.0	ext{ cm}$)*

---

## 5. 独立门襟（分裁/外接门襟）程序化生成规则

当用户指定生成**独立门襟 (Separate Fly Facing)** 时，AI 控制参数调整如下：

1.  **左前片主样：** 移除门襟延伸区域，仅保留沿 Y 轴的 $SA = 1.0	ext{ cm}$ 拼接缝份。
2.  **单独生成门襟裁片 (Separate Fly Piece)：**
    *   **宽度：** $W + SA_{	ext{in}} = 3.8 + 1.0 = 4.8	ext{ cm}$
    *   **高度：** $L + 2.0	ext{ cm}$ (上部预留腰口车合量，底部预留延展量)
    *   **右下角圆角半径：** $R_{	ext{fly\_corner}} = W - 0.8	ext{ cm} = 3.0	ext{ cm}$ (牛仔裤常见为平弧 J 字倒角)
