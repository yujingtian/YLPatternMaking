# 牛仔裤门襟程序化制版与几何算法规范 (AI/CAD Automation Spec)
**Denim Pants Fly Procedural Pattern Generation Specification**

---

## 1. 程序化建模补充说明（为什么需要算法规约）

为确保 AI 或参数化 CAD 引擎能够稳定、正确地生成牛仔裤门襟纸样，必须补充**数学坐标系、左右片非对称逻辑、G1 连续性切弧条件、厚重牛仔布补偿**等人工制版中容易默认忽略的技术约束。

### 1.1 左右前片非对称结构声明 (Left/Right Asymmetry Constraint)
AI 程序化建模必须将前片（Front Panel）分为互反镜像但结构不同的两个独立实体：
*   **左前片（Left Front Panel）：** 携带**门襟（Fly Facing）**（连裁出，或预留 $1.0\text{ cm}$ 拼缝用于接驳独立门襟）。
*   **右前片（Right Front Panel）：** **不生成门襟**，直接沿前浪直线保留标准拉链止口缝份（$SA = 1.0\text{ cm}$），并配套独立生成的**底襟/小股（Fly Shield）**。

---

## 2. 坐标系定位与核心参数（Parametric Schema）

### 2.1 坐标系定义
*   **原点 $O(0,0)$：** 前浪直线与前端腰口缝合线的交点。
*   **Y 轴（前浪轴线 AB）：** 沿前浪直线下行方向为正方向（$Y > 0$）。
*   **X 轴：** 垂直于 Y 轴向外延伸方向为负方向（$X < 0$ 表示向裁片内部， $X > 0$ 表示门襟外凸方向）。

### 2.2 核心输入参数表
| 参数常量 | 符号 | 标准牛仔裤默认值 / 计算公式 | 算法约束边界 |
| :--- | :--- | :--- | :--- |
| **前立裆长 (Front Rise)** | $H_{\text{rise}}$ | 由主款纸样提供 | $20.0 \le H_{\text{rise}} \le 35.0\text{ cm}$ |
| **门襟开深 (Fly Length)** | $L$ | $L = 0.35 \times H_{\text{rise}} + 2.0\text{ cm}$ | $14.0 \le L \le 18.0\text{ cm}$ |
| **门襟宽度 (Fly Width)** | $W$ | $W = 3.8\text{ cm}$ (常规 YKK 5# 拉链) | $3.5 \le W \le 4.2\text{ cm}$ |
| **止口缝份 (Seam Allowance)**| $SA$ | $SA = 1.0\text{ cm}$ | 锁边 / 拼合缝份恒定 |
| **牛仔面料折转退层补偿** | $\Delta w$ | $\Delta w = 0.25\text{ cm}$ | 解决中重磅丹宁折折转堆积 |

## 3. 连裁门襟几何推导与顺弧融合算法

```text
         O(0,0) +---------------+ 顶部镜像腰口 (已做 Δw 缩进补偿)
                |               |
                |               | W = 3.8 cm
                |               |
   Y 轴 (前浪轴) |               |
                |               |
                |               + P1 (起弧点)
                |               | 
                |               + P_turn (J型弧线上的拐点)
          (L,0) +              / \
                 \            /   \ (虚拟 J 型底弧)
                  +----------+ P2  + (与前浪完美融合)
                  裆底弯弧
```

### 3.1 顶部腰口（镜像 + 牛仔布退层补偿）
1.  **坐标镜像：** 取腰口线段 $[O, P_{\text{waist}}]$，以 Y 轴为中心进行对称变换。
2.  **牛仔面料退层（Turnback Allowance）：** 由于牛仔布较厚，内折后会把上侧撑凸，**门襟腰口顶端水平宽度必须减去 $\Delta w$**：
    $$X_{\text{top\_outer}} = W - \Delta w \quad (\Delta w \approx 0.25\text{ cm})$$

### 3.2 底角顺弧融合（J型先导与拐点求交算法）
为了在视觉和实际版型上保留门襟底部的饱满度，系统针对连裁门襟采用“先画 J 型，再找拐点融合”的几何构造逻辑：

1.  **完整 J 型基准线绘制：** 
    首先参考独立门襟的形态，基于门襟宽度 $W$ 和开深 $L$，在右下角构建一个带有平滑圆弧（如半径 $R_{\text{fly\_corner}}$）的完整虚拟 J 型外轮廓。
2.  **拐点 $P_{\text{turn}}$ 定位：**
    在该 J 型底部的圆弧线上计算并定位一个拐点 $P_{\text{turn}}$。这个点是门襟外侧实际轮廓线脱离 J 型圆弧、开始向内侧前浪收拢的起始分离点。
3.  **前浪完美融合 (G1 连续过渡)：**
    从拐点 $P_{\text{turn}}$ 开始，向左下方绘制一条过渡曲线，使其在底端 $P_2$ 点与**前浪底弧曲线**完美相切融合（G1连续）。通过这种方式，既保证了门襟下摆带有传统 J 型的圆润度，又实现了走线与前浪的平滑过渡。

## 4. 牛仔裤专有工艺与定位标记点

### 4.1 拉链止口定位剪口 (Fly Notch)
*   刀口（剪口）标记：位于原点 $O(0,0)$ 与开深点 $(0, L)$ 处，深度 $0.4\text{ cm}$，供车间折转对位。
*   **当前暂不绘制**：刀口属裁切对位工艺细节，留待后续工艺/裁切模块统一输出。

### 4.2 J 字压明线 (J-Stitch)
*   **明线 = 顺门襟外边（顶外角 → 起弧点 $P_1$）向内等距偏置的虚线**（参考线），内收量 $0.6\text{ cm}$（即明线宽 $W_{\text{stitch}} = W - 0.6 \approx 3.2\text{ cm}$）。
*   **打枣套结锚点 (Bar-tack Point) 与底部钩弧当前暂不绘制**（高应力工艺细节，留待后续工艺模块）。原规格备查：锚点 $P_{\text{bartack}} = (-W_{\text{stitch}}, \; L - 0.3\text{ cm})$，其垂直向下至裁片最外缘毛边的安全应力距离须 $\ge 1.0\text{ cm}$。

## 5. 独立门襟（分裁/外接门襟）程序化生成规则

当用户指定生成**独立门襟 (Separate Fly Facing)** 时，AI 控制参数调整如下：

1.  **左前片主样：** 移除门襟延伸区域，仅保留沿 Y 轴的 $SA = 1.0\text{ cm}$ 拼接缝份。
2.  **单独生成门襟裁片 (Separate Fly Piece)：**
    *   **宽度：** $W + SA_{\text{in}} = 3.8 + 1.0 = 4.8\text{ cm}$
    *   **高度：** $L + 2.0\text{ cm}$ (上部预留腰口车合量，底部预留延展量)
    *   **右下角圆角半径：** $R = W - \text{fly\_corner\_inset}$（默认 inset $0.8$ -> $R=3.0\text{ cm}$，与连裁门襟共用此内收参数；牛仔裤常见为平弧 J 字倒角）

## 7. 实现注记 (Implementation Notes)

程序化实现（steps/front_fly_steps.py）与本文档的口径差异及取舍：

* **共用原点 O（弯腰头口径）**：O = 前浪 ∩ 裤身顶边。**弯腰头**时腰头独立成片、裤身顶边为下腰头线，O 取**下前中腰点 $A'$**；**直腰头**时取**前浪顶点 $A$**（与 steps/front_steps.effective_waist 同一口径，见 前腰头绘制推导.md §4.3/§5.2）。
* **开深 L 基准**：$L = 0.35 \times$ 前浪 $+ 2.0$，前浪取**量体前浪** `front_rise`（含腰头成衣量，与腰头扣除口径无关）。本文档 §2.2 参数表的区间 $14 \le L \le 18$ 与公式及 §6 JSON 示例（rise=25 → L=10.75）矛盾，**以公式 + JSON 为准**。
* **连裁门襟底角逻辑（J 型先导 + 拐点融合）**：连裁门襟放弃两点直接逼近连接，改用**先画 J 型角弧（外边下端起 90° 圆弧，半径 R = `fly_corner_radius(W, fly_corner_inset)` = W − inset），在角弧上取拐点 $P_{\text{turn}}$（弧位 `fly_corner_turn`，1.0 = J 底 = 角弧终点，默认；越小拐点越靠上），再自拐点作融合弧与前浪底弧相切融合**的算法，以保证最终版型与独立门襟底层形状的一致性。`fly_corner_inset`（角弧半径内收，连裁/独立共用）、`fly_corner_turn` 均可自定义录入。
* **底角过渡圆弧**：融合弧为**二次贝塞尔 $(P_{\text{turn}}, Q, P_2)$ 升阶三次**（$Q$ = 拐点切线 ∩ 前浪切线交点），两端 G1 相切、自拐点单调下行融入前浪底弧（无波浪）。$P_2$ 自 O 沿前浪量取 $L + \text{drop}$（`fly_blend_drop`；None 自动取 $W-R$ 且不小于拐点所需防波浪最小值，手动过浅则抛错），落在裆弯弧上。**防波浪**：拐点越靠上（`fly_corner_turn` 越小），融合弧所需下移越大（`fly_blend_extend_min`），过浅则两切线交点反向、融合弧下坠后回升；该最小值由 `fly_blend_extend_min(W,R,turn)` 兜底（自动取大 / 手动校验）。非精确圆弧（本系统弧线统一以三次贝塞尔表示）。
* **完整 J 型虚线参考**：实际轮廓（顶边 -> 外线 -> 角弧起弧点 $P_1$ -> 拐点 $P_{\text{turn}}$ -> 融合弧 -> $P_2$）以**实线 struct** 上版；另像独立门襟那样把底部画全--**角弧剩余段（拐点 -> J 底）+ J 底边（J 底 -> 前浪@L）**以**虚线 ref** 补全为"完整 J 型"参考，便于对照版型。两段虚线与实线角弧在拐点、与 J 底边在 J 底均 G1 一笔顺滑（平弧 J 字倒角）；拐点已在 J 底（`fly_corner_turn=1.0`）时角弧余段退化、仅绘 J 底边虚线。曲线 `role`（`NamedCurve.role`，默认 struct）由 SVG 导出器区分实线/虚线，与直线同口径。
* **顶边方向**：顶边 O → 顶外角沿**垂直前浪方向**（局部 X 轴），长度 $W - \Delta w$；§3.1 的"腰口线段镜像"与 §6 JSON `waist_top_outer` 的 $y=-1.2$ 上移属**腰缝缝份**（先画后裁，裁切层统一加），未单独绘制。
* **J 字明线**：**顺门襟外边（顶外角 T → 起弧点 P1）向内等距偏置 `fly_stitch_inset`（默认 0.6）的直虚线**（参考线）；§4.1 拉链止口刀口、§4.2 打枣锚点与底部钩弧均**暂不绘制**（工艺细节，留待后续工艺/裁切模块），故参数 `fly_bartack_offset`、`fly_notch_depth` 已移除。
* **独立门襟（§5）**：**外缝顶点沿腰头线定位**——在裤身腰头线弧（弯腰头 = 下腰头线，直腰头 = 上腰弧，与 effective_waist 同口径）上自 O 向侧缝方向量取裁片**净宽 $W$**（**缝边/缩水不在绘制阶段考虑**，§5 的 $SA_{in}$ 拼接缝份与 §5.1 前片缝份统一留待后续**裁切/缝份模块**外拓，先画后裁）；**顶边 = 腰头线子弧**（与前片腰头线重合，门襟顶沿腰头线缝进腰头）；外缘（自外缝顶点）与缝份边（自 O）分别**沿前浪方向**下行裁片高 $L + extra$（$+2.0$ 全部作底部延展，上部腰口车合量同属裁切层缝份）；底角 90° 平弧圆角（R = W − `fly_corner_inset`，与连裁门襟共用此参数）以常数 $4/3 \cdot \tan(\pi/8) \approx 0.5523$ 贝塞尔逼近。**方向（关键）**：独立门襟绘图时**叠在前片上**（外缝顶点沿腰头线伸向侧缝方向、裁片伸入前片**内侧**，与前片身体重叠，之后裁片分离才单独成片）；与连裁门襟（凸向前片**外侧**、与前片相连）互为**前浪轴的镜像**。
* **左右片非对称（§1.1）**：本系统前片为**单片通用前片**，门襟（连裁或独立裁片）上版于该前片（视为左前片）；**右前片镜像与独立底襟/小股（Fly Shield）** 属裁片分离后的镜像与配件，暂未生成（先画后裁，裁切层未建）。
* **输出图层（§6）**：SVG 导出暂无分层机制，门襟轮廓/裁片以结构线（实线）、明线以参考线（虚线）上版。
