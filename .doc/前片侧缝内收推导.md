# 牛仔裤打板：前片侧缝内收量代数推导与侧起翘指南（成衣规格/第一性原理版）

## 一、 核心逻辑：第一性原理与牛仔结构特殊性

在牛仔裤（Jeans）平面打板中，前片侧缝内收量（Side Seam Inset）决定了腰臀转折的贴合度与侧缝线条的流畅性。

1. **第一性原理（腰线多余量消除）：** 侧缝内收量的本质，是消除前片腰线位置除“腰围实际需要”及“省褶保留量”之外多余的布料。
2. **绝对母公式与简化特例：** 
   * **母公式：** $\text{侧缝内收量} = \text{前片成品臀宽} - (\text{前片成品腰宽} + \text{前省/褶量}) - \text{前中收斜}$。
   * **特例（无省五口袋牛仔）：** 当前片无省（$S_{\text{dart}} = 0$）且前后片腰臀调节量相等（$k_{\text{hip}} = k_{\text{waist}}$）时，母公式在代数上可化简为 $\frac{H - W}{4} - X_{\text{front\_slant}}$。
3. **“内收为因，抬高为果”：** 侧缝内收倾斜后，侧缝线被拉长；为保证侧缝与腰线以 $90^\circ$ 直角顺接，侧缝顶点必须向上自然抬高（侧起翘）。
4. **成品规格先行：** 本文档所有公式与案例均基于**洗后成衣/成品目标规格（Finished Spec）**，打板时暂不揉入水洗缩率，待结构完形后再统一加算放大。

---

## 二、 侧缝内收量代数推导公式（母公式与特例）

### 1. 通用底层母公式（适用于所有裤型/含带褶牛仔裤）

以**成品目标臀围 $H$** 与 **成品目标腰围 $W$** 为推导基准：

$$\text{前片侧缝内收量 } \Delta X_{\text{side}} = W_{\text{front\_hip}} - \left( W_{\text{front\_waist}} + S_{\text{dart}} \right) - X_{\text{front\_slant}}$$

#### 参数拆解与计算方法：
* **前片成品臀宽 ($W_{\text{front\_hip}}$)：** $\frac{H}{4} - k_{\text{hip}}$ （前减后加调节量 $k_{\text{hip}}$ 通常取 $1.0 \sim 1.5\text{cm}$）。
* **前片成品净腰宽 ($W_{\text{front\_waist}}$)：** $\frac{W}{4} - k_{\text{waist}}$ （腰围前减后加调节量 $k_{\text{waist}}$ 通常取 $1.0 \sim 1.5\text{cm}$）。
* **前省/褶量 ($S_{\text{dart}}$)：** 
  * 标准五口袋牛仔裤（5-Pocket Jeans）：为了前口袋平整，**取 $0\text{cm}$**。
  * 复古褶裥牛仔裤（Pleated Jeans）：按实际设计褶量代入（如 $2.0 \sim 3.0\text{cm}$）。
* **前中内收量/前中收斜 ($X_{\text{front\_slant}}$)：** 前中线在腰线处向内倾斜的距离（用于贴合小腹）：
  * 中腰 / 高腰牛仔裤：取 $1.0 \sim 1.5\text{cm}$。
  * 低腰 / 卡胯牛仔裤：取 $0.5 \sim 1.0\text{cm}$。

---

### 2. 标准五口袋牛仔裤的代数化简（特例）

当处理**标准五口袋无省牛仔裤**（$S_{\text{dart}} = 0$），且前片腰臀调节量相等（$k_{\text{hip}} = k_{\text{waist}} = k$）时，将参数代入母公式：

$$\Delta X_{\text{side}} = \left( \frac{H}{4} - k \right) - \left( \frac{W}{4} - k + 0 \right) - X_{\text{front\_slant}}$$

展开括号消去 $k$：

$$\Delta X_{\text{side}} = \frac{H}{4} - \frac{W}{4} - k + k - X_{\text{front\_slant}} = \frac{H - W}{4} - X_{\text{front\_slant}}$$

> **代数结论：** 简化公式 $\frac{H-W}{4} - X_{\text{front\_slant}}$ 只是母公式在无前省、同调节量下的极简表达，工业实操中可快速心算。

## 三、 经典牛仔版型实操计算案例

### 案例 1：经典 501 中腰直筒牛仔裤（无前省，同调节量）
* **成品臀围 $H = 96.0\text{cm}$**，**成品腰围 $W = 72.0\text{cm}$**（腰臀差 $24.0\text{cm}$）
* 前后片调节量 $k_{\text{hip}} = k_{\text{waist}} = 1.0\text{cm}$，前省 $S_{\text{dart}} = 0\text{cm}$，前中收斜 $X_{\text{front\_slant}} = 1.2\text{cm}$

* **方法 A（母公式推导）：**
  1. 前片成品臀宽：$\frac{96}{4} - 1.0 = 23.0\text{cm}$
  2. 前片成品腰宽：$\frac{72}{4} - 1.0 = 17.0\text{cm}$
  3. 前侧缝内收量：$23.0 - (17.0 + 0) - 1.2 = \mathbf{4.8\text{cm}}$
* **方法 B（简易公式校验）：**
  $$\Delta X_{\text{side}} = \frac{96.0 - 72.0}{4} - 1.2 = 6.0 - 1.2 = \mathbf{4.8\text{cm}}$$

---

### 案例 2：复古双褶牛仔裤（Pleated Denim Pants）
* **成品臀围 $H = 96.0\text{cm}$**，**成品腰围 $W = 72.0\text{cm}$**
* 前后片调节量 $k = 1.0\text{cm}$，前片单侧设计 **$2.5\text{cm}$ 褶量**（$S_{\text{dart}} = 2.5\text{cm}$），前中收斜 $X_{\text{front\_slant}} = 1.0\text{cm}$

* **计算过程（必须使用母公式）：**
  1. 前片成品臀宽：$23.0\text{cm}$
  2. 前片腰线需保留宽度：$17.0 + 2.5 = 19.5\text{cm}$
  3. 前侧缝内收量：$23.0 - 19.5 - 1.0 = \mathbf{2.5\text{cm}}$
  *(由于保留了 2.5cm 的褶量，侧缝内收量自然收窄至 2.5cm，为前褶预留了精确空间)*

---

### 案例 3：腰臀调节量不相等特例（小腹微凸体型修正）
* **成品臀围 $H = 96.0\text{cm}$**，**成品腰围 $W = 72.0\text{cm}$**
* 臀围前减量 $k_{\text{hip}} = 1.5\text{cm}$，腰围前减量 $k_{\text{waist}} = 0.5\text{cm}$（前腰留宽以贴合小腹），无前省，前中收斜 $1.2\text{cm}$

* **计算过程（使用母公式）：**
  1. 前片成品臀宽：$\frac{96}{4} - 1.5 = 22.5\text{cm}$
  2. 前片成品腰宽：$\frac{72}{4} - 0.5 = 17.5\text{cm}$
  3. 前侧缝内收量：$22.5 - 17.5 - 1.2 = \mathbf{3.8\text{cm}}$

## 四、 几何导出的“侧缝抬高点（侧起翘）” $90^\circ$ 直角法则

算出侧缝内收量并画出斜侧缝后，无需经验死记，通过以下 $90^\circ$ 直角几何交汇法即可自动交出最精准的抬高点：

```
                    (侧起翘交点 S') 抬高点
                        ●
                      / |
                    /   |  ← 几何自然抬高量 (约 0.8~1.2cm)
    90° 直角       /    |
   ┌─────────────/──────┴───── 原始水平腰基准线 (WL)
  /             /
 / (前腰弧线)  / (侧缝弧线)
              /
             / 侧缝倾斜线 (内收 4.8cm)
```

### 作图三步骤：
1. **第一步（引侧缝斜线）：** 在腰基准线上确定算出的内收点（如 $4.8\text{cm}$），过臀围侧缝点向上顺弯延伸画出侧缝线，并**向上超长延伸 $1.5\text{cm}$**。
2. **第二步（定前中下落点）：** 根据低腰/中腰下落量，前中点向下下落 $0.5 \sim 1.0\text{cm}$ 得到前中腰顶点 $F'$。
3. **第三步（直角切入求交）：** 从 $F'$ 出发向下凹微弯绘制前腰弧线；**当前腰弧线相交于侧缝延伸线时，必须保持 $90^\circ$ 绝对直角**。此时相交的交点 $S'$，即为**完美的侧缝抬高点**。

## 五、 牛仔裤特有工艺细节与结构修正

### 1. 配合牛仔前口袋（5-Pocket Scoop Pocket）的弧线修正
牛仔前片侧缝线上包含前口袋袋口的上缝合段：
* **上段 8~10cm 保持平缓：** 从腰缝线（$S'$ 点）向下 $8 \sim 10\text{cm}$（口袋缝合区域），侧缝弧线不可过度弯曲，应保持相对平直的斜线，防止装口袋布（Pocket Bag）和袋口压线时拉针起褶。
* **转折点在臀围线上 3~5cm：** 侧缝弧线的最凹弯曲转折点应放在**臀围线上方 $3 \sim 5\text{cm}$ 处**，向下顺滑过渡连接至臀围侧缝点。

### 2. 赤耳/窄幅牛仔（Selvedge Denim）的直侧缝策略
在复古原色赤耳牛仔裤打板中，为了保留外缝布边（Selvedge ID）的完整红线，**侧缝在臀围线以下必须保持绝对直缝（$0$ 弯度）**：
* 臀围线以上侧缝依然向内收进 $\Delta X_{\text{side}}$（如 $4.8\text{cm}$），但折弯转折点严格锁定在臀围点上。
* 若腰臀差较大，可适当加大**前中收斜（$X_{\text{front\_slant}}$）**和**后约克斜度**来分担侧缝内收压力。

## 六、 阶段性打板流程说明

1. **核对成衣规格：** 在纸样网格上直接核对成衣腰围、臀围、侧缝长，确保 100% 匹配目标成品规格。
2. **后置加算水洗缩率：** 确认成品结构无误后，按面料实测横向缩率 $S_h$（如 5%）与纵向缩率 $S_v$（如 3%），对整张成品样板（或在 CAD 软件中）进行按比例放大，获得最终**裁剪排料样板**。
