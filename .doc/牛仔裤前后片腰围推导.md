# 裤装及牛仔裤腰围结构与纸样推导指南

在裤装制板中，腰围（Waist Circumference）的推导涉及**成品分配量**、**省道/约克（Yoke）消纳量**以及**腰臀差侧缝修量**的综合计算。与臀围的“后大前小”不同，腰围在成品状态下通常呈现“前后平分”或“前大后小”的规律。本文整理腰围结构推导的逻辑体系、数学公式及顺向打板实操步骤。

---

## 一、 核心结构逻辑

1. **成品腰围分配原则（“平分”或“前大后小”）**：
   - **人体腰凹与腹凸**：人体后腰中部向内凹陷（腰椎前凸），而腹部微凸。因此后腰半圈的实际体表尺寸并不比前腰大。
   - **成品尺寸**：成品腰围按四分之一基础量平分（$\frac{W}{4}$），或前片比后片略大 $0.5 \sim 1.0\text{ cm}$（$\\delta$）。

2. **腰臀差消纳机制**：
   - 从臀围过渡到腰围的尺寸差（腰臀差），通过**省道（Dart）/ 约克（Yoke）** 与 **侧缝弧线（Outseam Shape）** 共同吃掉。
   - **侧缝收量不是预先确定的已知数**，而是由“裁片臀宽”减去“腰部目标量”后自然推导出的结果值。

---

## 二、 符号与变量定义

| 符号 | 含义说明 | 单位 |
| :--- | :--- | :--- |
| $W$ | 成品总腰围（含放松量） | cm |
| $W_{\text{前成品}}$ | 单侧前片成品腰宽 | cm |
| $W_{\text{后成品}}$ | 单侧后片成品腰宽 | cm |
| $\delta$ | 成品腰围前后分配调节量（通常 $\delta = 0 \sim 0.5\text{ cm}$） | cm |
| $V_{\text{前省}}$ | 前片省量或褶量（Pleat） | cm |
| $V_{\text{后省}}$ | 后片省量或后约克（Yoke）转移省量 | cm |
| $T_{\text{前}}$ | 前片腰部目标画线宽（未扣除侧缝前） | cm |
| $T_{\text{后}}$ | 后片腰部目标画线宽（未扣除侧缝前） | cm |
| $S_{\text{前侧}}$ | 推导出的前片侧缝腰端收进量 | cm |
| $S_{\text{后侧}}$ | 推导出的后片侧缝腰端收进量 | cm |

---

## 三、 腰围推导公式体系

### 1. 成品腰围分配公式

设定成品腰围分配调节因子为 $\delta$：

- **单侧前片成品腰宽**：
  $$W_{\text{前成品}} = \frac{W}{4} + \delta$$

- **单侧后片成品腰宽**：
  $$W_{\text{后成品}} = \frac{W}{4} - \delta$$

> **说明**：
> - **前后平分法**：取 $\delta = 0$，则 $W_{\text{前成品}} = W_{\text{后成品}} = \frac{W}{4}$（绝大多数标准牛仔裤/休闲裤采用）。
> - **前大后小法**：取 $\delta = 0.5\text{ cm}$，则前片比后片大 $1.0\text{ cm}$（用于无弹高腰合体女裤，更贴合后腰凹陷）。

---

### 2. 纸样目标画线宽公式（含省量/约克）

在未缝合的纸样画线阶段，腰宽必须将吃掉的结构量（省/褶/约克）加回：

- **前片腰部目标量**：
  $$T_{\text{前}} = W_{\text{前成品}} + V_{\text{前省}} = \left(\frac{W}{4} + \delta\right) + V_{\text{前省}}$$

- **后片腰部目标量**：
  $$T_{\text{后}} = W_{\text{后成品}} + V_{\text{后省}} = \left(\frac{W}{4} - \delta\right) + V_{\text{后省}}$$

---

### 3. 侧缝收量推导公式（结果导出）

已知前片基础臀宽 $H_{\text{前}}$ 与后片基础臀宽 $H_{\text{后}}$（见臀围推导文档）：

- **前片侧缝收进量**：
  $$S_{\text{前侧}} = H_{\text{前}} - T_{\text{前}} = \left(\frac{H}{4} - \Delta\right) - \left(\frac{W}{4} + \delta + V_{\text{前省}}\right)$$

- **后片侧缝收进量**：
  $$S_{\text{后侧}} = H_{\text{后}} - T_{\text{后}} = \left(\frac{H}{4} + \Delta\right) - \left(\frac{W}{4} - \delta + V_{\text{后省}}\right)$$

---

## 四、 实操打板的顺向推导步骤

在实际开版制板时，遵循“先臀围，再目标腰围，最后收侧缝”的逻辑：

```
[ Step 1: 画出基础臀围线 (H/4 ± Δ) ]
               │
               ▼
[ Step 2: 设定成品腰宽 + 省量/Yoke量 (T = W/4 ± δ + V) ]
               │
               ▼
[ Step 3: 计算腰臀残余差值 (S = H - T) ]
               │
               ▼
[ Step 4: 侧缝向内量入 S，用弯尺连接臀围线顺弧 ]
```

1. **定臀线**：按臀围公式在横向上定出前片臀宽 $H_{	ext{前}}$ 和后片臀宽 $H_{	ext{后}}$。
2. **定目标腰量**：在腰线位置定出 $T_{	ext{前}}$ 和 $T_{	ext{后}}$（包含设定的省量或约克转移量）。
3. **求侧缝差值**：计算 $S = 	ext{裁片臀宽} - T$。
4. **画侧缝弧线**：自侧缝最外侧向内量入 $S$，使用服装弯尺将其顺弯连接至臀围线。

---

## 五、 不同裤型腰部结构处理对比

| 裤型 | 前片省量 $V_{	ext{前省}}$ | 后片省量 $V_{	ext{后省}}$ | 侧缝收量特点 |
| :--- | :--- | :--- | :--- |
| **标准牛仔裤（Jeans）** | **$0	ext{ cm}$**（无前省，贴合前腹） | **$2.5 \sim 4.0	ext{ cm}$**（用后约克 Yoke 代替直省） | 前侧缝收量较小，后侧缝由 Yoke 承担大部分消纳 |
| **传统西裤（Trousers）** | **$1.5 \sim 2.5	ext{ cm}$**（直省）或 **$3 \sim 6	ext{ cm}$**（打褶 Pleat） | **$2.0 \sim 3.0	ext{ cm}$**（直省） | 前后侧缝均匀收量，腰线弧度平缓 |
| **高弹紧身女牛仔裤** | **$0	ext{ cm}$** | **$1.5 \sim 2.5	ext{ cm}$**（浅 Yoke） | 腰臀差大部分靠面料拉伸消除，侧缝弧度较平 |

---

## 六、 总结

裤装腰围推导的核心在于区分**“成品腰宽”**与**“纸样腰宽”**：
- 成品腰宽是基础目标：由 $rac{W}{4} \pm \delta$ 决定。
- 纸样腰宽是绘图步骤：在成品宽上加加省量/约克量，最后与臀围线相减推导出侧缝收量。
