# 牛仔裤前中内收量推导指南

## 一、 核心功能：它解决了什么问题？

在牛仔裤平面打版中，**前中内收（前中进量）** 是配合人体工学与结构美学极其关键的微调技术：消除拉链区鼓包与“猫胡须”横褶，贴合骨盆向内倾斜的生理结构。不做调整的负面后果是前浪（拉链处）凸起拱起、产生“骆驼趾”或多余堆褶。

---

## 二、 计算基准：成品腰臀差

在推导内收量与消纳量时，必须明确一个核心原则：

$$\text{成品腰臀差}(\Delta_{HW}) = \text{成品臀围}(H) - \text{成品腰围}(W)$$

* **关键原则：** 打版推导**必须基于“成品腰臀差”**，而非“人体净腰臀差”。
* **消纳量分配：** 前中内收量、后中进量、侧缝收进量以及腰省，共同分担了 $\Delta_{HW}$ 在纸样四分之一截面上的总消纳布料量。

---

## 三、 前中内收量（进量）推导逻辑与算式

### 1. 推导逻辑
前中内收量主要受 **成品腰臀差** 和 **裁片立裆深度（腰位高低）** 的双重影响：
* **腰臀差越大** $\rightarrow$ 腰部收拢越剧烈 $\rightarrow$ 内收量加大。
* **腰位越高（立裆越深）** $\rightarrow$ 从臀围线向上延伸到腰线的斜长越长 $\rightarrow$ 内收量加大。

### 2. 经验推导算式与分配

前片四分之一纸样的总消纳量即为 $\frac{\Delta_{HW}}{4} = \frac{H - W}{4}$，前中内收量通常占其中的 **$15\% \sim 20\%$**，以系数 $k$ 表示：

$$\text{前中内收量} = \frac{\text{成品臀围}(H) - \text{成品腰围}(W)}{4} \times k \quad (k \text{ 默认取 } 0.2)$$

* $k = 0.2$ 时内收量 = $\frac{H-W}{20}$，为区间上限参考值；低腰款可取 $k = 0.15$ 或以修正量微调。

### 3. 不同腰位（高/中/低腰）实操对照表

| 腰位类型 | 成品腰臀差特征 | 立裆深度特征 | **前中内收推荐值** |
| :--- | :--- | :--- | :--- |
| **超高腰裤** | 腰臀差极大（约 $24 \sim 30\text{cm}$） | 立裆极深 | **$1.5 \sim 2.0\text{cm}$** |
| **标准中腰裤** | 腰臀差适中（约 $20 \sim 24\text{cm}$） | 立裆标准 | **$1.0 \sim 1.5\text{cm}$**（工业标准常用 $1.2\text{cm}$） |
| **低腰牛仔裤** | 腰臀差极小（腰头卡在胯骨） | 立裆极浅 | **$0.5 \sim 1.0\text{cm}$** |

> **预测口径加注（2026-09-02）**：本节 k=0.2 系数口径为**引擎实现基准**（`front_intake_ratio` 默认 0.2 不变）。照片提取（extract）的**预测口径**已被 [参数预测/前中内收预测.md](参数预测/前中内收预测.md)（K2：高腰基准带 2.5~3.5 + 四维修正）取代——用户裁定，见 [参数预测/参数推测知识库.md](参数预测/参数推测知识库.md) 冲突裁定记录。两口径差异只影响 extract 发射值，不影响引擎公式。

## 四、 平面打版实操画法

1. **画内收量：** 在前片纸样腰线位置，从原始前中垂直基准线向内平移量取 **前中内收量**（如 $1.2\text{cm}$），过此点与前中臀围线交点连斜线，得到 **前中斜缝线**。
2. **定腰线：** 前中斜缝线的后续处理（直角下落、顺弯腰线）详见 [前中下落量推导.md](前中下落量推导.md)。
